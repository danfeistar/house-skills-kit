## 快速上手（零依赖，任何电脑有 Python3 即可跑）

```bash
python3 tools/mortgage.py --price 1500000 --downpay 30 --years 30 --city 昆明
python3 tools/tax.py --price 1500000 --area 89 --city 昆明 --first 1 --held 6 --unique 1   # 全成本：税4项+费6项，买卖分账

python3 tools/floor.py --price 25000 --area 100 --floor 15 --top 30 --floor-adj 300 --d 98 --d 99 --pay one_time
```

## 三件工具

| # | 工具 | 脚本 | 覆盖场景 |
|---|---|---|---|
| ⑦-1 | 房贷月供计算器 | `mortgage.py` | 商贷/公积金/组合贷 × 等额本息/本金，利息对比、首付档校验 |
| ⑦-2 | 二手房税费计算器 | `tax.py` | 契税（首二套×面积段）/增值税（满二）/个税（满五唯一、差额取低），买卖双方分担 |

## 规则三层引擎（核心设计）

```
层1 全国默认档（rules/cities.yaml → default）
      ↓ 被覆盖
层2 城市档（cities: 昆明/成都/武汉…35城）→ 区县档（districts）
      ↓ 被覆盖
层3 我的模板（--save-template 存 JSON，--template 调用）
```

- **未内置城市**：自动套全国默认档并明确提示（同级模板+一键改，不装懂）
- **每个数字可追溯**：输出末尾附「参数来源表」——这个利率来自哪个城市档、哪个版本时点
- **改政策不改代码**：长沙契税新政出台 → 只改 `rules/cities.yaml` 一行，工具秒更新

```bash
# 存模板：把昆明参数存成我的模板
python3 tools/mortgage.py --city 昆明 --save-template my_kunming --price 1500000 --downpay 30 --years 30
# 之后任何城市参数不满足时：
python3 tools/mortgage.py --template my_kunming --price 1800000 --downpay 25 --years 25
```

## 老何验收指南（手工复核，10分钟）

**① 月供**：`--loan 1050000 --years 30 --city 昆明`（3.10%）
- 等额本息月供应 ≈ 4,484 元。计算器验算：月利率 = 0.031/12 = 0.0025833，360 期 → 月供 = 105万×0.0025833×(1.0025833)^360÷((1.0025833)^360−1)
- 等额本金首月 = 105万/360 + 105万×0.0025833 = 2,916.67 + 2,712.50 = **5,629 元** ✓
- 两方案利息差 74,516 元：0.031×105万×(359+1)/2×(月) 差额推导

**② 税费**：昆明 150 万 / 89㎡ / 首套 / 满五唯一 → 只有契税 1%（≤90㎡）= **15,000 元**
- 对照：武汉 200 万 / 120㎡ / 二套 / 未满二 → 契税 2%=4 万 + 增值税 5%=10 万 + 个税 1%=2 万 = **16 万**

**③ 折扣**：25,300 元/㎡ × 100㎡ = 253 万 → 98折 × 99折 × 一次性让2个点
- 综合 = 0.98×0.99×0.98 = **0.9508**，成交 = 253万 × 0.9508 = **2,405,514 元**（优惠 124,486）
- 套路校验：把基准改 26,000 同样折扣 → 折后更高 → 判定"折扣注水"

## 已知边界（诚实声明）

- 规则库全部档位为**演示口径**（yaml 顶部已声明），正式商用前须逐城核对当地最新官方公告——这是产品机制（数据外置+版本标注），不是缺陷
- 楼层差按"每层递增 X 元/㎡"线性简化；一房一价精确口径以销控表为准
- 个税"差额20% vs 全额1%"演示取低逻辑，部分城市强制差额法 → 改城市 YAML 即可
- 契税/增值税以家庭为单位认定（含未成年子女），工具按用户自报 `--first` 计算
