# 二手房源开发与委托 SOP · broker-listing-sop

**一句话**：二手经纪的房源端全链——房源从哪来 → 业主为什么卖、价格怎么谈下来 → 委托怎么签才有效 → 实勘建档怎么不留隐患 → 房源怎么分级维护 → 跳单怎么防，最后一环是**佣金证据链**。

**适用角色**：二手房经纪人（房源开发与维护）、门店经理（委托审批与纠纷处理）、经纪公司运营（真房源合规与端口管理）

**触发场景**：
- 小区驻守/端口/老业主转介拿到新业主，第一次上门
- 业主报价明显高于同小区近三个月真实成交
- 要签委托协议，纠结一般委托还是独家
- 实勘拍照建档，不确定哪些项必须核、哪些话不能说
- 房源挂牌 30 天没带看，要不要降价、怎么提
- 业主想私下成交 / 客户想跳过中介，怀疑跳单

## 核心认知（先立这四条）

1. **房源不是"登记"，是"拿到可成交的委托"**——只登记了电话、业主随便挂个价的，叫试水盘，不叫房源；房源质量的判据是三条：产权可查、价格可谈、业主可签委托。
2. **业主的价格不是被说服的，是被对照出来的**——你讲"太贵了"永远没用，拿同小区近三个月真实成交（不是挂牌价）摆出来，业主自己会算。
3. **独家是买来的，不是求来的**——独家委托必须给对价（推广投入、带看承诺、专属维护），只想锁死业主又不投入的"空独家"，既签不下来也守不住。
4. **佣金不是事后要的，是事前留痕的**——跳单官司打的从来不是道理，是带看确认单、委托协议、看房记录这些在成交前就已经存在的纸。

## 合规红线（每次输出前必查）

1. **真房源**：照片、面积、户型、朝向、楼层必须与实勘一致；禁止用效果图、样板间、别家房源图代替实勘；禁止美颜拉宽制造"大空间"
2. **不隐瞒瑕疵**：抵押、查封、共有、继承未过户、学位占用、户口未迁、租客在租、违建改造、凶宅等重大情形，必须书面告知并留痕
3. **不虚假承诺价格**：禁止以"我能卖更高"套取委托；禁止承诺"保证卖出"或"保证卖到某价"
4. **不擅自代理**：无委托不得对外发布该房源；共有产权必须全体共有人知情同意
5. **佣金明示**：佣金比例、承担方、支付节点必须在委托协议中写明，禁止事后加价、拆分收费
6. **个人信息保护**：业主电话、身份证、房产证影像不得外发、不得转给同行、不得存入非公司系统
7. **不骚扰不施压**：禁止高频电话轰炸、禁止以"再降就没人要了"式恐吓逼降价、禁止扣留钥匙或证件
8. **独家合规**：独家期限、独家对价、解约条件必须写清；不得设置无限期或无法解约的独家条款

## 与其他技能的关系

- 交易流程、税费、贷款、过户、交房 → `broker-client-deal-sop`（客户端）与 `calc-toolkit`（二手交易全成本、税费、月供、佣金提成）
- 房源讲房要点、竞品对照 → `sales-talk-library` 的地段/配套/户型域，按二手房口径改写
- 市场行情与竞品监控 → `competitive-intel-sop`（周监控三源交叉）
- 价格策略与优惠释放 → `pricing-incentive-release-sop`（一手口径，二手只借其分层与审批思路）
- 所有数字（税费、月供、佣金、成本）→ `calc-toolkit`，禁止口算

## 培训演练模式

- **业主压价演练**：AI 扮演业主"隔壁老王家挂 180 万，我这套不能低于 175"，经纪人演练 Part 2 的对照校准流程，AI 按"是否用了真实成交价、是否给三步报价"打分
- **委托签约演练**：AI 扮演坚持"只签一般委托"的业主，经纪人演练 Part 3 的独家对价说明，检查是否出现空独家式承诺
- **跳单复盘**：把真实纠纷经过贴进来，AI 对照 Part 6 逐项核证据链缺口，输出"下次该在哪个节点补哪张纸"

## 规范六段（v1 补齐）

### 必问信息
| 必问项 | 为什么要 |
|---|---|
| 业主卖房动因（换房/资金/继承/离婚等） | 决定议价空间与带看配合度 |
| 期望价与可接受底价（分开问） | 决定挂牌价与议价策略 |
| 房龄、产权状态（是否满年限、有无共有） | 决定交易周期与税费测算口径 |
| 抵押与查封情况 | 未查清等于埋雷 |
| 是否接受独家委托、钥匙与看房条件 | 决定维护动作与带看效率 |
| 房屋硬伤（采光/噪音/渗漏/户型） | 决定定价修正与话术边界 |

### 知识库与数据来源
- 房源卡十二字段与实勘十二项（本技能 Part 5/6）为唯一记录标准
- 价格锚点：同小区近 3 个月真实成交与在售挂牌（写明取数日期与来源）
- 政策、税费、限购、学位：按当地当期公告现查；本技能不含任何城市具体数字

### 目标读者
二手房经纪人（房源开发与维护）、店东（房源资产盘点）、业主（委托方案说明）。

### 写作风格
- 给业主的口径要口语化、有依据：每个报价建议后面跟一条事实（成交/带看/挂牌量）
- 不承诺成交价与成交周期，只给区间与条件
- 内部记录用字段语言，对外沟通不用内部术语

### 输出格式
1. 房源卡（十二字段，含实勘结论与硬伤）
2. 委托方案（三类委托对比 + 独家对价 + 协议七要素提醒）
3. 维护计划（30/60/90 天动作与触发条件）
4. 需要业主确认/补充的缺项清单

### 数据时间戳
房源卡标注挂牌价与成交锚点的取数日期；价格类数据超过 30 天必须重取；政策口径标注公告期。委托协议标注签署日期与到期日。
