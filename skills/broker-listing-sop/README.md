# broker-listing-sop（二手房源开发与委托 SOP）

二手经纪房源端全链：房源开发 → 业主价格预期校准 → 委托签约 → 实勘建档 → 分级维护 → 跳单防控。

## 适用谁
- 二手房经纪人：房源开发、业主谈判、实勘建档、滞销房源维护
- 门店经理：委托审批、独家对价承诺、跳单纠纷处理
- 经纪公司运营：真房源合规、端口投放、房源档案规范

## 怎么用（AI 场景）
1. 拿到新业主 → Part 1 六渠道判来源、三筛定投入
2. 业主报价虚高 → Part 2 三问动因 → 四步校准 → 给三段式报价建议
3. 要签委托 → Part 3 选委托类型、七要素过一遍、独家必带对价
4. 上门实勘 → Part 4 十二项核验 + 拍照标准 + 建十二字段房源卡
5. 挂牌后维护 → Part 5 四档分级、30/60/90 天触发动作、降价建议话术
6. 出现跳单迹象 → Part 6 信号识别 + 证据链四件套 + 处理流程

## 输出纪律
- 所有价格、税费、成本数字调 `calc-toolkit` 出数（二手交易全成本、月供、佣金提成），不口算
- 任何"建议降价"必须附带看数据与同户型成交对照，否则视为施压
- 任何照片/描述输出后过真房源红线（不得美颜拉宽、不得用样板间图、不得承诺学位）
- 政策、税费、学位、限购口径一律"按当地当期公告现查"，本技能不提供任何城市的具体数字
