# 渠道协同与分销管理 SOP（channel-collaboration-sop）

把渠道准入、政策培训、客户报备、案场交接、判客争议、佣金对账和渠道复盘串成一个可追踪流程。

## AI 使用场景
1. 输入渠道资料 → 输出准入档案卡、缺失资料和分层建议
2. 输入批准政策 → 输出渠道政策发布卡和培训验收清单
3. 输入报备、查重、签到和接待记录 → 输出时间线与待人工确认项
4. 输入结佣资料 → 输出政策版本、节点和金额差异表
5. 输入渠道数据 → 输出数量、质量、成本和合规复盘

## 输出纪律
- 客户归属只按已生效规则和证据呈现，AI 不代替授权人判案
- 客户信息遵循最小必要原则，不生成名单交换或扩散方案
- 未审批的价格、优惠、佣金和权益标记为待确认
- 渠道数量不能替代客户体验、成交质量和合规指标

## 与其他技能的关系
- channel-mgmt / inner-attribution / commission-mgmt：渠道底层模块
- pricing-incentive-release-sop：价格和优惠口径
- activity-organization-sop：活动联合获客
- sales-lead-grading：客户登记和跟进

## 什么时候不要用我

这个技能有明确边界，用错场景会得到看似正确但方向相反的结论：

- **渠道配比设计、依赖度红线、佣金档位与跳点** → `channel-management-advisor`（决策层）；本技能是执行层
- **佣金、税费的具体金额核算** → `calc-toolkit/commission.py`（`--scene channel`，支持跳点双算）
- **报备与归属的系统实现** → 内部 CRM 与流程配置，本技能只给规则
- **单客户成交与带看话术** → `broker-client-deal-sop` / `sales-closing-sop`

本技能不提供政策数字与法律结论：一律按当地当期公告现查。
