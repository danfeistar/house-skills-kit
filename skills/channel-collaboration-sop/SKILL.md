# 渠道协同与分销管理 SOP（标准作业程序）· channel-collaboration-sop

**一句话**：把渠道合作从“找人带客”变成准入有标准、报备有记录、接待有交接、佣金有依据、争议有仲裁的协同系统。

**适用角色**：渠道负责人、项目营销负责人、渠道经理、案场负责人、置业顾问、合作门店/机构和财务对账人员。

## 使用规则

1. 渠道合作以书面协议、项目政策和系统台账为准，不以口头承诺替代。
2. 客户归属按已生效的公司规则处理；AI 只整理证据和引用规则，不越权判案或改判。
3. 价格、优惠、佣金、保护期和结算条件必须使用当前版本，变更要同步并回收旧版。
4. 只采集和传递完成业务所必需的客户信息，禁止买卖、交换或扩散客户名单。
5. 渠道带访不改变案场接待、合规宣传和客户自主选择的底线。

## 核心流程

```text
渠道准入 → 合作签约 → 政策培训 → 报备查重
→ 到访预约 → 案场交接 → 归属确认 → 成交与回款核验
→ 佣金对账 → 异常仲裁 → 渠道分层复盘
```

## 三、报备、查重与到访交接

### 报备最小字段

| 字段 | 要求 |
|---|---|
| 客户标识 | 使用授权范围内的最小必要信息 |
| 意向项目 | 项目、批次或产品线 |
| 报备时间 | 系统自动记录或可核验时间 |
| 渠道主体 | 与合作档案一致 |
| 客户来源 | 渠道真实来源，不填虚构来源 |
| 预计到访 | 仅作预约信息，不等于实际到访 |
| 查重结果 | 有效/重复/待人工核验 |
| 操作人 | 渠道和案场各自留痕 |

### 标准交接

```text
渠道报备 → 系统查重 → 预约确认 → 到访签到
→ 案场接待人确认 → 需求与到访事实记录 → 归属状态更新
```

- 报备条件不完整，进入待补全，不直接锁定归属。
- 自然来访、二访、多访、亲属代购和跨渠道情况，按公司书面规则进入人工仲裁。
- 仲裁期间客户信息最小化展示，未确认前不向任何渠道承诺归属或佣金。
- 渠道人员不得代替客户签署、确认或提供虚假身份信息。


## 六、冲突与仲裁

### 处理原则

1. 先冻结争议记录和相关新增动作，不删除、不改写原始时间戳。
2. 收集最小必要证据：报备记录、查重结果、到访签到、接待记录、政策版本和客户授权信息。
3. 对照生效规则形成争议事实表，明确已知、未知和待补证据。
4. 由指定负责人或仲裁小组作出书面结论，AI 不代替授权人裁决。
5. 将结论、通知对象、执行时间和后续佣金影响归档。

复盘同时看数量、质量、成本、合规和客户体验，不以报备量单项排名。

## 合规红线

1. 不得买卖、交换、爬取或扩散客户名单及非必要个人信息。
2. 不得虚假报备、重复占客、冒用客户身份或诱导客户修改真实来源。
3. 不得发布未审批价格、优惠、佣金、返现、保本或收益承诺。
4. 不得以渠道费用、礼品或其他名义向客户违规收费或变相收费。
5. 不得以“内部关系”私改判客、保护期、价格或佣金结算规则。
6. 不得为了争夺归属在客户面前争吵、截留、贬损他方或强迫客户选择渠道。
7. 发现违规宣传、信息泄露、重大投诉或结算争议时，先暂停相关业务并升级处理。
