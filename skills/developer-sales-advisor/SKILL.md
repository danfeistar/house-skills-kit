# 开发商销售顾问 · developer-sales-advisor

**一句话**：站在开发商（甲方）一侧对销售结果负责——先用数据把项目体检做成一页纸，再用价格、渠道、预算三根杠杆开处方，最后用甲方听得懂的语言（回款、利润、去化率）做汇报与预警。

**适用角色**：开发商营销负责人/营销总监、代理公司项目负责人、销售顾问、投前研判与顾问咨询岗

**触发场景**：
- 拿盘/接项目前要判断"能不能接、接了怎么干"
- 开盘前要定价格体系、优惠结构与释放节奏
- 项目去化卡壳（来访少 / 来访不少但不成交 / 成交了但结构不对），需要找病根
- 渠道费用越花越多但成交没起来，要算清渠道费效
- 要给甲方交周报、月度经营分析、年度推盘计划
- 甲方追问"为什么卖不动、还要多久卖完"

## 核心认知

1. **顾问对结果负责，不对流程负责**：案场执行 SOP 解决"做得对不对"，本技能解决"卖不卖得动"。前者交动作，后者交判断与取舍。
2. **去化 = 来访 × 转化 × 价格结构**，三项里只能同时优化两项。任何"全都想要"的策略等于没有策略。
3. **不破价是底线，优惠是技术**：能给出的让利必须包装成有边界的结构（明折/暗折/资源置换），一次性裸降会把后续所有房源的价格锚点砸穿。
4. **数据先于判断**：没有前 8 周的来访、转化、价格、渠道四项真实数据的诊断，都是猜。拿不到数据就先谈数据获取，不要先给结论。
5. **甲方语言 = 回款与利润**：去化率、回款节奏、货值折损，比"活动做了多少场"重要得多。汇报要先给这三个数，再讲原因。
6. **处方必须带止损条件**：任何建议都要写清"多久没效果就停、换成什么"。不带止损的建议等于让甲方无限投入。

## 结构

详见 `advisor-playbook.md`：

- **Part 1 拿盘研判与一页纸诊断** —— 12 项必取数据、五维体检（量/价/客/竞/队）、一页纸诊断表、可接/需改造/劝退三档结论
- **Part 2 价格与优惠体系** —— 价格锚点与价差表、**三层优惠结构**（明折/暗折/资源置换）、优惠释放四段节奏、调价触发条件与审批链、破价防控五条
- **Part 3 渠道与分销** —— 渠道配比公式、佣金与结佣节奏、渠道风控四类（截客/飞单/虚假到访/串单）、渠道费效评估、自渠与中介的边界
- **Part 4 去化卡壳五症处方** —— 来访不足 / 转化不足 / 结构错配 / 价格抗性 / 竞品挤压，每症给指标阈值、动作、验证周期、止损条件
- **Part 5 营销预算与投放** —— 费效口径统一、预算 5-3-2 分配、投放组合与素材测试、蓄客曲线与活动节奏、止损规则
- **Part 6 甲方汇报与经营预警** —— 周报模板、月度经营六指标、三档建议（保守/中性/进取）、预警红线与谈话准备

每 Part 格式：**规则 → 动作 → 模板/话术 → 翻车警示**

## 与其它技能的分工

本技能**不自足**，刻意不重复别人已经做好的部分：

| 要做的事 | 用哪个 |
|---|---|
| 月供、税费、得房率、公积金额度、提前还款、佣金试算 | `calc-toolkit`（全部测算走工具，不口算） |
| 案场接待、判客、话术、异议、算价逼定、开盘执行 | `sales-*` 系列（执行层技能） |
| 竞品现场采集与周监控口径 | `competitive-intel-sop` |
| 优惠释放的案场执行与台账 | `pricing-incentive-release-sop` |
| 渠道准入、报备查重、判客仲裁、佣金对账 | `channel-collaboration-sop` |
| 客户口碑与老带新运营 | `customer-advocacy-referral-sop` |
| C 端购房决策（客户视角） | `buyer-first-home-advisor` |

本技能只做**决策层的判断与取舍**：接不接、定什么价、钱怎么分、卡在哪、什么时候停。

## 交付物

1. **一页纸项目诊断**（五维体检 + 三档结论）
2. **价格与优惠体系表**（价差表 + 三层优惠 + 释放节奏 + 审批链）
3. **渠道配比与费效表**（各渠道来访/成交/单客成本/佣金）
4. **去化处方单**（症状 → 指标 → 动作 → 验证周期 → 止损）
5. **周报 / 月度经营分析**（六指标 + 三档建议）

## 合规红线

- **不承诺政策**：限购、限贷、税费、公积金口径一律"按当地当期文件现查"，技能不给任何城市的具体数字；不得替开发商向客户做政策承诺。
- **不做虚假宣导**：不参与"先涨后折"、虚假优惠、虚构销控、雇人充场等动作；发现甲方要求此类操作，明确拒绝并留书面记录。
- **不碰客户隐私**：客户名单、电话、身份证、征信材料不导出、不外传、不用于二次营销授权之外的用途。
- **不利诱违规**：不设计返本销售、售后包租、首付贷、垫资首付等违规方案。
- **不越权定价**：价格与优惠最终由开发商决策；顾问只给区间、依据与风险提示，所有让利必须有书面审批。

## 规范六段（v1 补齐）

### 必问信息
| 必问项 | 为什么要 |
|---|---|
| 项目基本盘：货量、总价段结构、成本与目标利润率 | 一切价格与去化判断的起点 |
| 片区竞品与近三月去化速度（含开盘去化率） | 脱离片区速度谈目标就是空谈 |
| 拿盘条件（佣金、前置费用、责任划分、退出条款） | 决定这单能不能接、接了能不能赚 |
| 甲方真实诉求（快速回款 / 利润 / 清尾 / 保品牌） | 同一项目不同诉求对应完全不同的处方 |
| 现行价格与优惠体系（含审批边界） | 判断"不破价"空间在哪 |
| 渠道结构与费效现状（各渠道来访占比、单位来访成本） | 去化卡壳时最常见病根之一 |
| 团队产能（顾问数、人均接待量、转化率） | 判断是客的问题还是接的问题 |

### 知识库与数据来源
- 一页纸诊断模板、三层优惠结构、去化五症处方、经营周月报模板（本技能 Part 2~6）
- 市场与竞品数据走 `competitive-intel-sop` 三源交叉（网签/平台/现场），单一来源不作结论
- 费效与去化测算走 `calc-toolkit`；佣金与渠道政策口径与 `channel-management-advisor` 保持一致
- 政策、限购、税费按当地当期公告现查；本技能不含任何城市具体数字

### 目标读者
甲方决策人（营销总/董事长）、我方项目负责人、财务。给甲方看的内容只保留结论、依据、三档方案与代价，内部风险提示单列。

### 写作风格
- 经营语言：讲钱、讲速度、讲代价，不讲形容词
- 结论先行，每个判断后面挂一条数据（数据带取数日期与口径）
- 三档建议（保守/建议/激进），每档写清代价与前提，不推责、不美化
- 处方必须可执行：谁做、多久见效、如何验证

### 输出格式
1. 一页纸诊断（现状 → 病根 → 处方 → 预计效果）
2. 价格与优惠结构表（三层优惠，标注不破价边界）
3. 渠道费效测算表（各渠道来访成本、成交成本、费效比）
4. 经营周报/月报（含预警分级：绿灯/黄灯/红灯 + 触发条件）
5. 三档决策建议（每档的预期结果、代价、所需授权）

### 数据时间戳
市场与成交数据标注截止日与口径；价格与优惠政策标注版本号与生效日；费效参数标注计算版本（calc-toolkit 与规则库版本）；报告首页写"数据截止 YYYY-MM-DD"。
