# 开发商销售顾问 · 作业手册（advisor-playbook）

本手册是 `SKILL.md` 的正文展开。六个 Part，每 Part 统一格式：**规则 → 动作 → 模板/话术 → 翻车警示**。

所有测算（月供、税费、得房率、佣金、提前还款）一律走 `calc-toolkit`，本手册不口算、不给任何城市的具体政策数字。

---

## Part 1 拿盘研判与一页纸诊断

### 规则

1. **先要数据，后给判断**。拿不到前 8 周的真实数据，就不做诊断，只做"数据获取清单"。凭印象给出的结论，甲方一旦当真，后面全是你的责任。
2. **体检只看五个维度**：量（货量与结构）、价（价格带与让利空间）、客（来访基数与画像）、竞（竞品挤压度）、队（团队产能）。五个维度各自独立打分，不互相抵消。
3. **结论必须落成三档**：可接 / 需改造后接 / 劝退。没有第四档，也不要给"看情况"。

### 动作

**第一步：12 项必取数据清单**（缺项要标注，不要用推测填空）

| # | 数据项 | 口径要求 |
|---|---|---|
| 1 | 可售总货量与总货值 | 分楼栋/分产品，注明取证与未取证 |
| 2 | 产品结构 | 面积段、户型、楼层、朝向各自占比 |
| 3 | 历史去化 | 开盘至今累计 + 最近 8 周周均来访与周均成交 |
| 4 | 成交价格 | 表价、优惠后实收单价与总价段分布 |
| 5 | 库存结构 | 滞销房源清单（楼栋-户型-总价段），标注滞销天数 |
| 6 | 竞品 | 3 公里内直接竞品的供应量、周成交、价格带 |
| 7 | 来访渠道 | 各渠道来访量与单客成本（自渠/中介/老带新/自然） |
| 8 | 客户画像 | 来源区域、职业、家庭结构、首付能力分布 |
| 9 | 回款 | 已签未回款、按揭在途、逾期金额与账龄 |
| 10 | 成本与利润线 | 开发成本、可让利空间、降价到哪个点亏损 |
| 11 | 节点 | 施工、取证、交付、融资还款节点 |
| 12 | 团队 | 编制人数、在岗人数、近 3 个月流失、佣金政策 |

**第二步：五维体检打分**（每维 1-5 分，5 最好）

- **量**：货量是否与团队产能匹配；结构是否集中在难卖的总价段
- **价**：价格带在当地是否有竞争力；让利空间是否够打完一整年
- **客**：周均来访是否达得到目标（目标来访 = 月去化目标 ÷ 转化率 ÷ 4.3）
- **竞**：竞品是否在价格/产品/位置上形成硬挤压
- **队**：人均月成交、流失率、佣金是否有吸引力

**第三步：一页纸诊断表**

| 维度 | 现状（数据） | 判断 | 杠杆 | 风险 |
|---|---|---|---|---|
| 量 | 可售 XX 套 / 滞销占比 XX% | 健康 / 偏弱 / 恶化 | 定向去化 | 结构继续恶化 |
| 价 | 实收均价 XX，竞品 XX | … | 三层优惠 | 破价 |
| 客 | 周均来访 XX，目标 XX | … | 渠道+内容 | 单客成本上升 |
| 竞 | 竞品周成交 XX | … | 差异点对标 | 被动跟价 |
| 队 | 人均月成交 XX 套 | … | 编成+激励 | 人员流失 |

**第四步：三档结论 + 接的条件**

- **可接**：四维及以上健康 → 给推盘节奏与年度目标
- **需改造后接**：二到三维恶化但有明确杠杆 → 写明"改造动作 + 达标条件 + 不达标就撤"
- **劝退**：价格带与产品结构出现结构性死结（如总价段超出当地主流购买力 40% 以上且无改造空间）→ 直接说明理由，不接

### 翻车警示

- 用甲方口径的"我们项目很好、市场不好"当数据 —— 五维里三维是主观描述，等于没体检。
- 拿不到 8 周数据就下手给策略 —— 后面所有动作都在给错误判断打补丁。
- 把某个节点（开盘、房交会）的一次性来访高峰当成基础盘 —— 一周后打回原形。

## Part 2 价格与优惠体系

### 规则

1. **明折定锚、暗折做转化、资源置换保价格表**。三者比例失控，价格体系一个月内必崩。
2. **价格表只有最新版有效**，编号 + 审批 + 下发记录，案场只执行最新版。
3. **任何让利都要有边界**：限量、限期、限房号、限付款方式，四条里至少两条。
4. **降价是最后一根杠杆**，不是第一根。价值重构 → 暗折 → 置换 → 定向调价，顺序不能倒。

### 动作

**第一步：定价格锚点**

- 三个比较对象：本项目历史成交、3 公里直接竞品、同片区二手次新
- 输出：均价带、主力总价段、单价带（低/中/高三档）

**第二步：做价差表（给区间，不给绝对数）**

| 系数类型 | 建议区间 | 说明 |
|---|---|---|
| 楼栋 | ±3% 至 ±8% | 临街/临变电/临垃圾房要单独扣减并书面说明 |
| 楼层 | 每层 0.3% 至 1% | 顶层与底层单独设档，不参与线性递增 |
| 朝向 | ±2% 至 ±6% | 主朝向差异超过两档的，需现场比对采光 |
| 户型 | ±2% 至 ±5% | 暗卫、异形、走廊过长的要单独扣减 |

> 系数区间是方法论，不是当地市场价。每条都要用本项目已成交房源回溯验证一次：拿 20 套已成交房源反算系数，误差超过 3% 就重做。

**第三步：设计三层优惠结构**

| 层 | 内容 | 占比上限 | 是否公开 | 作用 |
|---|---|---|---|---|
| 明折 | 开盘折扣、一次性付款折扣、节点折扣 | 总让利 ≤40% | 公开可宣传 | 形成"现在最便宜"的锚 |
| 暗折 | 老带新、团购、渠道专属、一对一批 | ≤40% | 不公开 | 做转化、保面子 |
| 资源置换 | 车位、物业费、家装包、家电 | ≤20% | 可公开 | 不给现金，按成本价入账，不动单价 |

原则：**置换的成本要按成本价折算，不能按销售价折算**，否则等于变相大额降价；置换清单要写进认购书的附属协议。

**第四步：优惠释放四段节奏**

| 阶段 | 给什么 | 不给什么 |
|---|---|---|
| 蓄客期 | 意向金权益、优先选房权、早鸟名额 | 不报具体折扣数字 |
| 开盘期 | 明折一次性给足（"开盘最便宜"要能兑现） | 不给渠道专属价 |
| 持销期 | 暗折 + 置换逐步收紧（每两周收一档） | 不做全线裸降 |
| 尾盘期 | 定向、限期、限量的清库存政策 | 不对外公开宣传 |

**第五步：调价触发与审批链**

触发条件（满足其一才谈，不是想降就降）：
- 连续 3 周来访达标但转化率低于目标 50%
- 滞销房源集中在单一总价段且滞销天数 > 90 天
- 竞品出现同质产品价格下探 10% 以上并持续 4 周

审批链：销售顾问提分析 → 营销负责人复核 → 开发商决策 → 价格表改版下发 → 案场培训 → 台账记录。

**第六步：破价防控五条**

1. 一口价房源限量，且明确"售完不补"
2. 价格表版本管理（编号 + 审批签字 + 下发记录）
3. 案场只执行最新版，旧版当场回收
4. 渠道不得口头报价，一律引导客户到案场按表算价
5. 老客户补差方案必须书面化，且限定时间窗，不开口头承诺

### 翻车警示

- 一上来就打折：锚点砸穿，后面每次促销都要比上次更狠。
- 给渠道特殊价被客户互相比对：一个客户知道，全城都知道。
- 活动价没有限期：客户学会等，正常价永远卖不动。
- 置换按销售价折算：账面没降价，实际让利翻倍。

## Part 3 渠道与分销

### 规则

1. **渠道考核单客成本，不考核来访量**。只考核来访，等于花钱买人头。
2. **结佣节奏就是渠道动力**。该结不结，三个月内渠道会把你从推荐名单里删掉。
3. **报备与判客规则必须书面化并公示**，否则每周都在吵架。
4. **自渠要有保护期**，否则自渠团队会被中介的报备抢单，内部先崩。

### 动作

**第一步：渠道配比**

- 参考结构（按单客成本倒推，不按习惯）：自渠 40-50%、中介分销 30-40%、老带新与异业 10-20%
- 单一渠道占比不超过 50%，超过就要问：是渠道强，还是自渠废了
- 输出：各渠道目标来访、目标成交、单客成本上限

**第二步：佣金与结佣**

| 环节 | 动作 | 时间要求 |
|---|---|---|
| 报备 | 渠道提交客户信息，系统时间戳 | 到访前 ≥2 小时 |
| 到访 | 案场登记 + 电话核验 + 留痕 | 当次 |
| 认购 | 确认归属，双方签字 | 认购当日 |
| 签约 | 渠道确认单 | 签约后 3 个工作日 |
| 放款 | 佣金按比例结算 | 放款后 15 个工作日内 |

佣金结构：基础佣金 + 阶段奖励（超额、快速放款）+ 质量系数（退房率、客诉率扣减）。

**第三步：渠道风控四类**

| 类型 | 表现 | 判定依据 | 处置 |
|---|---|---|---|
| 截客 | 自有客户被中介报备 | 自渠首访登记时间早于报备时间 | 判归自渠，两次以上暂停合作 |
| 飞单 | 案场与中介串通改归属 | 认购单与系统归属不一致 | 追佣 + 人员处理 |
| 虚假到访 | 凑数带看、假客户 | 电话回访空号/拒接率高、无有效需求记录 | 该渠道当周到访不计费 |
| 串单 | 同客户多家中介报备 | 报备时间戳 + 首次到访记录 | 判给首报，其余作废 |

**第四步：渠道费效表（每周更新）**

| 渠道 | 来访 | 有效来访 | 认购 | 成交 | 渠道费 | 单客成本 | 单套渠道费 |
|---|---|---|---|---|---|---|---|

判读标准：
- 单客成本高于自渠 1.5 倍且成交率低于自渠 → 砍量或换渠道
- 单套渠道费超过单套毛利 30% → 该渠道不可持续
- 有效来访率低于 40% → 先查真实性，再谈优化

### 翻车警示

- 只考核来访量：一个月多花几十万，成交没变化。
- 佣金拖延：渠道不吭声，但下个月带看量掉一半。
- 不设报备规则：每周都在为归属吵架，客户被反复骚扰。
- 自渠没保护期：自己人先泄气。

## Part 4 去化卡壳五症处方

### 规则

1. **先定症状，再开处方**。五症同时治等于没治，一次只治主症，其它先止血。
2. **每个处方必须写四件事**：指标阈值、动作、验证周期、止损条件。
3. **活动不治病**。活动只能放大已有的转化能力，不能修复结构问题。

### 动作：五症对照表

| 症状 | 判断指标（阈值按项目自设） | 主要动作 | 验证周期 | 止损条件 |
|---|---|---|---|---|
| ① 来访不足 | 周均来访 < 目标来访（月目标 ÷ 转化率 ÷ 4.3） | 先查承接（自然/老带新/渠道），再查曝光（素材测试），再查拦截（动线/竞品截流） | 2 周 | 投放 3 周后单客成本超上限 1.5 倍 → 换组合 |
| ② 转化不足 | 到访-认购转化率 < 项目基准 | 拆环节：接待 → 算价 → 逼定 → 签约，逐环节找漏斗断点 | 2 周 | 单环节整改 2 周无提升 → 换人或换打法 |
| ③ 结构错配 | 滞销房源占比 > 30% 且集中在单一总价段/户型 | 定向优惠 + 软装/功能改造 + 换客群重定向 | 4 周 | 4 周去化率仍 < 该段均值一半 → 报请产品调整 |
| ④ 价格抗性 | 算价后流失占比 > 50%，且客户明确表达"贵" | 先价值重构（对比表/账算给客户）→ 暗折与置换 → 才动价格表 | 3 周 | 三轮价值重构后仍流失 → 提请定向调价 |
| ⑤ 竞品挤压 | 竞品周成交持续 1.5 倍于本项目，且 >30% 流失客户提到竞品名 | 找差异点做局部对标，不打全线价格战 | 4 周 | 竞品降价 10% 持续 4 周 → 提请价格带重估 |

**处方单模板**

```
症状：            （五症选一，主症）
数据依据：        （近 8 周指标 + 阈值对比）
处方动作：        （3-5 条，按优先级，指定责任人）
验证指标与周期：  （XX 指标，X 周内应达到 XX）
止损与替代：      （X 周未达则停，换 XX 动作 / 提请 XX 决策）
资源需求：        （费用、人力、审批）
```

### 翻车警示

- 五症一起治：钱撒了，哪个都没验证。
- 不设验证周期：处方的效果永远说不清，下次还是拍脑袋。
- 用活动掩盖结构问题：热闹一周，第二周更差。

## Part 5 营销预算与投放

### 规则

1. **先统口径，再谈预算**：营销费率、单客成本、单套营销费，三个数口径不一致就没法对比。
2. **预算按 5-3-2 分**，不是按"老板喜好"分。
3. **每渠道至少 3 组素材，测 7 天**看单客成本，再决定加不动。
4. **单一渠道不超过 40% 预算**，超过就等于把命交给别人。

### 动作

**第一步：口径统一**

- 营销费率 = 营销费用 ÷ 同期销售额（含渠道佣金，单列一行便于对比）
- 单客成本 = 渠道费用 ÷ 有效到访
- 单套营销费 = 营销费用 ÷ 成交套数
- 有效到访定义：完成接待 + 留下有效联系方式 + 有明确需求

**第二步：预算 5-3-2**

| 项 | 占比 | 内容 |
|---|---|---|
| 直接获客 | 50% | 渠道佣金、信息流投放、地推、异业合作 |
| 展示与内容 | 30% | 示范区维护、物料、自媒体内容生产、口碑素材 |
| 活动与机动 | 20% | 节点活动、开盘、应急（预留不低于 10% 机动） |

**第三步：投放组合与素材测试**

- 每渠道 3 组素材（不同卖点/不同人群/不同形式），7 天为一轮
- 判读：单客成本 + 有效来访率 + 到访后认购率，三项一起看
- 加量规则：单客成本低于上限且认购率达标 → 加 30%，不翻倍

**第四步：蓄客曲线倒推**

```
月去化目标 → 月成交 → 月认购（成交 ÷ 认购转签率）
→ 月有效到访（认购 ÷ 到访转认购率）→ 周来访 → 所需曝光量 → 预算
```

每一步用本项目历史实际转化率，不用行业平均数。

**第五步：止损规则**

- 单渠道连续 3 周单客成本高于上限 1.5 倍 → 停投
- 单渠道连续 2 周有效来访率 <40% → 查真实性
- 月度营销费用超预算 20% 且成交未达 70% → 冻结机动预算，重排优先级

### 翻车警示

- 预算全压活动：热闹是热闹，客户没留下。
- 不做素材测试：一套素材打三个月，单客成本翻倍也不知道为什么。
- 只看曝光和播放量：这些数字和成交之间没有因果关系。

## Part 6 甲方汇报与经营预警

### 规则

1. **先给三个数，再讲原因**：去化率、回款、货值折损。甲方最关心这三个。
2. **有结论也要有选项**。只给一个结论，等于把决策压力推回给甲方。
3. **坏消息要早说**，而且要带处方。晚说的坏消息会变成"你为什么现在才说"。

### 动作

**周报模板（一页）**

| 指标 | 本周 | 上周 | 计划 | 差异原因 |
|---|---|---|---|---|
| 来访（组） | | | | |
| 认购（套） | | | | |
| 成交（套/金额） | | | | |
| 去化率（累计） | | | | |
| 回款（万元） | | | | |
| 渠道成交占比 / 单客成本 | | | | |

下半页固定三块：**异常项（发生了什么）→ 归因（为什么）→ 下周动作（谁、做什么、什么时候验证）**。

**月度经营分析六指标**

1. 累计去化率 vs 计划（差异按产品段拆）
2. 实收均价与优惠率走势（明折/暗折/置换三段分开）
3. 回款完成率与逾期金额
4. 渠道结构变化与费效
5. 库存结构变化（滞销清单增减）
6. 客户画像变化（来源区域、总价段迁移）

**三档建议写法**

| 档位 | 内容 | 代价 | 前提 |
|---|---|---|---|
| 保守 | 维持价格，收紧优惠，控费用 | 去化慢，回款压力大 | 现金流能撑 X 个月 |
| 中性 | 暗折 + 置换组合，渠道加量 | 毛利下降 X% | 渠道能承接 X 组/周 |
| 进取 | 定向调价 + 产品改造 + 加大投放 | 触发老客户补差，毛利下降 X% | 开发商书面同意补差方案 |

**预警红线（触发即上报，不等月度会）**

- 回款逾期超过 X 天或逾期金额超过 X 万
- 去化率连续 3 个月低于计划的 70%
- 优惠后实收价跌破利润线
- 单渠道费效恶化到 2 倍以上
- 渠道退房率或客诉率异常升高

**甲方三问的标准回答结构**

1. "能不能降价？" → 先给让利空间测算（三层结构 + 利润线）→ 给出三个选项及代价 → 说明破价后的补差与后续房源影响
2. "还能不能快卖？" → 给蓄客曲线倒推 → 指出瓶颈环节（来访/转化/结构）→ 给达标前提与时间
3. "为什么卖不动？" → 用五维数据回答，指出主症 → 给处方与验证周期 → 明确止损条件

### 翻车警示

- 只报喜不报忧：等甲方自己发现时，问题已经不可逆。
- 把"市场不好"当唯一解释：甲方听过一百遍，这句话没有信息量。
- 不给选项只给结论：甲方不做决策，项目就原地不动，最后算在顾问头上。
