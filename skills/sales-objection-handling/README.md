# sales-objection-handling（客户异议处理）

案场高频异议三段式处理库：接（共情）→ 拆（找真实顾虑）→ 转（重构+证据+行动）。

## 适用谁
- 置业顾问：接待中实时应对
- 销售经理：新人培训、每日复盘对照
- 营销策划：案口 FAQ 口径底稿

## 怎么用（AI 场景）
1. 把客户异议原话+客户类型告诉 AI → 输出：顾虑分支判断 + 对应话术 + 禁语提醒
2. 演练模式：AI 扮演客户连续施压（可指定刁难强度），顾问应对后 AI 按禁语清单+三段式完成度点评
3. 复盘模式：把当天真实对话贴进来，AI 对照本库给处理得失分析

## 输出纪律
- 应对话术中的数字必须来自本案真实数据（AI 不确定时输出"需核实"标记，不编造）
- 每条应对末尾自动附合规自查结果（威胁式施压/虚假担保/贬损竞品/淡化负债 四项）
- 化解后不自动逼定（逼定时机与动作归 L1-3 技能）
