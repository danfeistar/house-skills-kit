# 客户异议处理 · sales-objection-handling

**一句话**：案场高频客户异议的三段式处理库——接（共情）→ 拆（找真实顾虑）→ 转（重构+证据+行动），每条异议配应对话术、禁语清单、分客群变通。

**适用角色**：置业顾问（日常应对）、销售经理（培训复盘）、营销策划（案口 FAQ 底稿）

**核心认知**（培训先立这三条）：
1. **异议是兴趣的证据**——真想走的客户不提异议，提异议说明他在算这笔账
2. **处理异议的目的=推进决策，不是辩论赢**——把客户说服了但没推进，等于白说
3. **同一句异议，背后是三种不同的真实顾虑**——先拆再答，别背标准答案

## 三段式结构

```
接：共情不断裂（"您这么想很正常"——不是嘴上认同，是让客户把话说完）
拆：找真实顾虑（超预算？怕买亏？家人没同意？砍价习惯？——分支判断）
转：重构+证据+行动（换角度算账 → 给可验证的证据 → 推一小步：带看/二访/算价）
```

## 触发场景
- 客户说出异议原话，需要应对
- 新人培训、异议演练（AI 扮演客户施压）
- 案场统一异议口径（防各顾问答法打架）
- 复盘：把本日/本周真实异议对照本库查处理得失

## 结构

详见 `objections.md`：
- **四大高频异议**：太贵了 / 再看看考虑 / 怕烂尾 / 会不会再降价
- **二级异议清单**：位置远 / 楼层朝向 / 物业费 / 学区不确定 / 别的盘更便宜 / 家人反对

每条异议五件套：**客户原话 → 顾虑拆解（分支表）→ 应对话术（含可验证证据要求）→ 禁语 → 分客群变通**

## 合规红线（每条应对输出前必查）

1. **不威胁式施压**："今天不定就涨价/没了"必须有真实调价文件或真实去化数据支撑
2. **不虚假担保**：交付风险类只用证据链说话（监管账户/工程进度/已交付盘），不打包票
3. **数据可验证**：成交价、优惠、库存等证据必须真实可查，宁说"我查一下给您准数"
4. **不贬损竞品**：客户拿竞品压价时，只做客观差异对比
5. **不淡化负债**：月供折算类话术不得引导客户超出偿付能力（"奶茶钱"式话术禁用，改为收入占比健康度算法）

## 与其他技能的关系
- 价格类异议的算账数字一律调用 calc-toolkit（月供/税费/购房成本），不口算
- 逼定动作与时机在 L1-3（本库只处理异议本身，异议化解后何时逼定看 L1-3）
- 客户登记与跟进节奏在 L1-5 判客跟进 SOP

## 规范六段（v1 补齐）

### 必问信息
| 必问项 | 为什么要 |
|---|---|
| 异议原话（一字不改地记下来） | 转述后判断就会跑偏 |
| 客户类型与预算（首购/改善/投资，预算档） | 同一句话对不同客群的真实含义不同 |
| 已释放的信息（价格、优惠、贷款口径） | 前面的说法决定这次怎么接，不能自相矛盾 |
| 真实顾虑线索（价？信？决策权？时机？） | 说"太贵"的客户有一半嫌的是位置或信任 |
| 竞品对比对象（具体哪个盘、什么说法） | 应对必须有对比依据，不能空口 |
| 家人与决策人参与情况 | 家人反对往往才是真异议 |

### 知识库与数据来源
- 三段式结构（接共情 → 拆真实顾虑 → 转重构证据行动）、四大高频异议分支、六条二级异议、禁语清单（本技能 Part 1~3）
- 回应所需证据物：销控表、成交价分布、工程进度书面口径、配套官方文件（规划文号）
- 竞品数据引用 `competitive-intel-sop` 采集结果，标注采集日期
- 学区、规划、交付标准等一律按官方文件与公告表述，无文号不承诺

### 目标读者
置业顾问（现场应对）、带训主管（统一口径与演练）、新人（背话术）。

### 写作风格
- 先接情绪再拆顾虑，禁止用"但是"直接否定客户
- 每条应对必须落到三样东西：一个证据、一个类比或案例、一个下一步动作
- 严禁贬低竞品、严禁编造成交与涨价消息
- 话术短、可背诵，一段不超过三句

### 输出格式
1. 异议应对卡（原话 / 真实顾虑判定 / 三段回应 / 证据物 / 下一步动作）
2. 禁语清单（本次场景适用的禁用表述）
3. 演练脚本与记录（角色扮演场景 + 暴露问题 + 改进点）

### 数据时间戳
引用的一切数据（成交价、去化率、工程进度）标注来源与时间；政策类异议标注公告期；话术版本标注生效日期，避免新旧口径混用。
