# sales-lead-grading（判客与跟进 SOP）

案场客户资产经营标准：判客分级 → 登记规范 → 分级跟进 → 掉客挽回 → 复判升级。

## 适用谁
- 置业顾问：客户定级、跟进执行、掉客挽回
- 销售主管/经理：判客仲裁、跟进质检、掉客复盘
- 案场负责人：客户登记与归属纪律

## 怎么用（AI 场景）
1. 输入接待记录 → ABC 分级建议（附原话依据）
2. 输入分级与上次跟进 → 下次触达方式与话题建议
3. 输入跟进台账 → 超期未触达清单与建议动作
4. 输入周期数据 → 跟进质量复盘（触达率/升级率/掉客率）

## 输出纪律
- 分级建议必须引用客户原话或行为事实，不出具"感觉像 A 类"式结论
- 归属争议只输出核查路径，不代案场做仲裁
- 不把本技能与 L1-4 首访接待混用（接待产画像，本技能管分级跟进）

## 什么时候不要用我

这个技能有明确边界，用错场景会得到看似正确但方向相反的结论：

- **接待动线与需求挖掘** → `sales-reception-sop`
- **成交阶段的算价与逼定** → `sales-closing-sop`
- **渠道报备、判客归属与撞单** → `channel-collaboration-sop`
- **客户数据的留存与隐私处理** → 按内部 CRM 与个人信息保护要求执行，本技能只讲分级逻辑

本技能不提供政策数字与法律结论：一律按当地当期公告现查。
