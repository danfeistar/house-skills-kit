# 价格策略与优惠释放 SOP（标准作业程序）· pricing-incentive-release-sop

**一句话**：让价格和优惠成为经过审批、按条件释放、全程留痕的经营工具，而不是顾问临场讨价还价。

**适用角色**：营销负责人、策划、价格委员会/审批人、案场负责人、置业顾问、渠道和财务。

## 使用规则

1. 先确认项目阶段、可售房源、成本与审批口径，再讨论价格策略。
2. 价格、折扣、付款、赠送、团购和认筹权益不得凭空补齐，均以批准版本为准。
3. 每一档优惠必须写清适用对象、有效期、触发条件、审批人和台账编号。
4. 优惠释放是经营动作，不等于虚构稀缺、谎报余量或制造恐慌。
5. 客户未明确表达支付能力、购买条件和决策时点前，不用优惠替代需求判断。

## 核心流程

```text
经营目标 → 房源与客户分层 → 价格信息核验 → 策略方案
→ 审批锁定 → 梯度释放 → 案场执行 → 台账核对
→ 变更同步 → 结果复盘
```

## 二、房源与客户分层

### 房源分层

| 层级 | 典型特征 | 策略关注 |
|---|---|---|
| 主推房源 | 位置、户型或总价符合阶段目标 | 保持价格稳定，强化价值证据 |
| 去化房源 | 去化速度低于阶段目标或存在客观短板 | 优先用付款、产品组合或合规权益改善决策 |
| 稀缺房源 | 真实库存少且有明确销控记录 | 只说明真实可售状态，不夸大稀缺 |
| 风险房源 | 信息、产权、交付或质量口径未完成核验 | 暂停对外释放，先补齐资料 |

### 客户分层

| 客户状态 | 可讨论内容 | 不应越过的边界 |
|---|---|---|
| 了解期 | 价格构成、付款试算、产品差异 | 不用最低价诱导留资 |
| 比较期 | 同类房源、真实优惠条件、决策成本 | 不贬损竞品、不虚构倒计时 |
| 明确意向 | 房源适配、审批范围内的条件 | 不先承诺后补审批 |
| 临门决策 | 已批准的最后可用方案和办理时限 | 不以“今天不定就永远没有”施压 |

## 四、案场执行

### 价格表达顺序

```text
房源事实 → 价格构成 → 付款能力试算 → 产品价值与客观差异
→ 已批准权益 → 客户决策条件 → 记录与下一步
```

建议表达：

> “我先把这套房的房源、单价、总价和付款方式按批准口径算清楚；您确认预算和房源都匹配后，我再核对这套房当前能用的公开权益。超出公开权益的部分需要审批，我不能先替您承诺。”

### 顾问执行检查

- [ ] 使用当前版本价格表，不使用个人旧截图
- [ ] 单价、总价、付款和优惠分栏记录
- [ ] 解释优惠的条件、有效期和是否可叠加
- [ ] 未审批的方案标记为“待确认”，不写成可兑现
- [ ] 客户主动提出价格异议后再进入优惠讨论
- [ ] 客户承诺、审批结果和最终方案均写入台账
- [ ] 同一房源在不同渠道的对外口径一致

## 五、变更与异常

### 变更流程

```text
提出变更 → 说明原因与影响范围 → 审批 → 更新版本号
→ 回收旧版 → 同步案场/渠道/客服/财务 → 抽查执行
```

### 异常处理

| 异常 | 立即动作 |
|---|---|
| 顾问报出旧价格 | 暂停继续传播，核对客户已获信息并由负责人统一纠正 |
| 优惠叠加错误 | 暂停签约前口径，按审批文件重新核算 |
| 客户拿到未审批承诺 | 保留原记录，禁止私自兑现或否认，升级负责人处理 |
| 渠道发布不同价格 | 立即下架/隔离错误版本，完成渠道回收和书面同步 |
| 房源状态与话术不一致 | 以销控和批准口径为准，暂停该房源宣传 |

## 六、台账与复盘

### 最小台账字段

| 字段 | 要求 |
|---|---|
| 客户标识 | 只记录最小必要信息 |
| 房源编号 | 与销控系统一致 |
| 价格版本 | 价格表版本和生效时间 |
| 优惠梯度 | 0/1/2/3及具体权益 |
| 条件与承诺 | 客户已确认的真实条件 |
| 审批信息 | 审批人、时间、编号 |
| 最终结果 | 未成交/认购/签约/待跟进 |
| 异常说明 | 口径偏差、退订或投诉 |

### 复盘指标

| 指标 | 计算方式 |
|---|---|
| 优惠使用率 | 使用该权益的成交/符合条件客户 |
| 梯度转化率 | 进入某梯度后的认购或签约/进入该梯度客户 |
| 单套优惠成本 | 实际优惠总额/对应成交套数 |
| 价格偏差率 | 台账实际成交口径与批准价格差额/批准价格 |
| 口径错误数 | 被发现的错误价格、过期政策或越权承诺次数 |

复盘先看成交质量、现金流和价格纪律，再看“让了多少”。优惠使用率高不代表策略有效，可能只是门槛过低或价格基础失真。

## 合规红线

1. 不得虚构原价、折扣、库存、客户抢购、最后期限或优惠名额。
2. 不得把审批中的价格、规划中的权益、口头承诺或可能获得的优惠写成确定事实。
3. 不得以返现、回购、保本、升值或投资收益承诺替代真实价格说明。
4. 不得未经授权收取认筹金、团购费、服务费或以其他名义变相收费。
5. 不得因客户拒绝购买或未满足条件而擅自修改规则、歧视性报价或制造合同外障碍。
6. 不得泄露客户预算、联系方式、成交价格等非必要个人或交易信息。
7. 发现价格表、销控、合同和对外宣传不一致时，先暂停传播并升级，不得自行“圆口径”。
