# 价格策略与优惠释放 SOP（pricing-incentive-release-sop）

面向营销负责人、案场负责人和置业顾问，规范价格事实核验、房源/客户分层、优惠梯度、审批、执行和复盘。

## AI 使用场景
1. 输入批准价格表、房源清单和活动政策 → 输出价格事实卡与待确认项
2. 输入阶段目标和竞品监控 → 输出策略选项与风险，不直接决定价格
3. 输入已批准权益 → 输出优惠卡片、案场说明和台账字段
4. 输入价格变更 → 输出旧版回收、同步对象和抽查清单
5. 输入成交与优惠台账 → 输出梯度转化、优惠成本和口径偏差复盘

## 输出纪律
- 不补写价格、折扣、库存、付款或截止日期
- 未审批内容明确标记为待确认
- 不生成虚假稀缺、虚构倒计时和保本升值话术
- 最终价格和权益以批准文件、销控和合同为准

## 与其他技能的关系
- 算价与逼定 → sales-closing-sop
- 开盘执行 → sales-opening-sop
- 竞品监控 → competitive-intel-sop
- 活动组织 → activity-organization-sop

## 什么时候不要用我

这个技能有明确边界，用错场景会得到看似正确但方向相反的结论：

- **佣金点位、渠道政策与跳点算法** → `channel-management-advisor` + `calc-toolkit/commission.py`
- **单盘整体经营诊断与去化处方** → `developer-sales-advisor`
- **单个客户的算价与逼定** → `sales-closing-sop`
- **税费、月供、违约金测算** → `calc-toolkit` 的 `tax.py` / `mortgage.py` / `deposit.py`
- **一房一价与备案价的合规口径** → 按当地房价备案与明码标价规定现查

本技能不提供政策数字与法律结论：一律按当地当期公告现查。
