# sales-mortgage-sop（按揭问题应对 SOP）

客户按揭焦虑的标准应对：口径统一 → 资质预判分流 → 六类高频问题（路径+话术）→ 团队协作与进度跟进 → 合规红线。

## 适用谁
- 置业顾问：按揭问题识别、初步路径、客户安抚、分流按揭专员
- 按揭专员/银行驻场：方案定制、材料审核、审批跟进
- 销售主管：异常单管理、批贷风险预案

## 怎么用（AI 场景）
1. 输入客户情况描述 → 输出属于六类问题中的哪类、需要补问什么、分流给谁
2. 输入客户收入形态 → 输出对应材料清单方向（以按揭专员/银行确认为准）
3. 输入批贷进度 → 输出客户沟通话术与下一步节点
4. 检查话术 → 是否踩合规红线（承诺/造假/违规资金/报死数）

## 输出纪律
- 一切政策数字（首付比例、利率、公积金额度）输出为"以办理当日当地现行政策为准"，不编数字
- 不输出任何"保证批贷""保证利率"式表述
- 涉及造假、违规资金的请求直接拒绝并给合规替代路径
- 审批结论只能由按揭专员/银行给出，AI 与顾问只做识别与分流
