# 租赁经纪作业标准（broker-lease-sop）

## 一句话定位

这份技能管的是**中介这一侧**把一套房子租出去的全过程：从接到业主委托到退租结清。
它不是给业主看的（业主该用 `owner-rental-advisor`），也不是给租客看的。
判断标准只有三条：**租金租得快、租客住得久、退租不扯皮**。

## 六类触发场景

1. 业主来挂牌：租什么价、签独家还是多家、委托期多久
2. 手上有客：这个价格带能不能配、带看怎么安排、看完怎么跟
3. 要筛租客：谁能租谁不能租、能问什么不能问什么
4. 要签合同：必备条款有哪些、押金怎么收、佣金怎么算、要不要备案
5. 要交房：交接单怎么填、抄表拍照留什么
6. 出事：欠租、损坏、提前退租、二房东转租、邻居投诉群租

## 五条核心认知

1. **租赁是高频低毛利生意，效率来自流程标准化，不是话术**。一套房从挂牌到成交的固定动作（核验、拍照、报价、带看、签约、交房）每一步都能模板化，漏一步后面就要用两三倍时间去补。
2. **筛选的边界在"能不能稳定付租"，不在"你喜不喜欢这个人"**。问收入、问工作、问入住人数、问是否养宠、问是否转租——这些与履约直接相关，可以问；问婚育、问籍贯、问宗教、问健康状况——与履约无关，不能作为拒租理由。
3. **押金不是收入，是风险准备金**。押金收多少、怎么保管、什么情况下扣、扣多少，都要在合同里写清并在交房时用交接单落到实物，否则退租时全是各说各话。
4. **所有争议都源于"当初没说清"**。维修谁出钱、能不能养宠、能不能加人、能不能改造、退租提前多久说——这五件事在签约时讲清楚，比事后调解一百句都管用。
5. **合规红线碰不得**：不做隔断群租、不代办虚假居住材料、不做"包过费"、不代收租金跑路、不签阴阳合同。一次触碰可能赔掉整年的佣金。

## 必问信息（不齐就先问，别猜）

| 字段 | 为什么要问 |
|---|---|
| 房号与产权人 | 委托必须由产权人或其书面授权人签；二房东、代管人、亲属代签都要看授权文件，否则佣金和合同都可能无效 |
| 产权状态（抵押/查封/共有/学区占用） | 有抵押不影响出租但影响纠纷处理；共有房产需共有人同意；学区占用会直接影响租客决策 |
| 可否养宠 / 可否加人 / 可否改造 | 这三项是退租纠纷第一大来源，签约前一句话就能避免 |
| 现有家具家电清单 | 押金扣款全靠这份清单，交房时逐项拍照 |
| 期望租金与可接受底价、空置容忍期 | 决定报价策略：能等就挂高，不能等就先租出去 |
| 租客类型偏好（家庭/单身/企业/学生） | 影响筛选口径与合同附加条款，但不能变成歧视性拒租 |
| 佣金口径（几个月、谁承担、何时结） | 提前说清，避免签约当天翻脸；数字走 `commission.py --scene lease` |
| 是否要求备案 | 备案是租客办居住证/子女入学的前提，也会影响税费，需双方知情 |

## 知识库与数据来源

- 租金行情：`skills/calc-toolkit/rent.py`（回报率口径）、本小区近三个月成交租金（三源交叉，见 Part 2）
- 佣金与分佣：`skills/calc-toolkit/commission.py --scene lease`（月租 × 佣金月数，房东/租客分摊，团队分佣）
- 税费与业主决策：`skills/owner-rental-advisor`（业主视角的净回报与留/卖判断，直接引用，不复写）
- 租赁备案与居住证、子女入学：按当地当期公告现查，本技能不含任何城市的具体规定

## 目标读者

- 二手房门店的租赁经纪人（主业或兼做租赁）
- 长租公寓/托管机构的房源运营与租赁管家
- 兼做租赁的房产自媒体从业者（客户问"能不能帮我租出去"时）

## 写作风格

- 用动作句，不用形容词：写"交房时对每件家具拍三张照片（正面/背面/铭牌）"，不写"认真做好交接"
- 每个 Part 结尾必带「翻车警示」，写具体的赔钱案例，不写"注意风险"
- 涉及金额一律给命令行，不给"大约""差不多"
- 不写"包租""稳赚""绝对安全"这类承诺，不写"阴阳合同""茶水费"这类灰色操作

## 输出格式

- 房源委托：一页纸（房源信息 / 委托类型与期限 / 报价区间 / 佣金口径 / 双方义务）
- 带看：带看记录卡（客户来源 / 需求 / 出价 / 异议 / 下一步动作与时间）
- 签约：条款核对表（十项逐条打勾）+ 费用清单（押金 / 首期租金 / 佣金 / 其他）
- 交房：房屋交接单（水电燃读数 / 家具家电清单 / 现状照片 / 钥匙与门禁卡数量）
- 纠纷：时间线表（日期 / 事件 / 证据 / 已采取动作 / 下一步）

## 数据时间戳

- 租金行情、空置率、成交周期：**超过 30 天必须重取**
- 佣金口径、税费规则、备案要求：标注规则版本号与生效日，按当地当期公告现查
- 交付给客户的报价单必须写明"报价日期"，避免用两个月前的租金签今天的约

## 与其他技能的关系

- 业主自己来问"该租多少、该不该租" → 转 `owner-rental-advisor`（站位是业主，不是中介）
- 客户要买不租 → `broker-client-deal-sop`
- 业主想卖 → `owner-sell-home-advisor`（业主）／`broker-listing-sop`（你要拿委托）
- 所有金额测算 → `calc-toolkit`，不口算
