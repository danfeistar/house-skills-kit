# 租赁经纪作业标准（broker-lease-sop）

中介这一侧把一套房子租出去的全过程：委托核验 → 报价带看 → 筛租客 → 签约收费 → 交房留痕 → 履约退租 → 纠纷风控。判断标准只有三条：租得快、住得久、退租不扯皮。

## 适用谁
- 二手房门店的租赁经纪人（主业或兼做租赁）
- 长租公寓 / 托管机构的房源运营与租赁管家
- 兼做租赁的房产自媒体（客户问"能不能帮我租出去"时）

## 怎么用（AI 场景）
1. "业主来挂牌，我该先核什么" → Part 1 六项核验 + 委托条款七项
2. "这套房挂多少合适" → Part 2 三源锚点 + 挂牌-成交价差 + 空置换算（跑 `rent.py` 给业主看回报）
3. "这个客户能不能租给他" → Part 3 合法问什么/不能问什么 + 收入租金比 + 四种骗局识别
4. "合同要写哪些条款、押金怎么收" → Part 4 十项必备条款 + 首日现金结构（佣金走 `commission.py --scene lease`）
5. "交房要留什么证据" → Part 5 交接单五件套 + 当天六个动作
6. "欠租 / 提前退租 / 二房东转租怎么办" → Part 7 欠租四步 + 四类高风险情形处置
7. "客户跳单了佣金还能要回吗" → Part 7.3 客户保护期与证据链

## 输出纪律
- 金额一律给命令：租金回报 `rent.py --net`；租赁佣金 `commission.py --scene lease`（月租×佣金月数，房东/租客分摊，`--splits` 团队分佣）；业主留卖判断 `buy_vs_invest.py`
- **单位纪律**：`commission.py` 的费率与分摊比例用**小数**（0.5 = 一半）；`rent.py` 的 `--vacancy` / `--tax-rate` / `--maint` 用**百分数**（15 = 15%），混用差 100 倍
- 交给客户的报价单必须写"报价日期"；租金行情、空置率**超过 30 天必须重取**
- 备案、居住证、子女入学按当地当期公告现查，本技能不含任何城市具体规定
- 交付物用模板：委托一页纸 / 带看记录卡 / 条款核对表 / 交接单 / 纠纷时间线表

## 什么时候不要用我
这个技能有明确边界，用错场景会得到看似正确但方向相反的结论：

- **业主自己在问"该租多少、该留还是该卖"** → `owner-rental-advisor`（站位是业主，中介视角会把它导向"怎么说服业主降价"）
- **客户要买不租** → `broker-client-deal-sop`
- **你要拿的是售房委托** → `broker-listing-sop`（卖房委托的独家条款、价格校准与防跳单逻辑不同）
- **业主要卖房** → `owner-sell-home-advisor`
- **涉及租约诉讼、清退执行、押金判例** → 律师；本技能只给作业流程与留痕要求

本技能不提供政策数字与法律结论：一律按当地当期公告现查。
