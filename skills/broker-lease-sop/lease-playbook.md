# 租赁经纪作业手册（lease-playbook）

> 中介侧七步全流程。每一步都给"做什么 / 怎么做 / 怎么留痕"，金额一律给可复制的命令。
> 业主视角请用 `owner-rental-advisor`，本手册不重复业主决策逻辑。

---

# Part 1 房源获取与委托

## 1.1 接委托前必须核的六项

| 核什么 | 怎么核 | 核不到怎么办 |
|---|---|---|
| 产权人身份 | 身份证 + 不动产权证（或购房合同+备案）姓名一致 | 不一致时必须有书面授权委托书，且注明租金收取权 |
| 抵押 / 查封状态 | 不动产权证附记页、业主手机端查询、当地不动产登记中心 | 有抵押可租但要写清纠纷处理；有查封**不能接** |
| 共有人 | 结婚证/户口本、房产证共有栏 | 共有房产需全部共有人签字或书面同意 |
| 二房东身份 | 原租约 + 产权人书面同意转租条款 | 拿不到书面同意不做（后续可能被清退，佣金也追不回来） |
| 房屋现状 | 现场看：隔断、群租、改建、消防通道 | 有违规隔断的不接，除非业主先整改 |
| 欠费与户口/学位占用 | 水电燃物业缴费记录、学区占用情况 | 欠费要在委托书里写清由业主结清；学区占用必须如实告知租客 |

## 1.2 委托类型三选一

| 类型 | 对价 | 适合谁 | 风险 |
|---|---|---|---|
| 一般委托（多家挂牌） | 谁成交谁拿佣金 | 空置容忍期长、想抬价的业主 | 同质竞争，容易被同行用"低佣金"截客 |
| 独家委托（期限内只你一家） | 换取更集中的带看与更强的议价推动 | 想快租、房子有硬伤需要包装 | 委托期内租不掉，业主会怪你；到期务必书面确认结束 |
| 转租权/包租（你承租再转租） | 赚差价 | 有稳定客源的门店 | **本质是二房东，压租风险与合规风险全在你身上，非专业机构不要碰** |

## 1.3 委托条款七项（缺一项就别签）

1. 委托期限（起止日）与到期后的处理（自动终止 / 需书面续签）
2. 委托租金区间与可接受底价，以及"低于底价需业主书面确认"的机制
3. 佣金口径：几个月租金 / 谁承担 / 何时结（签约日、交房日、还是首期租金到账日）
4. 业主配合义务：带看时间窗、钥匙交付方式、维修响应时限
5. 房屋现状清单与设备维修责任（自然损耗 vs 人为损坏）
6. 独家条款（如为独家）：委托期内业主私下成交仍需付佣的约定
7. 提前解约与违约条款（双方都可以退出的路径）

**翻车警示**
- ❌ 只看身份证不看房产证 → 租到"二房东转租"的房，真业主上门收房，租客找你退钱，佣金一分拿不到
- ❌ 独家委托没写到期日 → 一年后业主换了中介，你还以为自己有独家，白等三个月
- ❌ 佣金"成交后再说" → 签约当天业主翻脸只给半个月，你没依据

# Part 2 报价与带看

## 2.1 报价：三源锚点 + 一条反向校验

| 源 | 取什么 | 权重 |
|---|---|---|
| 同小区近 90 天**实际成交**租金（不是挂牌） | 同户型、同楼层段、同装修档 | 50% |
| 同小区**在挂**房源 | 看竞争面与挂牌-成交价差 | 30% |
| 相邻可比小区成交 | 补样本量，校片区差 | 20% |

反向校验：用 `rent.py` 反推业主的回报底线，判断这个租金业主能不能接受。

```bash
python3 skills/calc-toolkit/rent.py --price 1500000 --rent 3500 --net
```

实测读数（150 万房 / 月租 3500）：毛回报 2.80%、净回报 1.76%、净年收益 26,415 元、回收 56.8 年、租售比 1:429。
把这张表给业主看，比说"这个价市场就这样"有用得多——业主真正关心的是"我这笔资产在赚多少"。

## 2.2 挂牌-成交价差：先定"挂多少、让多少"

经验做法：挂牌价 = 目标成交价 ×（1 + 议价空间），议价空间按空置容忍期定：

- 空置容忍 ≤ 30 天：挂牌价贴成交价（+0~3%），求快
- 空置容忍 31~60 天：+3~6%，留出让价空间
- 空置容忍 > 60 天：+5~8%，但要接受带看量下降

**空置与降租的换算**（这一条最容易被业主忽略）：
空置 1 个月 = 直接损失 1 个月租金 = 3,500 元；改为降租 100 元/月的方案，需要 **35 个月**才能补回这一个月空置。所以"再等一个月看能不能租高价"这件事，对业主是负期望——除非他明确愿意为价格等待。

## 2.3 带看：动线、话术、留痕

- 动线：先看入户与公共区域（决定第一印象）→ 采光最好的空间（客厅/主卧）→ 厨房卫生间（最容易掉分）→ 收纳与家具
- 必答三问（提前准备答案）：能不能养宠 / 能不能加人同住 / 什么时候能入住
- 留痕：带看记录卡（客户来源、需求、出价、异议、下一步与时间），当天回填
- 安全边界：单独带看异性客户时告知同事行程；不进客户车辆；夜间带看两人同行

**翻车警示**
- ❌ 用挂牌价当成交价报给业主 → 业主按虚高价格挂 30 天零带看，最后被迫降价，你被换掉
- ❌ 带看不记录 → 一周后来问"那个看房的人呢"，你只剩"好像挺满意"这种回答
- ❌ 口头承诺"可以养宠" → 业主合同禁止，签约当天崩，客户和业主一起失

# Part 3 租客筛选与合规

## 3.1 合法问什么、不能问什么

| 可以问（与履约直接相关） | 不能作为拒租理由（与履约无关） |
|---|---|
| 月收入 / 收入来源稳定性 | 婚育状况、是否怀孕 |
| 工作单位与在职时长 | 籍贯、民族、宗教 |
| 入住人数与关系 | 年龄（除法律另有规定）、健康状况、残障 |
| 是否养宠、是否吸烟 | 性别（合租单间招租场景需符合当地规定） |
| 是否接受转租限制条款 | 政治面貌、既往病史 |
| 是否需要办理居住证/备案、是否有子女入学需求 | 婚恋状态 |

判断口径：**问的每一句都要能回答"这和他能不能按时交租、会不会损坏房子有什么关系"**。回答不了的问题就不问。

## 3.2 收入与稳定性校验

- 收入租金比：月收入 ≥ 月租 × 3（保守者可到 × 3.5）
- 稳定性佐证：近 3~6 个月工资流水或社保缴纳记录、劳动合同在职时长
- 自由职业/个体：近 6 个月银行流水 + 经营主体证明
- 学生/刚毕业：需共同签约人或担保人（父母共签最常用）
- 不接受任何以"我很有钱"为理由的免验证；也不接受押金多给以替代资质核验（押金再多也不解决持续付租）

## 3.3 企业租客与"代租"

- 企业名义签约：营业执照 + 法定代表人身份证明 + 授权经办人委托书；发票与税费口径提前说清
- 员工宿舍式入住：合同写明居住人数上限与更换人员报备机制
- **代租警惕**：任何"我帮朋友租，钱我付，合同写他的名字，钥匙我拿"的组合都要拒；实际居住人与签约人不一致是欠租与转租的高发前兆

## 3.4 四种常见骗局与识别

| 骗局 | 特征 | 防法 |
|---|---|---|
| 假客户骗钥匙 | 不看房只急着要钥匙、愿付定金但要"先拿钥匙" | 钥匙不外借；定金走对公或转账留痕 |
| 代办居住材料收费 | 客户要求你"帮忙搞定居住证/入学"，愿意加钱 | 一律不作代办，指引其按当地公安/教育部门流程自行办理 |
| 假房源套客 | 同行用低价假房源钓客，再转介真房源 | 不参与；自己的房源必须真实可看，价格标注日期 |
| 收租跑路（二房东模式） | 中间人以"包租"名义代收租金 | 非机构主体不做代收；代收必须进三方共管或业主账户 |

**翻车警示**
- ❌ 因"感觉这人不靠谱"拒租但说不出履约理由 → 涉嫌歧视，业主与客户都可能投诉
- ❌ 收客户"预定金"却不出收据、不留书面说明 → 反悔时被要求双倍返还且无法举证
- ❌ 帮客户"操作"居住材料 → 一旦被查，经纪人执业资格与门店资质都受牵连

# Part 4 签约与费用

## 4.1 十项必备条款（逐条核对，缺一条不签）

1. 租赁期限（起止日）与免租期（如有装修/搬入期）
2. 租金金额、支付周期、支付日、支付方式与逾期违约金（比例+计算方式）
3. 押金金额、保管方式、退还条件与退还时限（建议退房后 7 日内）
4. 费用承担：水/电/燃气/供暖/物业/宽带/垃圾清运的归属与结算方式
5. 维修责任划分：自然损耗（业主）与人为损坏（租客）、报修渠道与响应时限
6. 使用限制：可否养宠、可否加人同住、可否改造装修、可否转租/分租
7. 提前解约条款：通知期（建议 30 天）、违约金口径、剩余租金与押金处理
8. 房屋现状与家具家电清单（作为附件，与交接单一致）
9. 退租验收标准与交接流程（含清洁标准、钥匙归还）
10. 争议解决方式与送达地址（送达地址很关键，涉及解约通知是否有效）

## 4.2 押金与首付的现金结构

押金不是收入，是风险准备金。常见结构：押一付三、押一付一。
租客真实现金支出 = 押金 + 首期租金 + 佣金（租客承担部分）。

```bash
python3 skills/calc-toolkit/commission.py --scene lease --rent 3500 --months 1 --landlord-share 0.5
```

实测：月租 3,500 元、佣金 1 个月、双方各半 → 佣金合计 3,500 元，房东承担 1,750 元、租客承担 1,750 元，相当月租的 1.00 倍、占年租金 8.3%。

于是押一付三场景下租客首日现金 = 3,500（押金）+ 10,500（三个月租金）+ 1,750（佣金）= **15,750 元**。报价时先把这个数说清，客户不会在签约当天临时退出。

佣金 1.5 个月时（部分城市/部分机构做法）：

```bash
python3 skills/calc-toolkit/commission.py --scene lease --rent 3500 --months 1.5 --landlord-share 1
```

实测：佣金合计 5,250 元、占年租金 12.5%，且工具会提示"佣金超过 1 个月租金时，租客首付=押金+首期租金+佣金，报价前先说清"。

## 4.3 备案与票据

- 租赁备案：影响租客办居住证、子女入学，也影响业主税费口径；双方是否配合要在合同写明
- 发票：企业租客多数要票，税费由谁承担提前谈定，不要等到结佣时才发现要倒贴
- 佣金票据：门店应开居间服务费票据，避免"只给收据"的纠纷

**翻车警示**
- ❌ 合同只写"押一付三"不写逾期违约金计算方式 → 欠租时无从主张，只能干等
- ❌ 家具家电清单不写进附件 → 退租时"这个冰箱本来就有划痕"变成无解争论
- ❌ 不写送达地址 → 解约通知发不出去，法律上视为未通知，只能继续履行

# Part 5 交房与入住

## 5.1 交接单五件套

1. **水电燃气读数**：逐表拍照（表盘数字清晰可读），并与上月账单对得上
2. **家具家电清单**：逐件三张照片（正面 / 背面或侧面 / 铭牌或序列号）
3. **现状记录**：墙面、地面、门窗、卫浴、厨具的既有瑕疵，逐处标注位置并拍照
4. **钥匙与门禁**：数量、是否可复制、门禁卡张数、智能锁密码重置方式
5. **双方签字**：业主、租客、经纪人三方各存一份（电子版同步发送）

## 5.2 交房当天的六个动作

- 通电通水通燃气实测（热水器、空调、燃气灶逐一点火/开机）
- 网络与有线电视是否可用，路由器归属说清
- 物业费缴纳状态与门禁/车位权限开通
- 明确报修渠道（谁接单、多久响应、紧急情况电话）
- 提示租客：入住 7 日内提交一次全面问题清单，逾期视为验收通过
- 提醒租客留存交接单与付款凭证（退租时的唯一依据）

**翻车警示**
- ❌ 交接单不拍照只写"完好" → 退租时无法证明损坏是租客造成的，押金扣不动
- ❌ 不测热水器与空调 → 入住第三天报修，业主说"交给你时是好的"，双方各执一词
- ❌ 钥匙数量不写 → 租客私配钥匙、退租不交回，业主换锁费用算谁的又一场争议

# Part 6 履约期服务与退租

## 6.1 报修：三档响应

| 档 | 例子 | 响应时限（建议写进合同） |
|---|---|---|
| 紧急 | 漏水、断电、燃气泄漏、门锁失效 | 2 小时内响应，当天处理 |
| 重要 | 热水器/空调/冰箱故障 | 24 小时内上门 |
| 一般 | 灯具、五金、渗水痕迹 | 72 小时内安排 |

报修一律留痕：谁报的、什么现象、照片、上门时间、处理结果、费用归属。

## 6.2 续租

- 到期前 **45 天**启动续租沟通（太晚租客已找好新房）
- 续租条件优先在原合同框架内谈；调价要给出参照（周边成交租金 + 报价日期）
- 续租必须重签或签补充协议，**不要口头续租**——口头续租在纠纷中等于无固定期限租赁

## 6.3 退租四步

1. **提前通知**：按合同通知期（通常 30 天）书面提出，确认退租日期
2. **预约验收**：退租日前 1~3 天现场验收，带原交接单逐项对照
3. **费用结算**：水电燃气物业结清、损坏赔偿（有据可依的部分）、违约金（如提前解约）
4. **押金退还**：扣除项逐条列出并附照片与单据，余款在约定时限（建议 7 日）内退还，退还需留转账凭证

## 6.4 提前解约的三种口径

- 租客违约：按合同违约金（常见 1 个月租金）+ 已发生的实际损失；押金可抵，但须列明
- 业主违约（如卖房清退、自住收回）：赔偿租客搬家和差价损失，通常按月租 1 个月以上协商
- 双方协商一致：签书面解除协议，写清搬离日期、费用结清、押金退还

**翻车警示**
- ❌ 退租只口头结算不清点 → 一个月后租客回来说"少退我 800"，你没有任何凭据
- ❌ 押金扣款不给照片与单据 → 客户投诉到平台，扣款大概率被全额退回
- ❌ 口头续租后业主想涨价 → 既涨不了也赶不走，只能等下一个租期

# Part 7 纠纷与风控

## 7.1 欠租四步（先礼后兵，全程留痕）

1. **D+1 提醒**：微信/短信+电话，留截图与通话记录
2. **D+7 书面催告**：发书面催告函（寄送到合同约定送达地址），写明金额、期限、逾期后果
3. **D+15 协商方案**：给分期或延期方案，形成书面确认；同时告知业主进展
4. **D+30 依法解约**：按合同条款解除、清退，必要时走诉讼/仲裁；**全程不得自行断水断电、换锁、清理物品**

## 7.2 四类高风险情形

| 情形 | 识别 | 处置 |
|---|---|---|
| 二房东转租 | 实际居住人不是签约人、频繁换人 | 立即核实并书面通知整改；向业主报告并协同处理 |
| 群租/隔断 | 人均面积过小、床位出租、消防通道占用 | 停止续约、书面整改通知；业主不配合则按当地规定报告 |
| 短租/日租（公寓改民宿） | 频繁换客、要求按天结算 | 需符合当地规定与小区规约，未经许可不做 |
| 房屋被用于经营/仓储 | 大量货物、频繁货车、挂牌经营 | 核实是否违反合同使用条款，必要时解约 |

## 7.3 佣金的安全线

- **客户保护期**：委托书里写明保护期（如成交后 90 天内同一客户成交仍计佣）与客户确认方式（书面/系统报备）
- **结佣条件**：签约日 / 交房日 / 首期租金到账日，三选一写清，不写"尽快"
- **佣金追讨**：先书面催告 → 出示委托书与带看记录 → 必要时小额诉讼；所有带看记录就是你的证据链

## 7.4 经纪人的自我保护

- 不代收租金与押金（除三方共管或业主书面授权并单独设账）
- 不承诺"包租""包找租客到满意为止"
- 不在微信里替业主/租客做超出合同的承诺，所有变更回到书面
- 单独作业留行程报备，尤其夜间带看与陌生房源

**翻车警示**
- ❌ 欠租直接断水断电 → 从有理变无理，赔偿金额可能超过欠租本身
- ❌ 没有带看记录 → 客户跳单时无法证明你提供了服务，佣金要不回来
- ❌ 代收租金进个人账户 → 一旦被认定为挪用，执业资格与信用记录一起受损

```bash
# 租金回报（给业主看的口径）

```
