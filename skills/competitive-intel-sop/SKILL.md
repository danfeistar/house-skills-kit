# 竞品踩盘与市场监控 · competitive-intel-sop

**一句话**：把"踩盘"从逛马路变成情报生产线——分级名单 → 现场六模块采集 → 百分制打分 → 四指标周监控 → 月度报告 → 情报分发到各条线。

**适用角色**：策划（踩盘组织与月报主笔）、营销负责人（分级与权重拍板、报告审发）、置业顾问/踩盘执行人（现场采集）、市调/ data 岗（周数据监控）

**触发场景**：
- 新项目定位期或蓄客期，需要建立竞品名单与踩盘排期
- 竞品开盘、加推、调价等触发事件，需要 48 小时内动态踩盘
- 月度竞品与市场报告编写
- 周度供应/成交/去化/价格四指标监控
- 案场反踩盘管理与口径检查

## 核心认知

1. **踩盘不是逛盘**：带采集清单进场，出案场 30 分钟内落笔——没有记录的踩盘等于没踩。
2. **竞品情报是快过期品**：价格、优惠、销控按周变化，所有数据必须标注采集日期。
3. **预判比记录值钱**：打分表固定收尾一栏"如果我是他操盘手，下个月我会做什么"——竞品预判是我方排期的输入。
4. **踩盘是双向的**：反踩盘纪律（Part 7.2）与踩盘动作同等重要，销控/价格/话术/台账四个部位防采集。
5. **红线先于情报**：不冒充身份、不窃取商业秘密、不诋毁竞品——宁可拿不到情报也不碰红线。

## 结构

详见 `competitive-playbook.md`：
- **Part 1 踩盘的本质与纪律**：三个认知、例行/事件触发/周监控三类频次
- **Part 2 踩盘前准备**：竞品 A/B/C 分级标准、踩盘工具包与双人分工
- **Part 3 现场踩盘清单**：六模块采集（区位价值/展示面/销售力/价格优惠/销控去化/服务细节）+ 30 分钟落笔纪律
- **Part 4 竞品打分表**：百分制六维权重评分卡、打分纪律、竞品预判栏
- **Part 5 市场监控机制**：供应/成交/去化/价格周报四指标、三源交叉验证、土地/政策/客户月度补充
- **Part 6 月度竞品报告模板**：六段式结构、每月 {{5}} 日前出报
- **Part 7 情报应用与反踩盘**：情报去向分发表（话术/价格/物料/培训/排期）、反踩盘五部位纪律
- **Part 8 红线**：不冒充/不窃取/不诋毁/不造假/个人信息/报告保密，一票否决

每 Part 格式：**规则 → 动作 → 标准 → 翻车警示**

## 合规红线（速览，详见 Part 8）

1. 以真实身份到访踩盘，不冒充第三方身份套取非公开信息。
2. 只采集公开层面信息，不拿内部文件、不翻台账、不拍"内部资料"区域。
3. 竞品抗性只用于我方话术准备，不对外发布诋毁性表述，过广告法。
4. 踩盘数据必须真实，不为报告好看修改数据；月报限项目组内部流转。

## 与其他技能的关系

- 竞品对比话术怎么对客户说 → L1 话术库·竞品域（本文只采不写）
- 价格与优惠释放节奏 → L2-6；展示面与物料改进 → L2-4
- 蓄客排期与开盘方案受竞品预判输入 → L2-1 / L2-7
- 案场接待与判客口径、销控三岗台账 → L1-4 / L1-5 / L1-7
