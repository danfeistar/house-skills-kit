# 竞品踩盘与市场监控（competitive-intel-sop）

把竞品踩盘组织成一条情报生产线：分级名单 → 六模块现场采集 → 百分制打分 → 四指标周监控 → 月度报告 → 情报分发。目的是让"竞品在干什么"变成可比较的数据，而不是踩完盘回来的一堆形容词。

## 适用谁
- 策划、市调岗：维护竞品名单、按期出周监控与月度竞品报告
- 营销负责人：判断竞品动作对我方来访与价格的实际影响
- 置业顾问：应对客户"隔壁盘更便宜/送得更多"这类对比问题

## 怎么用（AI 场景）
1. "这个月竞品报告怎么写" → 六模块采集清单 + 百分制打分表 + 月度报告模板
2. "竞品出特价了，我们要不要跟" → 四指标周监控（供应/成交/去化/价格三源交叉）→ 判断是战术动作还是系统性降价
3. "客户说隔壁送车位" → 用采集到的价格与优惠结构做同口径对比，不靠印象
4. "哪些竞品要每周看、哪些每月看" → A/B/C 分级与踩盘频次
5. "踩盘被认出来怎么办" → 反踩盘纪律与合规红线

## 输出纪律
- 三源交叉：现场采集、公开平台数据、成交口径（中介/渠道反馈）三处对齐；对不上的数字标"存疑"，不取平均掩盖
- 打分表必须带权重与打分依据，不给"感觉不错"这种结论
- 竞品数据标注采集日期与来源；**价格类数据超过 30 天必须重取**
- 政策与市场统计口径按当地当期公告现查，本技能不含任何城市的具体数字

## 什么时候不要用我
- **要制定价格策略与优惠释放节奏** → 用 `pricing-incentive-release-sop`
- **要做单盘整体经营诊断（量价客竞队五维）** → 用 `developer-sales-advisor`
- **要把结论做成对外宣传物料** → 用 `marketing-materials-sop`，并走合规审核；竞品对比不得用于贬低对手
- **需要真实成交数据源** → 数据采集与授权合规不在本技能范围内，按合法渠道取数
- **要判断渠道动作对来访的影响** → 用 `channel-management-advisor` 的来访结构与渠道产能部分

本技能不提供政策数字与法律结论：一律按当地当期公告现查。
