# 竞品踩盘与市场监控 正文

> 本文管竞品情报的采集、打分与月度输出；竞品对比**话术**（怎么对客户说）归 L1 话术库·竞品域，不在此重复。
> 全文目标数字、费用、周期一律 `{{}}` 占位，按项目实际定。
> 红线（Part 8）优先级高于本文任何动作：踩盘手段与红线冲突，宁可拿不到情报也不碰红线。

---

## Part 1 踩盘的本质与纪律

### 1.1 三个认知

1. **踩盘不是逛盘**：带着采集任务清单进案场，每个动线节点都在采集，出来 30 分钟内落笔成档——没有记录的踩盘等于没踩。
2. **竞品情报是快过期品**：价格、优惠、销控每周都在变，踩盘信息的有效期按周计—— monthly report 里必须标注每个数据的采集日期。
3. **踩盘是双向的**：你在踩别人，别人也在踩你。Part 7 的反踩盘纪律与踩盘动作同等重要。

### 1.2 频次与触发

| 类型 | 频次 | 覆盖范围 |
|------|------|---------|
| 例行踩盘 | 每月 {{1}} 次/竞品 | 核心竞品逐月轮动，每季度全覆盖 {{1}} 轮 |
| 事件触发踩盘 | 48 小时内 | 竞品开盘/加推/大幅调价/示范区开放/换操盘团队 |
| 市场数据监控 | 每周 | 供应、成交、去化、价格四指标（Part 5） |

**翻车警示**：
- ❌ 只在销量下滑时才踩盘——等到有感觉再踩，竞品动作已经生效 {{2-4}} 周
- ❌ 踩盘记录留在踩盘人脑子里或手机相册里——情报不上台账，等于全组没踩

## Part 2 踩盘前准备

### 2.1 竞品名单分级（每季度复核一次）

| 分级 | 定义 | 数量 | 监控深度 |
|------|------|------|---------|
| A 级 | 同区域、同客群、同总价段，直接分流 | {{3-5}} 个 | 全要素踩盘+每周销控跟踪 |
| B 级 | 同区域或同客群，部分重叠 | {{5-8}} 个 | 季度踩盘+月度数据跟踪 |
| C 级 | 城市级标杆/话题盘 | {{2-3}} 个 | 半年踩盘，学亮点用 |

分级标准一句话：**客户从他家出来会不会拐弯来我这里**——会拐的全是 A 级。

### 2.2 踩盘工具包

- 《踩盘采集清单》（Part 3 全表，打印或平板带场）
- 《竞品打分表》空白份（Part 4）
- 角色设定：以真实身份正常到访（见 Part 8 红线），不扮装修公司、不扮同行压价套话
- 分工：{{2}} 人一组，一人主聊（问销售），一人侧记（看动线、看客群、看销控板）

## Part 3 现场踩盘清单（六模块采集）

### 3.1 区位与价值主张

| 采集点 | 要拿到的信息 |
|--------|-------------|
| 主打价值 | 沙盘讲解前 3 分钟的主推卖点（区域/学区/产品/品牌哪张牌） |
| 抗性处理 | 对明显短板（临高铁/高压线/距离市中心）怎么讲 |
| 客群画像 | 销售口中的"我们客户主要是……"（职业/来源区域/购房目的） |

### 3.2 展示面

| 采集点 | 要拿到的信息 |
|--------|-------------|
| 示范区 | 景观实景/样板间数量与装修标准、维护状态（新/旧/破损） |
| 销售物料 | 楼书/户型单页/价格单是否齐全，拿一套走 |
| 包装主题 | 当前主推的节点包装（节日/加推/清盘） |

### 3.3 销售力（最重要的模块）

| 采集点 | 要拿到的信息 |
|--------|-------------|
| 接待流程 | 沙盘→样板间→洽谈的动线与时长，有没有算价环节 |
| 话术质量 | 逼定力度、竞品打击话术（重点：他怎么说我这类项目）、按揭口径 |
| 团队状态 | 在场销售人数、接待饱满度、工装统一度、展业资格公示 |
| 逼定手段 | 当日优惠/房源紧张话术/时间节点，记原话 |

### 3.4 价格与优惠

| 采集点 | 要拿到的信息 |
|--------|-------------|
| 表价与实收 | 询问意向户型的一房一价，实收折扣口径 |
| 优惠结构 | 当日优惠/按时签约优惠/一次性付款优惠/老带新优惠，各几个点 |
| 特价与工抵 | 有无特价房/工抵房/清盘房源，价格与表价差 |

### 3.5 销控与去化

| 采集点 | 要拿到的信息 |
|--------|-------------|
| 推售结构 | 在推楼栋/户型/面积段，货量结构 |
| 销控板 | 公示的认购/签约状态（拍照存档，判断真实去化） |
| 去化话术 | "卖了多少"的销售口径 vs 销控板实况 vs 网签数据（Part 5 交叉验证） |

### 3.6 服务与细节

| 采集点 | 要拿到的信息 |
|--------|-------------|
| 物业与安保 | 门岗/停车场/水吧服务规格 |
| 客户动线细节 | 儿童区/洗手间/休息区配置（学区客群项目尤其看） |
| 情报残留 | 有无我项目的踩盘痕迹对比可学之处（竞品做得好的，直接抄） |

**落笔纪律**：出案场 30 分钟内，两人合写《踩盘记录单》（每个模块 3-5 条要点+照片归档），当天入台账。

## Part 4 竞品打分表

### 4.1 评分卡（百分制）

| 维度 | 权重 | 评分要点 | 得分 |
|------|------|---------|------|
| 区位与配套 | {{20}} | 地段能级/交通/学区/商业兑现度 | |
| 产品力 | {{20}} | 户型/得房率/装标/楼栋布局 | |
| 展示面 | {{15}} | 示范区品质/维护/样板间感染力 | |
| 价格性价比 | {{15}} | 实收价 vs 产品力的相对位置 | |
| 销售力 | {{15}} | 团队状态/话术质量/逼定体系 | |
| 品牌与物业 | {{10}} | 开发商口碑/已交付呈现/物业规格 | |
| 去化动能 | {{5}} | 销控板真实去化速度 | |

### 4.2 打分纪律

- 权重按项目竞争策略定（拼产品就把产品力调到 {{25-30}}），权重变更由营销负责人拍板
- 每次踩盘重打分，打分变化 ≥ {{5}} 分的维度必须写原因
- 打分表尾部固定一栏："**如果我是他操盘手，下个月我会做什么**"——竞品预判比竞品记录值钱

**翻车警示**：
- ❌ 全维度打高分/低分——打分失去区分度，等于没打；优秀的维度敢于打 {{90+}}，差的不怕打 {{60-}}
- ❌ 只打分不预判——竞品下个月的动作才是我方排期的输入

## Part 5 市场监控机制（周报四指标）

### 5.1 每周固定采集

| 指标 | 口径 | 主要来源 | 用途 |
|------|------|---------|------|
| 供应 | 新取证/新开盘货量 | 当地住建/房管局公示网 | 判断竞品推盘节奏 |
| 成交 | 网签套数/面积 | 当地网签备案系统公示 | 判断真实市场温度 |
| 去化 | 竞品去化率 | 销控板+踩盘+网签三源交叉 | 修正销售口径水分 |
| 价格 | 成交均价（非表价） | 网签数据+踩盘实收 | 识别变相降价 |

**三源交叉法**：销售口径去化 × 销控板实况 × 网签数据，三者差值大的项目标记"口径存疑"，报告里注明。

### 5.2 城市面月度补充

- 土地市场：区域成交地块的楼面价与竞得人（预判 {{12-18}} 个月后新竞品）
- 政策面：限购/限贷/公积金/补贴类政策的当地执行细则变化（引用时标注"以办理当日当地现行政策为准"）
- 客户面：案场来访结构变化（哪个竞品分流来的多了/少了，反推竞品动作效果）

## Part 6 月度竞品报告模板

```
《{{项目名}} 竞品与市场月报（{{年月}}）》
1. 本月市场大盘：供应/成交/均价三行结论 + 环比一句话
2. A级竞品动态：每家 5 行内——动作/价格/去化/我方应对
3. 打分表变化：分数变动 ≥5 分的维度与原因
4. 竞品预判：各家下月可能动作（每家 1 条）
5. 我方建议：价格/推盘/展示面/话术 四选一到二，每条给依据
6. 数据附录：踩盘记录单编号、采集日期、采集人
```

- 报告由策划主笔，营销负责人审后发；每月 {{5}} 日前出上月报
- 报告里的竞品价格与去化一律标注采集日期；引用网签数据注明数据源

## Part 7 情报应用与反踩盘

### 7.1 情报去向（谁用怎么用）

| 情报 | 去向 |
|------|------|
| 竞品打击话术/我方应对话术 | L1 话术库·竞品域（本文只采不写） |
| 价格与优惠情报 | L2-6 价格策略（优惠释放节奏的输入） |
| 展示面亮点 | 物料与示范区改进清单（L2-4 联动） |
| 销售力差距 | 案场培训选题（L4 联动） |
| 竞品预判 | 蓄客/开盘排期调整（L2-1/L2-7 输入） |

### 7.2 反踩盘纪律（我方防采集）

| 部位 | 纪律 |
|------|------|
| 销控板 | 真实销控不入公开展示区；对外口径与销控三岗台账（L1-7）一致 |
| 价格 | 一房一价表不主动示客，算价环节在洽谈区完成 |
| 话术 | 全员统一口径（L1 系），不给竞品踩盘人留"团队话术混乱"把柄 |
| 台账 | 客户登记信息、认筹数据不外传；发现异常到访（长时逗留/高频拍照）通知案场负责人 |
| 识别 | 对"问得太专业"的到访者保持标准接待——信息给到公开层面为止 |

## Part 8 红线（一票否决）

| # | 红线 | 说明 |
|---|------|------|
| 1 | **不冒充身份** | 以真实身份到访，不扮装修公司/中介/记者套取非公开信息；不使用录音以外的欺骗性采集手段承诺 |
| 2 | **不窃取商业秘密** | 只采集公开层面信息（公示价格/公开销控/现场展示），不拿内部文件、不翻台账、不拍摄标注"内部资料"区域 |
| 3 | **不诋毁竞品** | 采到的竞品抗性只用于我方话术准备，任何员工不得对外（含客户、媒体、网络）发布诋毁性表述；过广告法 |
| 4 | **数据不造假** | 踩盘记录、打分、报告数据必须真实采集；不为了"报告好看"修改数据 |
| 5 | **个人信息合规** | 踩盘不采集竞品客户个人信息；我方掌握的客户名单严禁用于互换情报 |
| 6 | **报告保密** | 月报与打分表限项目组内部流转，不外发（含朋友圈/行业群） |

**检查点**：营销负责人每月抽一份踩盘记录单核对红线 1/2/4；违反红线 1/2/3 的，当次踩盘作废并纳入个人考核。

## 附：竞品常见问题速答（我方销售被客户问竞品时）

> 详细话术归 L1 话术库·竞品域，此处只给口径纪律：
> 1. 不主动贬低竞品——客户没提竞品，不主动开炮；
> 2. 客户提竞品，先认可再转折（"他家 XX 确实可以，不过您要看 XX 的话……"）；
> 3. 只说事实与我方优势，不说"他家要烂尾/他家人不行"类评价性表述；
> 4. 口径以当月竞品月报的《我方应对》一节为准，月报没更新的不临场发挥。
