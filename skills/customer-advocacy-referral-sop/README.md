# 客户口碑与老带新运营 SOP（customer-advocacy-referral-sop）

面向客户关系、营销、案场和内容团队，规范服务反馈、口碑内容授权、老带新承接、推荐线索登记和权益兑现。

## AI 使用场景
1. 输入客户回访记录 → 输出服务问题分类、维护动作和是否适合口碑触达
2. 输入客户评价和授权范围 → 输出可发布内容草稿及待核验项
3. 输入老带新规则 → 输出规则卡、登记字段和兑现检查表
4. 输入推荐线索 → 输出来源核验时间线和待人工处理的争议项
5. 输入推荐与客诉数据 → 输出口碑运营复盘

## 输出纪律
- 先服务、后推荐；客户未主动表达意愿时不强推
- 推荐由新客户主动联系或授权登记，不索要亲友联系方式
- 客诉未闭环时暂停推荐触达
- 不把个案体验写成普遍保证，不以奖励换虚假评价

## 与其他技能的关系
- referral-growth：老带新基础模块
- sales-lead-grading：客户登记与跟进
- channel-collaboration-sop：渠道归属、报备与佣金
- crisis-response：客诉与危机
