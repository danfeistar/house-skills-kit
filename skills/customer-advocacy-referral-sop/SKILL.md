# 客户口碑与老带新运营 SOP（标准作业程序）· customer-advocacy-referral-sop

**一句话**：先把客户服务做好，再在客户自愿和规则透明的前提下承接口碑与推荐，不把业主变成未经授权的营销名单。

**适用角色**：客户关系、营销策划、案场负责人、置业顾问、物业/客服、内容团队和项目负责人。

## 使用规则

1. 口碑运营的前提是服务事实和客户自愿，不以礼品逼迫好评，不以奖励换取虚假评价。
2. 推荐由老客户主动转发或授权登记；不得索取、买卖、交换朋友和亲属联系方式。
3. 推荐规则、适用条件、奖励形式、兑现节点和失效情形必须书面明确。
4. 客诉、质量争议和未解决服务问题优先进入客诉流程，不借老带新转移或压低问题。
5. 客户肖像、姓名、房号、聊天记录、评价和案例必须按用途取得授权，撤回后停止使用。

## 核心流程

```text
服务交付 → 满意度与问题识别 → 分层维护 → 自愿表达推荐意愿
→ 合规说明规则 → 主动转发/官方登记 → 来源核验
→ 案场接待 → 结果回写 → 权益核验兑现 → 关系维护复盘
```

## 一、客户关系分层

| 层级 | 判断依据 | 维护重点 | 推荐动作 |
|---|---|---|---|
| 服务中 | 正在看房、签约、交付或处理问题 | 及时答疑、记录承诺和进度 | 不主动要求推荐 |
| 满意待维护 | 已完成阶段服务且无未结问题 | 回访体验、提供真实资料 | 客户主动表达时轻量说明规则 |
| 业主关系 | 已成交/交付并进入服务周期 | 工程、交付、物业和活动沟通 | 以服务内容为主，不连续营销 |
| 口碑参与 | 自愿分享体验或主动询问推荐 | 授权、内容核验、隐私保护 | 提供官方入口和规则卡 |
| 风险/客诉 | 有未解决投诉、争议或敏感问题 | 客诉分级、专人处理、留痕 | 暂停推荐邀约和营销触达 |

客户状态必须来自真实服务记录，不能仅凭“可能满意”推断。

## 三、口碑内容与授权

### 内容核验

客户案例或评价对外使用前，核对：

- [ ] 内容来自客户真实表达，未拼接成客户未说过的话
- [ ] 项目名称、房源、价格、配套和时间事实已核验
- [ ] 没有把个案体验写成所有客户必然结果
- [ ] 没有承诺升值、收益、学区、交付或绝对品质
- [ ] 客户明确知道发布渠道、用途、展示范围和保存期限
- [ ] 肖像、姓名、声音、房号和聊天截图按实际用途分别授权
- [ ] 客户可撤回，撤回后有下架和停止传播动作

## 四、老带新承接

### 推荐触发

可在以下情形轻量说明一次规则：

- 客户主动说“朋友也想了解”或询问如何推荐
- 客户明确表达对服务满意，并主动询问推荐方式
- 新客户主动说明真实介绍关系
- 已批准的业主活动明确包含自愿分享入口

不适合触发的情形：客户正在投诉、催促处理问题、明确拒绝营销、未完成关键服务或处于高压决策状态。

## 五、线索登记与来源核验

### 推荐线索最小字段

| 字段 | 要求 |
|---|---|
| 新客户标识 | 由新客户主动提交或授权登记 |
| 推荐人标识 | 仅记录核验推荐所必需的信息 |
| 主动联系时间 | 系统时间或可核验记录 |
| 推荐方式 | 官方链接/名片/活动入口等 |
| 项目意向 | 客户主动提供的项目或需求 |
| 归属状态 | 待核验/有效/重复/争议 |
| 服务负责人 | 明确到人 |
| 授权范围 | 是否允许后续联系及渠道 |

```text
新客户主动联系 → 说明来源并授权 → 查重/核验
→ 进入正常接待与 L1-5 台账 → 推荐关系状态更新
```

推荐关系有争议时，按 `channel-collaboration-sop` 的规则和仲裁流程处理，AI 不私自改判。

## 六、权益兑现与异常

### 兑现检查

- [ ] 推荐关系有效且不处于争议状态
- [ ] 推荐人和新客户满足批准规则条件
- [ ] 对应政策版本在触发日有效
- [ ] 成交、回款或其他触发节点已被授权部门确认
- [ ] 奖励形式、金额/权益和发放时间与批准版本一致
- [ ] 发放记录、凭证和客户通知已归档

### 异常处理

| 异常 | 动作 |
|---|---|
| 客户未授权却被登记 | 停止使用信息，核实来源并删除非必要字段 |
| 推荐关系重复 | 保留原始记录，按生效规则进入核验/仲裁 |
| 客诉未解决仍被邀约 | 停止邀约，转客诉负责人，完成问题闭环后再评估 |
| 客户撤回内容授权 | 记录撤回时间，停止新增传播并按渠道下架 |
| 奖励规则发生变化 | 按触发日期锁定适用版本，不用新规则覆盖旧事实 |
| 渠道与业主推荐撞单 | 分别记录来源，按书面归属规则处理，不在客户面前争执 |

## 七、复盘指标

| 指标 | 计算方式 |
|---|---|
| 主动推荐率 | 主动表达推荐意愿客户/完成有效回访客户 |
| 推荐线索有效率 | 通过授权和查重的推荐线索/推荐线索总数 |
| 推荐到访率 | 推荐线索实际到访/有效推荐线索 |
| 推荐成交率 | 推荐成交/有效推荐线索 |
| 权益准时兑现率 | 按承诺节点完成兑现/应兑现记录 |
| 授权撤回处理及时率 | 在规定时间完成停止使用/应处理撤回 |
| 推荐相关投诉率 | 推荐造成的有效投诉/推荐线索数 |

复盘重点看服务质量、推荐线索真实性、客户自主性和权益兑现，不用奖励金额单项评价口碑运营。

## 合规红线

1. 不得购买、交换、导出、群发或私自保存客户及其亲友联系方式。
2. 不得冒用客户评价、伪造推荐关系、诱导客户修改来源或以奖励换虚假好评。
3. 不得在客诉、质量争议或客户明确拒绝后继续施压营销。
4. 不得擅自承诺返现、优惠、礼品、佣金、购房资格或其他未审批权益。
5. 不得将单个客户的体验、成交价格、收益或配套情况宣传成普遍保证。
6. 不得未经授权发布客户姓名、肖像、房号、聊天截图、录音和联系方式。
7. 发现信息泄露、虚假评价、违规收费或集中投诉时，先停止相关活动并升级处理。
