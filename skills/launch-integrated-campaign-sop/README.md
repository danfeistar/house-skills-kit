# 节点开盘整合营销 SOP（launch-integrated-campaign-sop）

面向项目营销负责人和策划团队，统筹蓄客、活动、物料、工程、价格、渠道、口碑与开盘执行的节点战役。

## AI 使用场景
1. 输入开盘节点和目标 → 输出战役简报与倒排表
2. 输入各条线任务 → 输出九格协同表、责任人和版本闸口
3. 输入房源、价格、渠道和客户数据 → 输出认筹收口与现场衔接清单
4. 输入战役结果 → 输出 24/72 小时复盘和改进台账

## 输出纪律
- 本技能管整合策略，不替代 `sales-opening-sop` 的开盘日现场执行
- 不补写房源、价格、优惠、工程、配套或成交数字
- 不使用虚假热度、虚构稀缺和强迫决策手段
- 所有对外资产必须有批准版本、负责人和回读指标

## 与其他技能的关系
- presale-marketing-sop：蓄客与认筹预热
- activity-organization-sop：活动执行
- pricing-incentive-release-sop：价格和优惠
- channel-collaboration-sop：渠道协同
- sales-opening-sop：开盘日执行
