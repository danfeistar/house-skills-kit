# property-media-creator（房产自媒体博主内容助手）

房产自媒体账号的**内容生产与经营**技能：定位 → 选题库 → 脚本 → 拍摄剪辑 → 平台合规 → 私信转化 → 复盘 → 变现。

## 适用谁
- 经纪人自营账号、门店/机构运营号
- 房产测评/探盘博主、政策解读创作者
- 开发商营销号内容负责人

## 怎么用（AI 场景）
1. 起号或改号 → Part 1 三圈定位 + 五类人设 + 差异化四问 + 前 10 条内容安排
2. 不知道拍什么 → Part 2 四源采集法（客户问答/搜索词/评论区/带看现场）+ 选题卡模板
3. 完播率低 → Part 3 黄金 3 秒八种钩子 + 分型结构表（10 秒速讯 / 15 秒深度）
4. 拍完不会剪/字幕乱 → Part 4 三种机位 + 字幕硬标准（零错字、关键词置上 1/3、负面词清单）+ 封面三要素与 A/B
5. 被限流/判违规 → Part 5 五条红线 + 限流信号识别 + 申诉整改流程
6. 有播放没咨询 → Part 6 评论区三板斧 + 私信六句结构 + 留资合规 + 到访衔接
7. 月度复盘 → Part 7 四指标口径 + 封面/钩子 A/B + 复盘表 + 三条止损规则
8. 要变现 → Part 8 四类路径 + 三处披露义务 + 三段式报价

## 输出纪律
- 每次交付四件：**选题卡 / 口播稿（三栏分镜）/ 字幕稿（与口播同源，单行 ≤14 字）/ 发布自检表**
- 必须带「数据时间戳」一行；价格类超 30 天、政策跨越公告期必须重取
- 价格、面积、政策、学位一律"按当地当期公告现查"，本技能不含任何城市具体数字
- 测算类内容（首付/月供/置换成本）走 `calc-toolkit`，不在脚本里口算
- 发布前过九条合规红线（虚假房源/学区承诺/收益承诺/诱导平台外交易/隐私/搬运/歧视/广告披露/冒充官方）
