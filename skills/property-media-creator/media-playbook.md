# 房产自媒体内容创作 正文

> 示例中 `{{}}` 为占位符，必须替换为本案真实数据。价格、政策、学位一律"按当地当期公告现查"，本文件不含任何城市的具体数字。
> 每次交付必带「数据时间戳」一行，无时间戳不得发布。

---

## Part 1 定位与人设

### 1.1 三圈定位法（三个圈都填满，账号才立得住）

| 圈 | 问题 | 填错的表现 |
|---|---|---|
| **我能提供什么**（能力圈） | 我是经纪人/测评人/业主/机构？我掌握的是房源、数据、还是经验？ | 什么都说，观众记不住你 |
| **谁需要我**（人群圈） | 城市 + 预算档 + 新房或二手 + 刚需或改善 | "所有买房人"=没人 |
| **为什么是我**（差异圈） | 别人也能讲这些，凭什么信我？ | 内容与同行同质，只能靠低价博眼球 |

**三圈交集写法（一句话定位）**：
> 我在 {{昆明}} 专门帮 {{首付 30~50 万的首次刚需}} 挑 {{二手两房}}，靠的是 {{每天带看现场的真实数据}}。

### 1.2 五类人设与可信度来源

| 人设 | 可信度来自 | 内容优势 | 风险 |
|---|---|---|---|
| **一线经纪人** | 带看量、成交案例 | 现场感强、私信转化高 | 易变成刷房源，专业度不足 |
| **测评/探盘博主** | 横向对比、数据 | 客观感强、涨粉快 | 无真实房源掌控，转化弱 |
| **业主视角** | 亲身经历 | 真实感强、共鸣高 | 样本单一，难以持续 |
| **政策解读** | 出处、原文比对 | 权威感强 | 说错一句就失信，且易违规 |
| **机构运营号** | 机构背书、服务体系 | 可承接大流量 | 人设冷，互动差 |

### 1.3 差异化四问（起号前必须回答）

1. 同行都在讲什么？我**不讲**什么（划出禁区）？
2. 我有什么**别人拿不到的一手素材**（独家房源、真实成交价、现场影像）？
3. 观众看完能**带走什么具体动作**（算清首付/避开一个坑/知道去问谁）？
4. 三个月后，观众会用**哪一句话**向朋友介绍我？

### 1.4 起号前 10 条内容安排（别乱发）

| 序号 | 类型 | 目的 |
|---|---|---|
| 1 | 自我介绍（一句定位 + 一个承诺） | 立人设 |
| 2 | 我最擅长回答的一个问题 | 立专业 |
| 3–4 | 两条速讯（真实价格/真实房源） | 立"有真货" |
| 5 | 一条避坑（客户踩过的坑） | 立"敢说" |
| 6 | 一条"不适合谁"（反向筛选） | 立"不忽悠" |
| 7–8 | 两条探盘（现场感） | 立"在一线" |
| 9 | 一条客户问答合集 | 立"懂需求" |
| 10 | 一条行动召唤（如何咨询、什么流程） | 立"可承接" |

### 1.5 翻车警示

- ❌ **定位写"房产知识分享"**：没有人群、没有城市、没有差异，等于没定位
- ❌ **前 10 条全是房源刷屏**：观众只当你是"广告号"，涨不了粉
- ❌ **人设与身份不符**：非经纪人却讲"内部价"，一旦被查实，账号直接判死

## Part 2 选题库机制

### 2.1 四类选题（比例参考：速讯 40% / 避坑 25% / 探盘 25% / 判断 10%）

| 类型 | 目的 | 示例方向（不含具体数字） |
|---|---|---|
| **速讯型** | 抓搜索流量 | 某小区新出房源、价格调整、新盘开盘 |
| **避坑型** | 抓转发与信任 | 首付算漏的四笔钱、看房时的三个隐藏问题 |
| **探盘型** | 抓本地流量 | 现场动线、采光实测、噪音实测 |
| **判断型** | 抓专业认同 | "这类人不建议买这个片区""这个价格区间我为什么不推荐" |

### 2.2 四源采集法（选题永不枯竭）

1. **客户问答源**：把近 30 天客户问过的问题原句记下来，取前 20 条 → 每条一个选题
2. **搜索词源**：平台搜索框输入城市/片区，看下拉推荐与"大家都在搜" → 直接对应需求
3. **评论区源**：自己与同行视频下的高赞追问，尤其"那我这种情况怎么办"
4. **现场源**：带看时听到的吐槽（"这采光不行""这户型怎么这么怪"）→ 现场实拍 + 回应

### 2.3 选题卡模板（一条视频一张卡）

```
选题：{一句话}
目标读者：{首次刚需/改善/学区/投资/业主}
钩子句：{前 3 秒那句话}
核心事实：{1 个可核验事实 + 来源}
取数日期：{YYYY-MM-DD}
CTA：{私信关键词/评论引导}
风险点：{是否涉及政策/学区/收益，需加声明}
```

### 2.4 月度淘汰规则

- 连续 2 条同类型内容完播低于账号均值 → 该类停做一个月
- 某选题连续 3 条播放低于基准 → 该选题维度封存，换维度
- 任何选题命中红线（学区/收益/内部消息）→ 立即下架并复盘

### 2.5 翻车警示

- ❌ **靠"热门话题"选题**：与人群不匹配，来了流量也不咨询
- ❌ **只做房源刷屏**：账号变成公告栏，平台推荐权重也会降
- ❌ **选题卡不写取数日期**：一周后价格变了，旧视频变成错误信息

## Part 3 脚本结构

### 3.1 黄金 3 秒：八种钩子（直接套）

1. **结论反差**："这套房我劝你别买，除非你符合一个条件。"
2. **具体数字**："同户型，这栋比隔壁楼每平少 {{X}} 元，原因在这。"
3. **损失提示**："首付差 {{X}} 万，很多人是漏算了这一笔。"
4. **反常识**："楼层不是越高越好，这两层转手最难。"
5. **场景切入**："刚带完一组客户，他们看中的这套有个硬伤。"
6. **问题直击**："预算 {{X}} 万，在 {{片区}} 到底能买什么？"
7. **对比开场**："同一笔钱，买这边和买那边，五年后差在哪。"
8. **身份背书**："经手过 {{N}} 套 {{片区}} 的房，这三类我不推。"

> 八种钩子里，**结论反差与具体数字**在房产垂类完播最稳，优先用。

### 3.2 分型结构（照表填，不要凭感觉剪）

| 分型 | 时长 | 结构 | 字数 |
|---|---|---|---|
| 速讯 | 10 秒 | 钩子（1 句）→ 事实（1 句）→ 影响（1 句）→ CTA（1 句） | ≈50 字 |
| 深度判断 | 15 秒 | 钩子 → 支撑点 1 → 支撑点 2 → 支撑点 3 → 不适合谁 + CTA | ≈75 字 |
| 探盘 | 15~30 秒 | 反差画面钩子 → 入户 → 主空间 → 采光/视野 → 结论 + CTA | ≈75~150 字 |
| 政策解读 | 15 秒 | 政策对谁有影响 → 2 个受影响场景 → 1 个不适用 → 免责声明 + CTA | ≈75 字 |

### 3.3 三段口播（把内容压进 15 秒的唯一办法）

- **第 1 段（0~4 秒）**：钩子 + 结论，不允许出现"大家好""今天带大家看"
- **第 2 段（4~11 秒）**：三个支撑点，每个一句话，用"第一/第二/第三"或"一是/二是/三是"分隔
- **第 3 段（11~15 秒）**：边界（"不适合 XX 的人"）+ 行动指令（"评论区打 XX，我发你一份对比表"）

### 3.4 口播与字幕同源

- 字幕**必须与口播逐字一致**（含数字单位），不许字幕另写一套
- 单行不超过 14 字，两行一段，关键词（价格、面积、片区、数字）置于画面上 1/3，避免被平台 UI 遮挡
- 数字写法统一：`{{X}} 万`、`{{X}} 元/㎡`、`建面 {{X}} ㎡`，全片同一口径

### 3.5 常见废稿五型（自查清单）

1. **铺垫型**：前 3 秒在自我介绍/问好/描述天气
2. **多点型**：一条讲三个卖点，观众一个都记不住
3. **无据型**：说"很多客户都说"，但没有一个具体事实
4. **违规型**：出现"必涨/稳赚/一定上得了/内部价"
5. **无 CTA 型**：看完不知道下一步做什么

### 3.6 翻车警示

- ❌ **钩子用提问但答案是废话**："你知道买房要注意什么吗？"——观众直接划走
- ❌ **为凑时长加废话**：宁可 10 秒讲清，不要 30 秒注水
- ❌ **字幕与口播不同步**：后期改动口播却没改字幕，是最常见的翻车

## Part 4 拍摄剪辑与封面

### 4.1 设备最低配置

- 手机（后置主摄，1080p 30fps 起）+ 稳定器或靠墙固定
- 有线/领夹麦（现场噪音是完播最大杀手，风声一起观众就走）
- 补光：白天靠窗，室内靠一盏面光（别用顶灯，脸上出阴影）
- 剪辑：任意手机剪辑软件即可，重点在节奏不在特效

### 4.2 三种常用机位

| 机位 | 用途 | 要点 |
|---|---|---|
| **口播正机位** | 判断型/政策型 | 眼睛看镜头，胸口以上，背景干净 |
| **手持跟随** | 探盘 | 走慢、少晃，转弯处停 0.5 秒再转 |
| **固定空镜** | 采光/视野/配套 | 每个空镜 2~3 秒，够剪辑就行 |

### 4.3 字幕规范（硬标准）

- **中文零错字**：价格、面积、片区名、政策术语，发布前三审
- 字号一致、位置一致，不遮挡主体与被平台 UI 遮挡区域
- 负面词清单（一律不用）：`最`、`第一`、`唯一`、`绝版`、`必涨`、`稳赚`、`内部价`、`保证`、`包过`、`史上最低`、`错过再无`
- 关键数字可加底色强调，但一屏不超过 2 处

### 4.4 BGM 与节奏

- 速讯型用无歌词轻节奏，音量压到人声的 20% 以下
- 探盘型可保留现场环境音（脚步声、鸟声），提升真实感
- 政策解读型不加音乐，只留人声，减少听觉干扰

### 4.5 封面三要素与 A/B

1. **一句话大字**（≤10 字，直给结论或数字）
2. **一个具体画面**（房源/现场/对比图，不用网图）
3. **一个可视差**（高低对比、前后对比、价格划线）

> A/B 方法：同一内容出两版封面（结论型 vs 数字型），各跑 24 小时，留存高的那版做该账号的封面模板。

### 4.6 翻车警示

- ❌ **封面用网图/效果图**：与视频内容不符，观众划走还伤信任
- ❌ **字幕压到价格区**：正好被平台评论区 UI 盖住，等于白做
- ❌ **全片加同一首热门 BGM**：容易被判同质化内容，推荐权重下降

## Part 5 平台规则与限流

### 5.1 五条红线（房产垂类高频违规）

1. **虚假房源**：房源不存在、已成交仍发布、价格面积与实际不符
2. **学区与入学承诺**：承诺"一定能上""包入学"
3. **收益与升值承诺**："必涨""年化 X%""稳赚不赔"
4. **诱导平台外私下交易**：引导加私人联系方式绕过平台交易
5. **无依据的官方身份**："开发商内部""房管局消息""独家代理"

### 5.2 限流信号识别

| 信号 | 判断方式 |
|---|---|
| 播放量骤降（同类型内容低于均值 50% 以上且持续 3 条） | 查是否有违规提醒/作品状态异常 |
| 仅粉丝可见 / 推荐为 0 | 平台作品状态页查看 |
| 评论区被折叠、他人看不到 | 用另一账号查看 |
| 私信功能受限 | 私信页提示 |

### 5.3 申诉与整改

1. 先自查内容与红线清单逐条比对（多数是学区/收益/内部价表述）
2. 删除或改为合规表述后重新发布（不原样重发）
3. 通过平台申诉入口提交，附事实依据（房源委托、政策原文）
4. 连续 3 条被限 → 暂停发布 3 天，只做互动养号，避免账号权重继续下滑

### 5.4 搬运与二次创作边界

- 他人视频/图片：取得授权或使用明确可商用素材，标注来源
- 二次创作需有实质加工（重剪、重讲、加数据），不得原片搬用
- 房源视频如由案场提供，需确认可使用范围（是否允许二次剪辑与发布）

### 5.5 翻车警示

- ❌ **被限流还继续发**：越发权重越低，正确做法是停下自查
- ❌ **改两个字就当整改**：平台识别的是整段语义，换皮不解决问题
- ❌ **用"仅供参考"当免责护身符**：违规表述仍在，声明救不了

## Part 6 评论区与私信转化

### 6.1 评论区三板斧

1. **置顶补充**：发布后 5 分钟内自己置顶一条补充（面积/价格口径/取数日期）
2. **预置三条回复**：价格类、位置类、资格类各一条标准回复，避免逐条现编
3. **引导关键词**："评论区打 `{{对比表}}`，我发你一份"——把公域流量转成私信

### 6.2 私信六句结构（从打招呼到约看，不许多说）

1. **回应需求**："您问的是 {{片区}} {{预算档}} 的两房，对吗？"
2. **给具体**："目前符合的有 3 套，价位分别在 {{区间}}。"
3. **给差异**："这 3 套最大区别是 {{采光/楼层/税费}}。"
4. **给建议**："如果您更看重 {{需求}}，我建议先看第 2 套。"
5. **给动作**："我把三套的采光视频发您，看完告诉我哪套想实地看。"
6. **给边界**："具体税费和资格以窗口口径为准，我带您去核一遍。"

> 原则：私信里不承诺价格、不承诺资格、不催单；只给信息与下一步动作。

### 6.3 留资合规

- 只收集成交必需字段（称呼、意向片区、预算档），不索要身份证、社保明细等敏感信息
- 不把客户信息转售或跨项目共享
- 客户要求删除信息时必须删除并确认

### 6.4 到访衔接

- 约看前发定位 + 到访清单（带什么材料、看几套、预计多久）
- 到访当天由承接人负责，不让客户"到了没人管"
- 到访后 24 小时内回访一次，给出"看过的三套对比"而不是"考虑得怎么样"

### 6.5 翻车警示

- ❌ **私信第一句就报价**：客户还没说清需求，报价只会引发比价
- ❌ **私信承诺"我能给你再便宜 X 万"**：越权承诺，交付不了就失信
- ❌ **把客户拉进群统一发广告**：合规与体验双输

## Part 7 数据复盘

### 7.1 四指标口径与健康值（按账号自身基准校准）

| 指标 | 算法 | 关注点 | 健康信号 |
|---|---|---|---|
| **完播率** | 完播次数 ÷ 播放次数 | 钩子与时长是否匹配 | 10 秒内容 ≥40%，15 秒内容 ≥30% |
| **互动率** | （点赞+评论+转发）÷ 播放 | 内容是否有争议点/共鸣点 | ≥5% 且评论中有具体提问 |
| **涨粉率** | 新增粉丝 ÷ 播放 | 人设是否清晰 | ≥0.5% |
| **咨询转化** | 私信咨询数 ÷ 播放 | CTA 是否有效 | ≥0.2%，且咨询中 ≥30% 说清需求 |

### 7.2 封面与钩子 A/B

- 同一内容只测一个变量（封面或钩子，不同时改）
- 每组跑 24 小时，样本不足 500 播放不作判断
- 结论写进账号的"模板库"：什么钩子+什么封面在这个城市这个人群上有效

### 7.3 月度复盘表（一页纸）

| 选题类型 | 条数 | 平均播放 | 平均完播 | 咨询数 | 结论（加量/维持/停做） |
|---|---|---|---|---|---|
| 速讯 | | | | | |
| 避坑 | | | | | |
| 探盘 | | | | | |
| 判断 | | | | | |

### 7.4 三条止损规则

1. 连续 10 条内容咨询 <1 → 停更三天，重做人群定位（不是加更）
2. 某类型投入产出长期垫底 → 该类型砍掉，把产能集中到咨询最多的两类
3. 账号被限流后不复盘就复更 → 直接换赛道重来（旧账号权重修复成本高于新号）

### 7.5 翻车警示

- ❌ **只看播放量做决策**：播放高但无咨询的内容，是"热闹的死号"
- ❌ **同时改封面、钩子、时长**：改完不知道哪个起作用
- ❌ **样本太小就下结论**：500 播放以下的差异是噪音

## Part 8 变现与披露

### 8.1 四类变现路径

| 路径 | 收入形态 | 前提 | 风险 |
|---|---|---|---|
| **带看/成交佣金** | 成交后按约定分佣 | 有真实成交能力与合规渠道 | 需披露利益关系，不得虚假承诺 |
| **广告/软广** | 按条或按效果 | 有稳定播放与垂类人群 | 必须标注广告，不得伪装体验 |
| **知识付费/社群** | 课程、咨询、资料 | 有过硬方法论与案例 | 不得承诺收益，不得夸大 |
| **工具与服务** | SaaS/代办服务 | 有交付能力 | 明码标价，不捆绑强制消费 |

### 8.2 披露义务（三处都要）

1. **视频内**：口播或字幕出现"本内容含商业合作"
2. **简介区**：写明合作方与利益关系
3. **评论区置顶**：合作项目名称与是否为代理

### 8.3 合作报价结构（不报单一数字，报三段）

- **基础制作费**：拍摄 + 剪辑 + 脚本（覆盖成本）
- **发布费**：按账号当前平均播放阶梯定价
- **效果费**（可选）：按咨询或到访结算，需明确归因口径与结算周期

### 8.4 风险提示

- 佣金合作不签"保成交"，只签服务范围与结算规则
- 广告内容涉及价格/政策的，同样受第 5 节红线约束
- 知识付费类内容不得出现"稳赚""必涨""包学会"表述

### 8.5 翻车警示

- ❌ **收钱讲"内部消息"**：这是红线里最重的一条，容易同时触发平台处罚与法律风险
- ❌ **不标注广告**：一旦被举报，账号与商业合作同时受损
- ❌ **报价只给一个总价**：后期效果不好必然扯皮，三段结构才可谈
