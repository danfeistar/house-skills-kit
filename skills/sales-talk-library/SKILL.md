# 案场话术库（五域）· sales-talk-library

**一句话**：按地段/配套/户型/竞品/品牌五域组织的案场标准说辞库——每个维度给标准话术、分客群变通、翻车警示，AI 可直接用于话术生成、接待陪练、新人培训。

**适用角色**：置业顾问（日常接待）、销售经理（新人培训/话术统一）、营销策划（案口物料文案）

**触发场景**：
- 客户问到地段/配套/户型/竞品/品牌相关问题，需要应对说辞
- 准备新开盘/新案场的说辞手册
- 新人培训、话术演练（AI 扮演客户）
- 统一案场口径（防止各顾问说法打架）

## 使用方法

1. **取话术**：按客户问题定位到域 → 维度 → 场景，取标准说辞
2. **换变通**：按客户类型（刚需/改善/投资）选用变通说法，同一事实三种讲法
3. **过红线**：输出前自查文末合规红线，翻车警示里列的高频错误逐一核对
4. **演练模式**：让 AI 扮演客户（指定客群+情绪），顾问用本库话术应对，AI 给点评
5. **品牌定制**：`{{项目名}}` `{{板块}}` 等占位符由 render.py 按 brand.yaml 注入

## 结构

详见 `domains.md`：
- **地段域**（板块位置·4 维）：交通 / 板块规划与格局 / 学区与入学口径 / 土地稀缺与去化
- **配套域**（生活圈·5 维）：教育 / 医疗 / 商业与商圈 / 公园水系与休闲 / 邻里——吸收原环境与商圈维度
- **户型域**（7 维）：带看顺序 / 户型图对比 / 赠送空间 / 实得面积 / 采光通风 / 收纳动线 / 样板间合规边界
- **竞品域**（3 场景）：客户提竞品 / 主动对比 / 比后再访
- **品牌域**（5 维）：开发商实力 / 物业口碑 / 工程质量 / 交房保障 / 业主社群

每个话术块的三件套：**标准说辞 → 分客群变通 → 翻车警示**

## 合规红线（每条话术输出前必查）

1. **学区不可承诺**：划片范围每年由教育部门公布，只说"历史上对本项目所在地块的划片情况+以教育局当年公布为准"，严禁"肯定能上 XX 学校"
2. **规划不可夸大**：规划中的地铁/学校/商业，必须注明"规划已公示（可提供文号/链接）+ 建成时间以政府公告为准"，严禁"马上就通/确定落地"
3. **数据必须真实**：库存、成交价、通勤时间等可验证数据严禁编造——宁可说"我现在查一下给您准数"
4. **不贬损竞品**：只讲自己强项与差异，不给竞品起外号、不传播竞品负面传言
5. **不威胁式逼单**："不买就涨价/没了"必须有真实依据（真实调价文件/真实去化数据），否则禁用
6. **不替客户担保**："绝对保值/稳赚"类表述禁止；收益类话题回到"租售比数据+风险自担"

## 与其他技能的关系

- 竞品对比的**数据源**来自 L2-2 竞品踩盘报告（策划线产出）
- 价格谈判类话术在 L1-3 逼定技能（本库只管五域价值陈述）
- 政策/税费/贷款数字一律引用 calc-toolkit 计算，不口算

## 规范六段（v1 补齐）

### 必问信息
| 必问项 | 为什么要 |
|---|---|
| 客户问题原话与客群类型 | 同一话术对不同客群效果差数倍 |
| 项目当期数据（价格、优惠、配套进展、规划文号） | 说辞里的数字过期=当场失信 |
| 竞品对比对象（哪个盘、哪一项） | 对比要有具体项，不能泛泛"比它们好" |
| 使用场景（案场接待/电话/开盘/直播） | 决定话术长度与语气 |
| 必须规避的合规项（学区、收益、规划、交付承诺） | 说辞是最容易踩红线的地方 |
| 需要统一的争议口径（客户反复问的难题） | 各说各话是案场最大的内耗 |

### 知识库与数据来源
- 五域 24 个话术块（地段/配套/户型/竞品/品牌），每块含标准话术、分客群变通、翻车警示（本技能 Part 2~6）
- 一切数据以当期官方口径为准：规划须有文号，配套须有实况，价格须有版本
- 学区、入学、升值、收益类问题：只陈述官方公告与既有事实，不作任何承诺
- 竞品信息引用 `competitive-intel-sop` 采集结果，标注采集日期

### 目标读者
置业顾问（现场背诵使用）、培训负责人（编手册与考核）、新人（入职演练）。

### 写作风格
- 口语、可直接背；一段不超过三句，说出口不超过 20 秒
- 不用形容词堆砌（"环境优美""交通便利"），用可验证的事实（"步行 8 分钟到 X 站"须实测）
- 每个数字后面能说出出处；说不出出处的数字不许进话术库
- 对客户的承诺性表述一律改为条件句

### 输出格式
1. 话术卡（问题 / 标准话术 / 分客群变通 / 翻车警示 / 合规提示）
2. 说辞手册目录（按五域组织，标注版本与生效日）
3. 新人演练脚本（问题 → 应答 → 常见错误 → 评分要点）

### 数据时间戳
话术引用的数据标注取数日期与来源文件；规划类标注文号；政策类标注公告期；话术库标注版本号与生效日期，过期条目应当下架而不是留着解释。
