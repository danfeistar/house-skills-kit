# sales-talk-library（案场话术库）

给案场销售团队用的五域说辞库：地段 / 配套 / 户型 / 竞品 / 品牌。每个话术块三件套：标准说辞 → 分客群变通 → 翻车警示 → 合规自查。

## 适用谁
- 置业顾问：接待前备话术、接待中查口径
- 销售经理：新人培训、统一案场口径
- 营销策划：案口物料文案的口径底稿

## 怎么用（AI 场景）
1. 把客户问题+客户类型（刚需/改善/投资）告诉 AI → 输出对应域的标准说辞+变通
2. 演练模式：AI 扮演客户（可指定情绪与刁难点），顾问应对，AI 按翻车警示逐条点评
3. 输出前自动过合规红线（学区/规划/数据真实性/不贬损竞品）

## 配置项（brand.yaml 注入）
- `{{项目名}}` `{{城市}}` `{{板块}}`：项目信息
- `{{最近地铁站}}` `{{商圈}}` `{{公园}}`：地段要素
- 城市划片政策等外部数据一律引用官方口径，不入本库
