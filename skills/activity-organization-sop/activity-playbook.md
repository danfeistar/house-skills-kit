# 营销活动组织 SOP 正文

> 本文管单场活动的策划、审批、执行、承接与复盘；内容脚本与拍摄工艺引用内容线技能，本技能只负责活动策略、组织与线索承接。
> 全文目标数字、费用、周期一律 `{{}}` 占位，按项目实际定。
> 红线（文末）优先级高于本文任何动作。

## Part 1 活动目标定义

### 1.1 一个主目标原则

每场活动**只设一个主目标**。最多配两个辅助目标。没有明确目标的活动不进入排期。

| 阶段 | 最匹配的主目标 |
|---|---|
| 暖场/形象导入 | 触达 |
| 拓客/圈层突破 | 留电 / 到访 |
| 认筹预热/开放 | 到访 / 认筹 |
| 老带新/答谢 | 推荐 / 到访 |
| 品牌联动/异业 | 触达 / 留电 |

**翻车警示**：
- ❌ "办一场热闹"——到场多但无留电、无预约，等于零转化
- ❌ 主目标模糊到"提升品牌认知"——无法回读、无法考核、无法优化

### 1.2 成功判定标准

活动结束后判定是否成功的唯一依据是主指标是否达到阈值。辅指标作为诊断参考。

```
成功判定公式：
主指标实际值 ≥ 目标值 × 80% → 合格，可复制
主指标实际值 ≥ 目标值 × 100% → 优秀，值得投入更多资源
主指标实际值 < 目标值 × 50% → 偏差过大，需深度复盘而非追加预算
```

## Part 2 活动选型框架

### 2.1 选型决策树

```
客户是谁？
├── 新客户（未到访过案场）→ 定向邀约或公开报名
│   ├── 预算有限 → 小型沙龙/异业合作（≤30人）
│   └── 预算充足 → 示范区开放/大型主题活动（50-200人）
├── 老客户（已到访/已购/已登记）→ 定向邀请
│   ├── 有成交但未转介绍 → 老带新专属权益活动
│   └── 有购买意向 → 产品体验+政策宣讲
└── 不确定 → 用 L1-5 分级台账筛选 A/B 类优先邀约
```

### 2.2 常见类型选型矩阵

| 类型 | 规模 | 预算区间 | 主目标 | 适合阶段 |
|---|---|---|---|---|
| 小型圈层沙龙 | {{15-30}} 人 | {{低}} | 留电/到访 | 蓄客中后期 |
| 单位团购推介 | {{20-50}} 人 | {{中}} | 到访/认筹 | 蓄客冲刺 |
| 异业联合快闪 | {{不定}} | {{低至中}} | 触达/留电 | 全阶段 |
| 示范区开放 | {{50-200}} | {{中高}} | 触达/到访 | 展示面开放时 |
| 老业主答谢 | {{30-80}} | {{中}} | 推荐/到访 | 有交付或有认筹后 |
| 主题暖场（节日） | {{不定}} | {{低}} | 留电/到访 | 展示面开放早期 |

**选型纪律**：
1. 先选客群再选类型——不是先想办什么再找人来
2. 每期只做不超过两种活动类型的组合
3. 同类型活动之间至少间隔 {{7-14}} 天（给首触和跟进留时间窗口）

## Part 3 活动简报与方案模板

### 3.1 一页简报必填项

每次活动开工前由策划填写《活动简报》，经营销负责人审核后锁定：

```text
活动名称：[中文]
项目/批次：[项目名]
主目标：[触达/留电/到访/认筹/推荐/品牌体验]
目标数值：[具体数字]
目标客群：[来源/画像]
报名人数上限：[N]
活动时间：[月/日/时间段]
活动地点：[位置]
活动预算上限：[金额]（含机动项）
核心主题/口号：[一句话描述]
报名入口及授权文案：[链接/表单，注明合规条款]
宣传渠道：[列出每个入口的来源码]
主负责人：[姓名+岗位]
现场接待承载：[最大同时在场人数]
供应商（如有）：[公司+对接人]
风险预案摘要：[前三项]
成功判定条件：[量化表述]
```

### 3.2 活动方案必含清单

一份完整方案必须包含以下六个部分：

| 序号 | 章节 | 输出物 |
|---|---|---|
| ① | 背景与目标 | 为什么办、办成什么样算成功 |
| ② | 流程表 | 逐小时或半小时段安排 |
| ③ | 人员分工 | 谁做什么、异常升级链 |
| ④ | 现场动线与承接设计 | 签到→体验→咨询→留电路径 |
| ⑤ | 预算表 | 分项预算+备用金+审批链 |
| ⑥ | 风险表 | 至少覆盖天气/安全/投诉/超承载 |

**翻车警示**：
- ❌ 只有流程表没有承接设计——办了等于没接
- ❌ 只有预算没有风险表——出事了才知道该不该停

## Part 4 邀约报名与信息收集

### 4.1 邀约层级

| 层级 | 方式 | 适用对象 | 注意 |
|---|---|---|---|
| A 级定向邀约 | 电话/当面 | A 类客户（高意向） | 提前 {{3}} 天通知，告知活动内容但不承诺销售政策 |
| B 级定向邀约 | 短信/微信私发 | B 类客户（中等意向） | 统一话术模板，附报名链接和来源码 |
| C 级公开招募 | 线上海报/自媒体 | 泛目标人群 | 强调授权和隐私保护，不提供未经批准的价格信息 |

### 4.2 报名表单字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 姓名 | 是 | 最小必要信息 |
| 联系电话 | 是 | 须附带授权声明 |
| 来源渠道 | 自动回填 | 从来源码解析 |
| 参与人数 | 否 | 如带家人同行 |
| 关注焦点 | 否 | 客户主动填写的购房需求 |
| 是否方便通话 | 是 | 便于后续联系 |

**信息纪律**：不在活动中采集报名表单以外的其他信息；不做"顺便问一下"式的信息追问（归入 L1-5 需求挖掘范围）。

## Part 5 活动流程与现场执行

### 5.1 标准流程示例（小型沙龙 {{90}} 分钟版）

| 时段 | 环节 | 主持人/责任人 | 备注 |
|---|---|---|---|
| {{0-10}} | 签到入场 + 扫码留电 | 签到岗 | 同步检查座位承载力 |
| {{10-15}} | 开场欢迎 + 自我介绍 | 主持/顾问 | 统一口径，不涉销售政策 |
| {{15-40}} | 主题分享（价值/规划/产品） | 嘉宾/策划 | PPT 过广告法 |
| {{40-65}} | 体验互动（沙盘/样板间/茶歇交流） | 全体顾问 | 自然对话，记录需求 |
| {{65-80}} | 答疑区 + 预约/资料领取 | 咨询区 | 高意向单独引导 |
| {{80-90}} | 离场提醒 + 感谢 | 主持 | 预告下次动作，确认首触时间 |

### 5.2 不同规模的流程调整

- **超 50 人**：分场次（上下午各一场），每场控制承载量
- **团购地推**：增加决策人一对一沟通时长，减少集体宣讲
- **答谢/老带新**：减少正式宣讲，侧重情感维系和转介绍规则公示

### 5.3 现场管控要点

1. **承载力预警**：签到超过预定人数的 {{90%}} 时启动分流措施
2. **政策口径冻结**：活动当天任何人不得擅自添加、修改或口头承诺未在审批版本中的价格、优惠和权益
3. **问题记录**：顾问发现共性问题（如抗性处理不到位）当场记录卡片，活动后纳入话术库更新
4. **媒体与拍照**：涉及客户正面照须现场确认授权用途

## Part 6 线索承接与首触跟进

### 6.1 现场至电话的黄金时间线

| 时间点 | 要求 |
|---|---|
| 活动期间 | 高意向客户现场做需求笔记（不占用过多个人时间） |
| {{24h}} | 首轮电话触达，提及活动内容和互动细节 |
| {{48h}} | 完成第一次分级判定（参考 L1-5） |
| {{72h}} | 写入周报并纳入漏斗数据 |
| {{1周}} | 根据分级结果决定下一轮触达动作 |

### 6.2 首触话术结构

```
第一句：感谢您参加{{活动名}}，我是{{姓名}}
第二句：您在{{某环节}}提到/问到{{客户关注点}}...
第三句：我整理了一份相关/{{补充资料}}，稍后通过{{方式}}发您
第四句：如果您方便，本周{{时间段}}可以来案场看一下实...
```

**话术纪律**：
- 首触必须提到活动现场的真实互动点（证明不是群发）
- 不主动推进到计算价格和逼定环节（那是后续场景）
- 如果客户明确表示暂不需要，标记"暂缓跟进"，不反复打扰

### 6.3 活动线索独立标签

所有活动来的线索在台账中标记为 `活动-{{活动名缩写}}`，与电开、派单、老带新等渠道并列。周报里单独列活动漏斗行。

## Part 7 复盘与二次优化

### 7.1 复盘节奏

| 时间 | 内容 |
|---|---|
| {{48h}} 内 | 基础数据复盘（到场率、留电率、预约率、成本） |
| {{72h}} 内 | 质量复盘（线索分级分布、首触完成率、有效性抽样） |
| {{1周}} 内 | 全流程复盘（目标设定、选型、流程、承接、竞品反应） |

### 7.2 复盘必回答五个问题

1. 主指标达标了吗？差了多少？
2. 哪一环掉了鱼？（报名→到场 / 到场→留电 / 留电→预约）
3. 哪个动作最值？哪个最不值？
4. 有没有被竞品同期反制？
5. 下次保留/停止/只改三件事是什么？

### 7.3 知识沉淀

每次有效复盘至少沉淀一条可复用经验：

| 沉淀类别 | 示例 |
|---|---|
| 好话题材 | "资产配置的宏观视角"比"楼盘户型讲解"留电率高 {{X}}% |
| 坏环节 | 签到排队超时导致流失 —— 下次分两批签 |
| 话术改进 | 首次触达提到了具体客户关注点 → 转化率提升 |
| 供应商评价 | 搭建效果、服务响应、报价合理性 |
| 竞品动态 | 我们在办活动时竞品是否同步做了动作 |

## Part 8 合规红线（一票否决）

| 类别 | 红线 | 说明 |
|---|---|---|
| 资金红线 | 未取得预售许可证，不得通过活动收取认筹金/定金/诚意金/会员费/报名费等变相锁定款项 | 免费活动和预约不构成收费 |
| 广告法 | 不使用极限词、不承诺升值/学区/投资回报、不发布未经公示的价格或优惠 | 活动海报、PPT、口播、自媒体内容一体适用 |
| 个人信息 | 名单采集须客户授权；仅限案场授权系统内使用；严禁购买、交换、流出名单 | 活动签到表上的电话号码只能用于本次回访 |
| 身份真实 | 不冒充政府机构、学校、银行、媒体或其他组织举办活动；嘉宾、合作方如实标注 | 伪造身份会触发合规事故 |
| 公平对待 | 同一活动的所有参与者获得同等信息和机会；不向个别人口头透露未公开的政策或优惠 | 违规口头承诺属于红线行为 |
