# 营销活动组织 SOP（标准作业程序）· activity-organization-sop

**一句话**：把地产营销活动从“办一场热闹”变成“目标可定义、过程可控、线索可归因、结果可复盘”的执行系统。

**适用角色**：策划、营销负责人、案场负责人、活动执行供应商、置业顾问、渠道与客服团队。

**触发场景**：
- 暖场活动、示范区开放、项目节点活动
- 圈层沙龙、单位团购推介、异业品牌联动
- 老业主答谢、客户转介绍活动
- 直播/线上报名与线下到访联动
- 活动结束后的线索清洗、复盘和二次转化

## 使用规则

1. 先输入活动目标、目标客群、预算上限、时间地点、项目阶段和可用资源，再生成方案。
2. 每个活动只设一个主目标，最多配置两个辅助目标；没有目标的活动不进入排期。
3. 所有数字、费用、政策、权益和时间节点使用项目实际值，不得凭空补齐。
4. 方案必须同时输出：活动简报、执行清单、人员分工、现场动线、线索表、复盘表。
5. 涉及价格、优惠、认筹、团购、报名费或礼品权益时，先经过项目审批和合规检查。

## 核心流程

```text
目标定义 → 客群与场景 → 活动选型 → 简报与预算 → 审批锁定
→ 邀约报名 → 现场执行 → 线索承接 → 24小时首触
→ 72小时复盘 → 二次触达与动作优化
```

### B. 目标设计

| 活动目标 | 主指标 | 辅助指标 | 不宜作为唯一成功标准 |
|---|---|---|---|
| 触达 | 有效触达人数 | 内容互动、报名 | 只看曝光量 |
| 留电 | 有授权的有效留电数 | 留电率、来源结构 | 只看签到人数 |
| 到访 | 活动后预约/实际到访 | 到访率、首触完成率 | 只看现场热闹程度 |
| 认筹 | 合规认筹转化 | 意向落位、分级结构 | 用礼品数量代替转化 |
| 老带新 | 有效推荐线索 | 到访、成交 | 无授权名单数量 |
| 品牌体验 | 满意度与有效反馈 | 内容自传播 | 把主观好评当成交 |

**目标纪律**：主指标必须能由报名、签到、留电、到访或后续台账回读；无法回读的目标改写。

## 活动选型

| 类型 | 更适合的目标 | 关键设计 | 主要风险 |
|---|---|---|---|
| 示范区/样板间开放 | 触达、到访 | 参观动线、预约分时、接待承载 | 到场超承载、现场拥堵 |
| 小型圈层沙龙 | 留电、到访 | 主题先行、限额报名、主持控时 | 变成硬推销会 |
| 单位/团购推介 | 到访、认筹 | 决策人对接、统一政策口径 | 私下承诺优惠 |
| 异业联合活动 | 触达、留电 | 双方权益书面确认、来源码 | 名单交换失控 |
| 老业主答谢/老带新 | 推荐、到访 | 推荐规则公示、授权登记 | 诱导或违规买卖名单 |
| 节点主题暖场 | 触达、留电 | 主题、报名钩子、现场承接 | 只办活动不接线索 |

**选型原则**：客群与活动主题要匹配；活动规模服从接待能力；预算优先投向可追踪的触达和承接，不为“场面大”单独加码。

## 执行清单

### 活动前

- [ ] 锁定活动目标、客群、人数上限、场地和预算
- [ ] 完成活动简报、流程表、风险表和人员排班
- [ ] 明确报名入口、授权文案、来源码和签到字段
- [ ] 确认宣传内容、嘉宾介绍、礼品与权益口径
- [ ] 完成供应商、设备、物料、天气和备用方案确认
- [ ] 按 L1-4 安排接待动线，按 L1-5 安排线索分级与跟进
- [ ] 涉及销售政策时，完成项目审批和全员口径培训

### 活动中

- [ ] 签到与报名信息匹配，不用未经授权的名单补录
- [ ] 主持人按批准流程执行，不临时口头增加价格或权益承诺
- [ ] 现场设置明确的咨询、预约和离场登记位置
- [ ] 高意向客户由指定人员承接，避免多人重复跟进
- [ ] 记录实际到场、有效留电、预约和异常情况
- [ ] 每个来源使用唯一来源码，照片和视频按授权范围使用

### 活动后

- [ ] 当日完成签到、留电、预约和异常数据核对
- [ ] 线索在 {{24}} 小时内完成首轮触达，进入 L1-5 台账
- [ ] 活动资料、费用凭证、授权记录和现场问题统一归档
- [ ] {{72}} 小时内完成主指标、费效和线索质量复盘
- [ ] 只保留不超过 {{3}} 条下次可执行的优化动作

## 现场分工与动线

| 岗位 | 活动前 | 活动中 | 活动后 |
|---|---|---|---|
| 总负责人 | 目标、预算、审批 | 决策与异常升级 | 复盘拍板 |
| 策划 | 流程、物料、供应商 | 节奏与内容 | 报告归档 |
| 案场负责人 | 接待容量、人员排班 | 动线、秩序、口径 | 线索交接确认 |
| 置业顾问 | 邀约与客户画像 | 咨询、预约、需求记录 | 首触与分级 |
| 签到/数据岗 | 表单、来源码、字段 | 签到与实时统计 | 数据去重与报表 |
| 供应商 | 搭建、设备、服务 | 现场保障 | 撤场与结算 |

推荐动线：

```text
入口签到 → 活动主区 → 项目/主题体验 → 咨询区 → 预约/留电登记 → 离场提醒
```

动线设计以“少排队、能登记、能承接”为标准；不把客户强行截留在活动区，也不在未经授权的情况下采集额外信息。

## 线索承接与归因

```text
报名 → 签到 → 有效留电/授权 → 现场咨询 → 预约到访
→ L1-5分级 → {{24}}小时首触 → {{72}}小时复盘
```

### 线索表必备字段

| 字段 | 要求 |
|---|---|
| 来源码 | 每个渠道/活动入口唯一 |
| 客户标识 | 以授权范围内的最小必要信息记录 |
| 到场状态 | 已到场/未到场/取消/重复报名 |
| 关注点 | 预算、面积、区域、户型等客户主动提供的信息 |
| 后续动作 | 预约、资料发送、再次邀约或暂不跟进 |
| 负责人 | 明确到人，避免公海无人处理 |
| 首触时间 | 记录是否在规定时限内完成 |

### 复盘指标

| 指标 | 计算方式 |
|---|---|
| 报名到场率 | 实际到场 ÷ 有效报名 |
| 有效留电率 | 有授权有效留电 ÷ 实际到场 |
| 预约率 | 活动后预约 ÷ 有效留电 |
| 首触完成率 | 时限内完成首触 ÷ 应首触线索 |
| 单个有效留电成本 | 实际费用 ÷ 有效留电 |
| 单个到访成本 | 实际费用 ÷ 活动后到访 |

**数据纪律**：去重规则、统计时间、来源码和数据口径写进复盘表；不把重复签到、工作人员、供应商和无授权信息计入客户线索。

## 风险预案

| 风险 | 预防 | 现场处理 | 是否暂停活动 |
|---|---|---|---|
| 人数超承载 | 分时预约、人数上限 | 暂停入场并分流 | 可能 |
| 设备/停电 | 备用设备、纸质表 | 切换备用方案 | 视影响 |
| 天气/交通 | 提前预警、室内备选 | 通知改期或转场 | 视安全 |
| 客户投诉 | 统一口径、专人接待 | 记录、安抚、升级 | 视影响 |
| 价格/权益争议 | 只用批准版本 | 停止扩散，负责人确认 | 必要时 |
| 个人信息泄露 | 最小化采集、权限控制 | 立即隔离并上报 | 必要时 |
| 安全事故 | 消防、疏散、医疗预案 | 先救助、再上报 | 是 |

## 合规红线

1. 未取得预售许可证，不得通过活动收取认筹金、定金、诚意金、入会费或其他变相锁定款项。
2. 活动宣传不得使用极限词、虚假稀缺、未经批准的价格优惠、升值承诺、学区升学承诺或未核实的规划信息。
3. 不得以抽奖、礼品、团购或报名为名诱导客户提供超出必要范围的个人信息。
4. 名单采集须取得授权；不得购买、交换、私存、出售或向无关人员转交客户名单。
5. 不冒充政府、学校、银行、媒体或其他机构，不伪造嘉宾、合作方、成交数据和客户反馈。
6. 现场发生安全、资金、重大投诉或个人信息泄露风险时，先暂停相关动作并按项目应急链上报。

## 与其他技能的关系

- 蓄客期整体节奏与阶段排期 → `presale-marketing-sop`；本技能负责单场活动的落地执行
- 竞品活动与市场动态输入 → `competitive-intel-sop`
- 接待动线与需求记录 → `sales-reception-sop`
- 判客、分级和首触跟进 → `sales-lead-grading`
- 认筹后的开盘衔接 → `sales-opening-sop`
- 内容脚本、拍摄和账号运营工艺 → 内容线技能，本技能只管活动策略、组织与承接
