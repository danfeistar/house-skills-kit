# 营销活动组织 SOP（activity-organization-sop）

把地产单场活动从"办一场热闹"变成目标可定义、过程可控、线索可归因、结果可复盘的执行系统。

## 适用谁
- 策划：活动简报、流程表、预算编制与供应商对接
- 营销负责人：目标拍板、审批锁定、复盘验收
- 案场负责人：接待承载、人员排班、现场动线管理
- 置业顾问/客服：邀约、咨询承接、首触跟进

## 怎么用（AI 场景）
1. 输入活动目标、客群、预算上限、时间地点和阶段 → 输出完整活动方案
2. 输入已完成活动的原始数据 → 自动产出复盘表和优化建议
3. 输入已审批活动 + 突发事件（天气/超载/投诉） → 生成应对预案

## 输出纪律
- 每个活动只设一个主目标，无主目标不推荐
- 涉及价格、优惠、权益时，必须先经项目审批，不得代定政策
- 内容创作工艺（脚本/拍摄/剪辑）不在此重复，引用内容线技能
- 个人信息采集遵循最小必要和授权原则

## 与其他技能的关系
- 蓄客期整体排期 → presale-marketing-sop
- 竞品踩盘与情报 → competitive-intel-sop
- 接待动线与判客 → sales-reception-sop / sales-lead-grading
- 认筹开盘衔接 → sales-opening-sop
- 话术库 → sales-talk-library / sales-objection-handling
