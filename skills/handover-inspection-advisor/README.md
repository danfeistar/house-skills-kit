# 交房验收（handover-inspection-advisor）

交房是买方唯一一次有筹码提异议的时点。这个技能给的是**可打印的验收清单 + 可直接递交的问题清单模板**：先验后签、书面留痕、整改闭环。

## 适用谁
- 购房者本人：自己验、自己提异议（首选，最省钱）
- 置业顾问 / 客服岗：陪同验房按同一份清单走，客户诉求能闭环成工单
- 第三方验房师：当交付报告模板，结论可复核
- 房产自媒体 / 顾问：讲清"验房到底验什么"，不做玄学验收

## 怎么用（AI 场景）
1. "要交房了，我该带什么查什么" → Part 2 资料清单 + 工具清单（200 元内配齐）+ 拍照编号规则
2. "开发商要我签完字才给验房" → Part 1.1 先验后签怎么谈，签收房单时该注明什么
3. "验房从哪开始" → Part 3 公共部位先行（屋面/地下室/电梯），再进 Part 4 室内八大系统
4. "空鼓、渗漏怎么判" → Part 4.3 防水与 Part 4.5 空鼓，含闭水试验这一唯一提前发现防水失效的办法
5. "面积少了算不算违约" → Part 5.1 `area_error.py` 算误差比与补退金额（3% 红线）
6. "问题怎么提才有用" → Part 6.1 问题清单七列模板 + 6.2 留证 + 6.3 拖延时的三级升级
7. "这房子能不能不收" → Part 1.3 三种结论 + 6.4 什么情况下才有依据拒绝收房
8. "入住后发现渗漏还能找开发商吗" → Part 7 保修三要素（时间/书面/归属）+ 90 天节奏

## 输出纪律
- 面积与尺寸走命令：`area_error.py`（误差比与补退）、`efficiency.py`（得房率与套内单价对比）
- 交房应缴费用核对走 `newhome.py`（契税/登记费/维修基金/物业预存，逐项标来源）
- **一现象一条目**：位置 + 现象 + 判断标准 + 依据，不写"整体感觉不错"
- 只写能复现的：能拍照、能量尺、能放水试验的才算验收项；闭水试验这类要写清条件
- 保修期限、交付条件、物业费标准一律按合同条款与当地现行规定现查，并标注核对日期
- 结论三选一：**可以收房 / 整改后再收 / 存在不能收房的依据（写明依据）**

## 什么时候不要用我
这个技能只管"交房这一刻及之后的保修"，不管交易本身。用错场景会让你把力气花在不该花的地方：

- **还在走过户、定金、赎楼、网签** → `resale-transaction-sop`（交房只是它第 12 个节点）
- **还没买，在算买得起买不起、月供多少** → `buyer-first-home-advisor` + `calc-toolkit/capacity.py`
- **要核对新房交易成本与应缴费用全貌** → `calc-toolkit/newhome.py`（本技能只核交房环节那几项）
- **收房后打算出租要算租金回报** → `owner-rental-advisor` + `rent.py`
- **要结构安全鉴定、防水闭水专业检测、甲醛检测** → 有资质的检测机构；本技能只给自检项与判断标准，不出鉴定结论

本技能不提供政策数字与法律结论：保修期限、交付条件、面积误差的具体适用与诉讼主张，一律按合同条款与当地当期规定现查，必要时咨询律师。
