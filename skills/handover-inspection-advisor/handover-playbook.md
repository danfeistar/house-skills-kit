# 交房验收作业手册（handover-playbook）

> 七 Part 从"收到交房通知"到"入住后 90 天"。清单可直接打印带到现场。
> 政策与保修期限一律按合同条款与当地现行规定现查，本手册不给任何城市的年限数字。

---

# Part 1 验收三条底线与程序

## 1.1 三条底线

1. **先验后签**：签字收房意味着对交付状态的确认。合同或交房通知里写"先签字再验房"的，先谈程序：请求"验房后再签收房单"，或"签字仅表示收到通知，不代表验收合格"，并在单据上注明。
2. **书面留痕**：所有问题进问题清单，递交时留收件证据（收件人签字、盖章回执、拍照、快递单）。**口头反映不构成主张。**
3. **整改闭环**：每条问题要有"要求完成时间 + 复验安排"，不接受"我们会处理"这种无时限答复。

## 1.2 现场程序（建议固定成七步）

1. 核对交房通知书、身份证、购房合同、付款凭证
2. 索取并核对"交付标准说明书 / 竣工验收备案证明"（能提供的部分）
3. 领钥匙、水电气卡、门禁卡，当场点数
4. 按 Part 3 → Part 4 顺序验收（公共部位先看，室内后看）
5. 现场填问题清单，双方各留一份
6. 谈整改时限与复验时间，写入清单
7. 决定是否签收房单；若签，注明"整改事项见附件清单"

## 1.3 三种收房结论（现场就要定，别含糊）

| 结论 | 适用情形 | 后续动作 |
|---|---|---|
| **可以收房** | 无影响使用的缺陷，或仅表面瑕疵 | 签收房单，清单里的表面问题仍要求整改 |
| **整改后再收** | 有影响使用的缺陷（渗漏、无水电、门窗无法闭合） | 不签收房单或注明保留，约定复验日期 |
| **存在不能收房的依据** | 未达到合同约定的交付条件（如缺备案、配套未完成） | 书面提出拒绝收房，要求书面答复；必要时咨询律师 |

**翻车警示**
- ❌ 没看交付条件就签字 → 后续发现未达交付标准，已签的收房单成为对方抗辩证据
- ❌ 问题只发微信语音 → 无凭据，整改优先级永远排在最后
- ❌ 复验时只看"改没改"，不核对"改得对不对" → 表面补平、内部渗漏照旧

# Part 2 到访准备：资料与工具

## 2.1 资料清单（缺一样现场就会卡）

- 身份证、购房合同（原件）、付款凭证/发票、交房通知书
- 户型图（带尺寸）、合同附件里的交付标准与品牌清单（精装房必带）
- 合同里关于面积、层高、赠送空间的条款页（拍照存手机也行，但要知道在哪一页）
- 前期与销售的沟通记录（尤其涉及"赠送/可改/品牌"的部分）

## 2.2 工具清单（200 元内配齐）

| 工具 | 用来查什么 |
|---|---|
| 卷尺（5m 以上） | 开间、进深、层高、门窗洞口 |
| 空鼓锤（或螺丝刀柄） | 墙地面空鼓 |
| 手电筒 | 阴角、管井、吊顶内部 |
| 插座检测器（十几元） | 缺地线、零火接反、无电 |
| 小水桶 / 矿泉水瓶 | 地漏排水坡向、排水通畅 |
| 纸巾 / 手纸 | 管道接口渗水（贴上看是否洇湿） |
| 记号笔 + 便利贴 | 现场标记问题位置 |
| 手机（拍照/录像） | 每处问题至少一张全景 + 一张细节 |

## 2.3 拍照编号规则（决定了后面能不能举证）

`位置-项号-序号`，例如 `客厅-墙面空鼓-01`。**每张照片必须带参照物**（门框、开关、插座），否则日后无法证明是哪一面墙。

**翻车警示**
- ❌ 只带手机不带队尺 → 层高、开间全靠目测，谈不出结论
- ❌ 照片不带位置信息 → 整改时对方说"这处不是我们交的房"
- ❌ 精装房不带品牌清单 → 无法核对交付品牌与型号

# Part 3 公共部位与入户前检查

## 3.1 公共部位（决定这套房未来的居住质量，最容易被跳过）

| 部位 | 查什么 |
|---|---|
| 单元门 / 门禁 | 能否正常闭合上锁、对讲是否可用 |
| 电梯 | 运行是否平稳异响、层站显示、轿厢照明与通风、年检标识 |
| 楼道与消防通道 | 疏散宽度、有无堆物、消防栓箱是否完整、应急照明 |
| 外立面与公区墙面 | 开裂、渗水痕、砖缝空鼓、涂料起皮 |
| 地下室 / 车库 | 渗漏与积水、排水沟是否通畅、顶板有无渗痕 |
| 屋面（能上则上） | 排水口是否堵塞、防水层是否破损 |

## 3.2 入户前

- 门牌号与合同一致；入户门开合顺畅、锁具顺畅、门框与墙体之间无缝隙漏风
- 门外公共区域是否有明显渗漏、管道井是否有异味
- 燃气表、水表、电表编号记录（交房当天读数拍照，作为欠费分界）

## 3.3 为什么先看公共部位

公共部位的缺陷（屋面渗漏、地下室渗水、电梯故障）**整改成本高、周期长**，且直接影响入住。签约时很难发现，交房时是唯一的窗口。

**翻车警示**
- ❌ 直接进自家门，公共部位一眼不看 → 入住后发现屋面渗漏，责任在开发商但已错过集体维权窗口
- ❌ 不记录水电燃气表读数 → 上一手或施工期的费用算到你头上
- ❌ 电梯年检标识过期不反映 → 后续停梯风险由业主承担

# Part 4 室内八大系统实测（60~90 分钟）

## 4.1 给水与排水

- 所有龙头、花洒：出水是否正常、水压是否够（同时开两个龙头看衰减）
- 台盆、洗菜盆、马桶：接口是否渗漏（纸巾贴接口，5 分钟后看是否洇湿）
- **地漏**：倒一瓶水，看排水速度与坡向（水是否往地漏流），有无返味
- 排水立管：检查检修口是否渗水、是否有异味冒泡

## 4.2 电气

- 用插座检测器逐个插：**缺地线、零火接反、无电**三类问题一次测出
- 配电箱：分路标识是否清晰、漏电保护是否动作（按试验按钮）、总容量与合同是否一致
- 开关：每个回路逐个开合；双控位置是否按图纸
- 弱电：网线口是否通（带个笔记本或测线仪）、电视口、对讲

## 4.3 防水与渗漏（最贵的一项）

- 卫生间、厨房、阳台的**阴角、管根、地漏周边**是否有渗水痕、返碱、发霉
- 楼上同位置有无渗漏痕迹（顶板水渍是最直接的证据）
- 外墙内侧是否有水渍、涂料起皮（对应外立面的渗漏点）
- 有条件时要求做**闭水试验**（蓄水 24~48 小时后看楼下顶板），这是唯一能提前发现防水失效的办法

## 4.4 门窗

- 开合是否顺畅、有无异响、锁点是否对齐
- **气密性**：关窗后夹一张纸，抽不出来才算合格
- 玻璃：是否有划痕、气泡、3C 标识；双层中空是否进水雾
- 窗台与窗框周边：打胶是否连续、有无渗水痕（下雨后复验最准）

## 4.5 墙地面空鼓与开裂

- 空鼓锤逐面墙扫（重点：**梁下、柱边、门窗洞口两侧、烟道周围**）
- 单块砖空鼓面积和整面墙的空鼓比例都要记；空鼓会掉砖、也会导致后期瓷砖脱落
- 裂缝：区分发丝裂缝（常见）与贯穿裂缝（需专业判定）

## 4.6 层高与开间

- 每个房间测 3~5 点层高（中心 + 四角），记录最小值
- 开间与进深按合同户型图核对；**测得尺寸与图纸差异要写进清单**，不要口头说"感觉小了"

## 4.7 通风与烟道

- 厨房烟道：点火或放一张纸在烟道口，看是否吸附（说明排风通路正常）
- 卫生间排气道同样方法；检查止回阀是否装、是否反向
- 开启外窗看对流是否顺畅（塔楼单面户型尤其要看）

## 4.8 附属与细节

- 栏杆高度与间距（安全项，按当地规定现查）
- 阳台排水、空调机位、冷凝水管
- 入户门与楼道的防火等级标识（高层住宅必查）
- 赠送空间（露台/储藏/夹层）：是否与合同描述一致，是否可合法使用

**翻车警示**
- ❌ 只看表面，不测水电 → 入住后才发现某路无电、地漏返味，整改要砸砖
- ❌ 不做闭水试验 → 漏水到楼下时，责任与维修费全在自己
- ❌ 空鼓只敲一面墙 → 剩下几面墙的砖在一年内陆续脱落
- ❌ 层高只量中间一点 → 梁下净高压头，吊顶方案全部作废

# Part 5 面积、层高与合同差异核对

## 5.1 面积差异先算误差比，再决定结论

```bash
# 合同面积 vs 产权登记面积：误差比 + 补退金额 + 法定依据
python3 skills/calc-toolkit/area_error.py --contract {{合同面积}} --final {{产权登记面积}} --price {{合同单价}}
```

判定口径（工具会自动给出适用条款）：
- 误差比在 **3% 以内（含）**：据实结算，多退少补
- 超出 3%：买方可主张解除或按约定处理；**合同另有约定的从约定**，但"只多退少补、免除其他责任"这类条款可能被认定为不公平条款

**面积缩水的真实影响**：不是那几万块差价，而是**套内实际使用面积变小**。建筑面积不变而公摊变大的情况，走的是"公摊系数"路径，判断要看合同与实测报告，不要只比总面积。

## 5.2 得房率与套内单价（两个盘比价时用）

```bash
# 建面价相同时，得房率高的实际更便宜
python3 skills/calc-toolkit/efficiency.py --mode compare --label-a {{A盘}} --rate-a {{A盘得房率}} --price-a {{A盘建面单价}} --label-b {{B盘}} --rate-b {{B盘得房率}} --price-b {{B盘建面单价}}
```

## 5.3 层高与赠送面积

- **层高**：合同写"层高 2.9m"指的是结构层高，净高要扣楼板与找平层，实测净高比层高少 10~15cm 属正常区间；差异过大必须书面提出复测
- **赠送面积**（露台、储藏、夹层）：通常不计入产权面积，交付缩水无法按面积误差主张，只能按"与合同/宣传不符"的违约路径处理。**所以签约时就要求把赠送的尺寸、位置写进合同附图**

## 5.4 交房环节的费用核对

```bash
# 一手房交易成本：契税 + 登记费 + 维修基金 + 物业预存（逐项标来源）
python3 skills/calc-toolkit/newhome.py --price {{合同价}} --area {{建筑面积}} --first {{1|2|3}} --city {{城市}}
```

核对要点：维修基金按什么标准收、物业费预存几个月、是否代收其他费用（代收必须给票据）。

**翻车警示**
- ❌ 面积少了就算钱，不算套内 → 客户以为拿了补偿，实际使用面积永久缩水
- ❌ 把"层高"当"净高" → 与实测对不上时误判开发商违约
- ❌ 赠送面积只听销售说 → 交付时缩水，无任何书面依据可主张
- ❌ 代收费用不给票据直接交 → 后期无法核对也无法追讨

# Part 6 问题清单写法与整改交涉

## 6.1 问题清单的七列（可直接照抄成表格）

| # | 位置 | 现象 | 判断标准 / 合同依据 | 要求整改内容 | 要求完成时间 | 照片编号 |
|---|---|---|---|---|---|---|
| 1 | 客厅东墙 | 空鼓约 0.6㎡（梁下） | 空鼓需铲至基层重做 | 铲除重抹并复测 | {{日期}} | 客厅-墙面空鼓-01 |
| 2 | 主卫地漏 | 排水缓慢、有返味 | 排水坡向不对/存水弯缺失 | 调整坡向、补装存水弯 | {{日期}} | 主卫-地漏-02 |

**写法纪律**：
- 现象必须**可复核**（尺寸、位置、现象三要素齐）
- 依据要么是合同条款，要么是行业通行的验收标准，不要写"我觉得"
- 整改要求写做法，不写"修好"（"铲除重抹"可验收，"修好"不可验收）

## 6.2 递交与留证

1. 现场填好 → 双方签字 → 各留一份
2. 同时以书面函件或官方 App 工单再递交一次（双重留痕）
3. 记录接收人姓名、岗位、日期；拍照留存
4. 约定复验时间（建议 7~15 天内第一次复验）

## 6.3 开发商拖延时的三级升级

| 级别 | 动作 | 目的 |
|---|---|---|
| 一级 | 客服/物业书面催办，抄送置业顾问 | 建立"已提出、未处理"的记录链 |
| 二级 | 向项目公司发正式函件（挂号信或 EMS，留存单号） | 形成可举证的催告，为后续索赔铺路 |
| 三级 | 向当地住建/房管部门反映、或依合同约定主张违约责任、咨询律师 | 引入第三方与合同救济 |

## 6.4 能不能拒绝收房

- **有依据才可以**：未达到合同约定的交付条件（缺竣工验收备案、配套未完成、无水电），书面提出拒绝收房并要求书面答复
- **只有瑕疵不建议拒绝**：空鼓、门窗、表面问题属于"可整改瑕疵"，拒绝收房容易被认定买方违约，正确做法是**收房 + 保留整改主张 + 保留尾款/押金**

**翻车警示**
- ❌ 清单只写"墙面有问题" → 无法定位、无法验收、无法举证
- ❌ 口头催办十次不留痕 → 法律上等于没催过
- ❌ 因为空鼓拒绝收房并停付尾款 → 可能被认定违约，反被追责
- ❌ 整改完成后不复核就签字确认 → 后续再出问题，对方一句"你已确认"结束

# Part 7 收房后 90 天：保修主张与救济路径

## 7.1 90 天内必须做的事

1. **第 1~7 天**：把现场遗留问题清单再核一遍，有没有新增（空置期暴露的渗漏往往在这时出现）
2. **第 1 个月**：下雨后复验外墙内侧、窗台、顶层顶板（雨天是唯一真实的防水测试）
3. **第 2 个月**：装修前做一次二次验收（拆改前的原始状态取证，避免后期争议归因不清）
4. **第 3 个月**：核对整改完成情况，逐条销项；未完成的按 Part 6.3 升级

## 7.2 保修主张的三个要素

| 要素 | 要什么 |
|---|---|
| 时间 | 发现问题的时间要能证明（照片时间、报修记录） |
| 书面 | 报修必须有书面记录（App 工单、报修单、函件） |
| 归属 | 属于保修范围（施工质量）还是使用不当/装修造成，这条决定谁出钱 |

**保修期限按合同条款与当地现行规定现查**（主体结构、防水、管线、设备各有不同），本手册不给具体年限数字。

## 7.3 常见争议与判断

- **渗漏到楼下**：优先止漏，再定责任；装修前的渗漏一般归施工质量，装修后的破坏归业主
- **墙面开裂**：发丝裂缝（腻子层）与贯穿裂缝（结构）处理方式完全不同，后者需专业鉴定
- **返味**：多为地漏缺水封、存水弯缺失、烟道止回阀失效，属可整改项
- **空鼓脱落**：已过装修期的，需证明原始空鼓（用交房照片/验收清单）

## 7.4 空置期与费用

- 物业费起算时间按合同与当地规定，空置期是否打折按当地现行口径现查
- 出租前用 `holding.py` 算持有成本，用 `rent.py` 算租金回报，避免"买了就空着"

```bash
# 自住/出租的持有成本与净回报（含空置、税费、维护）
python3 skills/calc-toolkit/holding.py --price {{总价}} --city {{城市}}
```

**翻车警示**
- ❌ 收房后立刻装修，不留原始状态证据 → 后续渗漏责任无法界定
- ❌ 只打电话报修 → 保修期内也拿不出报修时间证据
- ❌ 把装修造成的问题当施工质量主张 → 被驳回后连原有的人情渠道也断了
- ❌ 空置不报备不缴费 → 产生滞纳金甚至影响产权相关手续
