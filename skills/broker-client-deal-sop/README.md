# broker-client-deal-sop（二手房客户匹配与成交 SOP）

二手房经纪客户端全链：需求澄清 → 配房排序 → 带看动线 → 双线议价 → 签约过户交房 → 风险核验 → 佣金争议。

## 适用谁
- 二手房经纪人：客户对接、配房、带看、议价、签约推动
- 门店经理：议价审批、合同复核、僵局出面
- 交易专员：网签、资金监管、贷款、过户、交房交接

## 怎么用（AI 场景）
1. 新客户进店 → Part 1 七问（一轮不超过三问）+ 首付四笔漏算 + 资格预判
2. 配房 → Part 2 三维打分（硬约束过滤 / 软需求加权 / 风险扣分），每套必带"代价"
3. 带看 → Part 3 一场三套（锚定·主推·备选）+ 二选一话术 + 不表态四因排查
4. 卡价 → Part 4 双边动机拆解 + 让步阶梯（每让必换）+ 僵局三破法
5. 签约过户 → Part 5 七步流程 + 交房五交接
6. 签约前 → Part 6 九类风险逐条核验（每条要有纸或截图）
7. 佣金争议 → Part 7 口径四件事 + 私下签怎么回 + 处理流程

## 输出纪律
- 全部数字调 `calc-toolkit`：二手交易全成本、税费、月供、公积金额度、贷款年限、佣金提成，不口算
- 税费/限购/学位/落户口径一律"按当地当期公告现查"，本技能不提供任何城市具体数字
- 不承诺贷款能批、不承诺学位与落户；资格判断只给"大概率/以官方核验为准"
- 任何建议输出后过合规红线（阴阳合同/代收代付/隐瞒重大情形/诱导违约）
