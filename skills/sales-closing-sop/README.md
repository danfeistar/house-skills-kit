# sales-closing-sop（算价与逼定 SOP）

案场成交端完整动作链：算价 → 博弈 → 逼定 → 成交，含团队配合逼定（顾问×顾问、顾问×主管）。

## 适用谁
- 置业顾问：算价演示、议价应对、逼定收口
- 销售主管/经理：审批配合、二次逼定、压轴成交
- 案场负责人：统一口径与配合纪律

## 怎么用（AI 场景）
1. 客户坐下算价 → 按 Part 1 动作链铺单、Part 2 让步梯度博弈
2. 出现购买信号 → Part 3 判读信号组合 → Part 4 选对应分级话术
3. 单兵推不动 → Part 6 触发配合：同伴挽客 / 请示主管 / 经理压轴
4. 成交收口 → Part 5 认购动作 + 离场情绪管理
5. 演练/复盘模式见 SKILL.md

## 输出纪律
- 所有价格/月供/税费数字调 calc-toolkit 出数（不口算、不编造）
- 优惠承诺必须标注“走真实审批链”；稀缺话术必须可验证
- 谈判话术输出后自动过合规红线（虚假优惠/虚假稀缺/威胁/挑拨/淡化负债）
