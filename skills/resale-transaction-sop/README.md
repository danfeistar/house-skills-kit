# 二手房交易全流程与风险（resale-transaction-sop）

一套二手房从看中到拿钥匙，要跨 12 个节点、动三方、经手五笔钱。这个技能给的是**可打印的交易时间轴 + 风险排查表**，不是流程科普。

## 适用谁
- 二手经纪机构 / 门店：新经纪人上手的作业手册，店长盯节点管控
- 独立经纪人 / 合作单：判断卡点在哪、这单的风险该不该接
- 买方 / 卖方（自助交易）：每一步该准备什么、哪些钱不该先付
- 房产自媒体 / 顾问：讲清"这单为什么卡住了"，而不是笼统说"流程很长"

## 怎么用（AI 场景）
1. "二手房要走哪些流程、要多久" → Part 1 十二节点表 + 时间轴的正确写法（不给死天数）
2. "定金交了能退吗" → Part 3.1 三个"金"的区别 + `deposit.py --mode penalty` 算双倍返还
3. "卖家房子还有贷款，怎么弄" → Part 2.3 赎楼三条路，收谁出钱、买方垫资的两种安全条件
4. "合同怎么签才不踩坑" → Part 3.2 必写 12 条，逐条对客户念一遍
5. "贷款批不下来怎么办" → Part 4.4 三种走向，强调必须写进合同第 5 条
6. "税费谁承担、大概多少钱" → Part 5.1 买方卖方分列 + `tax.py` 出数并标核对日期
7. "交房要注意什么" → Part 6.2 交房六件事确认单 + 尾款保留条款
8. "房子被查封了／卖家反悔了" → Part 7 按现场类型直接取补救路径

## 输出纪律
- 金额一律走命令，不口算：`tax.py`（全成本，买卖分列）、`deposit.py`（定金罚则/逾期违约金）、`mortgage.py`（月供）、`fund.py`（公积金额度）、`loanterm.py`（房龄与年限）、`status.py`（首套二套三口径）、`area_error.py`（面积误差）、`commission.py`（中介费与分佣）
- **税费必须买卖分列**，逐税种写清谁承担；合在一起报一个"总税费"客户会认为你在藏钱
- **不给死天数**：写"取决于 X"，并注明以当地经办部门为准；"包过户、45 天拿证"这类话不做承诺
- 政策口径（限购、限售、税费优惠、公积金、网签与资金监管）一律按当地当期公告现查，并标注核对日期
- 权属结论只认登记簿：**签约前查过一次不等于过户那天还干净**，过户前复检
- 涉及法律责任只写规则与后果，不写"一定能赢"

## 什么时候不要用我
这个技能只覆盖"已经谈成、要把交易安全办完"这一段。用错场景会把责任边界搞反：

- **还在找房源、要签委托或独家** → `broker-listing-sop`（本技能从"看中"之后开始）
- **还在议价、客户犹豫、要比不同房源** → `broker-client-deal-sop`（议价策略与带看节奏在那边）
- **房子打算出租而不是出售** → `broker-lease-sop`（租赁的押付、退租、维修责任是另一套）
- **交房时的专业验收（空鼓、渗漏、门窗、水电）** → `handover-inspection-advisor`（本技能只给交房动作清单）
- **新房（一手房）交易流程** → 走案场线 + `calc-toolkit/newhome.py`，一手没有卖家赎楼、个税与增值税
- **要正式法律意见、诉讼代理、税务筹划** → 律师事务所 / 税务师事务所；本技能只给流程与判断

本技能不提供政策数字与法律结论：限购、限售、税率、优惠档与公积金口径一律按当地当期公告现查，并标注核对日期。
