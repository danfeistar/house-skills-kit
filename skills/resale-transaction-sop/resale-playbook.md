# 二手房交易作业手册（resale-playbook）

> 七 Part 从"看中一套房"到"拿到钥匙"。所有金额走 `skills/calc-toolkit/`，不口算。
> 政策数字一律按当地当期公告现查：本手册只给流程、判断和话术，不给任何城市的税费、限购、限售数字。

---

# Part 1 交易全景：12 个节点、三方责任与时间轴

## 1.1 十二个节点（顺序不能乱）

| # | 节点 | 谁做 | 产出 | 能否跳过 |
|---|---|---|---|---|
| 1 | 需求与资格预判 | 经纪人 + 买方 | 买方资格与贷款资质初判 | 不能 |
| 2 | 看房与初筛 | 经纪人 + 买方 | 房源与需求匹配结论 | 不能 |
| 3 | 权属查档 | 经纪人 / 卖方 | 登记簿摘要、抵押与查封状态 | **绝不能** |
| 4 | 议价与成交条件 | 双方 + 经纪人 | 成交价、税费承担、交房时间 | 不能 |
| 5 | 签居间/买卖合同 + 付定金 | 双方 | 合同、定金收据 | 不能 |
| 6 | 网签备案 | 经纪人 / 交易中心 | 网签合同 | 不能（多数城市强制） |
| 7 | 资金监管 | 双方 + 监管机构 | 监管协议、首付款入账凭证 | 视当地要求，能进就进 |
| 8 | 贷款申请与面签 | 买方 + 银行 | 受理单、评估报告 | 全款可跳 |
| 9 | 批贷 | 银行 | 批贷函 | 全款可跳 |
| 10 | 抵押注销 / 赎楼（卖方） | 卖方 + 担保方 | 注销证明 | 无抵押可跳 |
| 11 | 缴税与过户 | 双方 + 税务 + 登记中心 | 完税凭证、受理单 | 不能 |
| 12 | 放款、交房、水电物业户口过户 | 银行 + 双方 + 物业 | 交房确认单、过户回执 | 不能 |

**时间轴的正确写法**：不写"大约 45 天"，写"第 3 节点前必须完成查档；第 8 到第 9 节点的时长由银行审批决定；第 10 节点若需赎楼，由担保方放款节奏决定"。给死天数等于给承诺。

## 1.2 三方责任边界（出事时先看这一张）

| 主体 | 必须做 | 不负责 |
|---|---|---|
| 卖方 | 权属真实、无隐瞒抵押查封、按时注销抵押、按时迁出户口、按约定交房 | 不负责买方贷款资质 |
| 买方 | 资格与征信真实、按约定付款、按约定办理贷款、按时接收房屋 | 不负责卖方赎楼（除非合同约定垫资） |
| 经纪机构 | 核验与告知、如实披露已知瑕疵、协助办理、保管交易资料 | **不承担产权瑕疵担保责任**，也不承诺贷款获批 |

**这张表的价值**：客户吵起来时，先定位"这是谁的责任"，再谈解决方案。把三方责任混在一起谈，最后一定是经纪人背锅。

## 1.3 一句话流程版（给客户的第一条回复）

> 先查档（能不能买、有没有抵押查封）→ 谈妥条件签合同付定金 → 网签并把钱进监管 → 买方办贷款 → 卖方注销抵押 → 缴税过户 → 银行放款 → 交房过户水电物业。**没有查档和资金监管这两步，先别付大钱。**

**翻车警示**
- ❌ 先收定金后查档 → 房子有查封，定金要不回来，客户直接投诉
- ❌ 用"包过户、45 天拿证"当卖点 → 一次赎楼延误就变成违约承诺
- ❌ 三方责任不分，出事后按"谁收了中介费谁负责"处理 → 经纪人替产权瑕疵背锅

# Part 2 查档与前置资格（付任何钱之前）

## 2.1 查档查六项

1. **权属真实性**：权利人姓名、证件号与卖方身份证是否一致；证载面积与挂牌面积是否一致
2. **抵押**：有无抵押、抵押权人是谁、余额多少（余额决定赎楼金额）
3. **查封与限制**：司法查封、行政限制、异议登记、居住权登记——任何一项在，交易立即停
4. **共有情况**：登记簿"共有情况"栏；隐性共有（夫妻共同财产、继承未析产、代持）必须当面确认
5. **租赁**：买卖不破租赁，带租约的房子必须拿到租约原件与租客书面放弃优先购买权的确认
6. **限售与特殊性质**：房改房、经适房、回迁房、公寓、商业性质，各有不同的上市条件与税费档

**核查渠道**：当地不动产登记中心查询（权利人本人或授权查询）；线上政务平台可查的以平台为准。**不接受卖方手机里的截图作为唯一依据**——截图可能是旧的，也可能是别人的。

## 2.2 买方资格与资质（先判"能不能买"，再谈"买哪套"）

- **购房资格**：本地户籍/社保个税年限、家庭已有套数、限售期。按当地当期公告现查。
- **首套二套认定**：三套口径不同（商贷、公积金、契税），必须分开判，别用一句话回答"你是首套"。

```bash
# 三套口径一次判清（城市档 + 家庭套数 + 房贷记录）
python3 skills/calc-toolkit/status.py --city {{城市}} --local-homes {{本市住房套数}} --prior-loans {{全国房贷记录次数}}
```

- **可贷能力**：收入流水、征信、年龄、房龄四条线都会压额度。

```bash
# 房龄线 / 年龄线 / 公积金线三线取短，看哪一条在压你
python3 skills/calc-toolkit/loanterm.py --house-age {{房龄}} --age {{借款人年龄}} --mode commercial --city {{城市}}
```

## 2.3 抵押与赎楼：这一单最大的卡点

卖方有按揭未结清时，必须先注销抵押才能过户。三条路，选哪条决定风险归属：

| 方式 | 谁出钱 | 优点 | 风险 |
|---|---|---|---|
| 卖方自筹还清 | 卖方 | 干净、无额外费用 | 卖方拿不出钱就卡死 |
| 担保公司赎楼 | 担保方垫资 | 速度快 | 产生担保费，费用谁承担要写清；担保方会要求买方首付先进监管 |
| 买方首付垫资赎楼 | 买方 | 卖方容易接受 | **买方风险最大**：钱付了、过户失败，追偿困难 |

**纪律**：买方垫资赎楼只在两种情况下考虑——①资金进监管、由监管方按节点划付；②有银行或担保方书面介入。现金直付给卖方去还贷，一律不建议。

**翻车警示**
- ❌ 只查了"有没有抵押"，没查余额 → 赎楼金额算错，交易中途缺钱停摆
- ❌ 卖方说"我老婆同意"，但共有人没签字 → 合同效力被挑战，全部重来
- ❌ 带租约的房子没拿租客放弃优先购买权 → 过户后被租客起诉，买方和经纪一起被投诉

# Part 3 定金、居间与买卖合同

## 3.1 三个"金"的区别（客户必问，一次说准）

| 名称 | 法律效果 | 反悔后果 |
|---|---|---|
| **定金** | 担保合同履行，适用定金罚则 | 买方违约不退；卖方违约双倍返还 |
| 订金 / 意向金 / 诚意金 | 预付款性质，不适用罚则 | 一般原额返还（有约定从约定） |
| 押金 | 担保特定事项（如房屋损坏） | 按约定扣减 |

罚则算多少，用工具，别口算（定金超过合同总价 20% 的部分不产生定金效力）：

```bash
# 卖方违约：双倍返还；换 --breach buyer 就是买方违约不退
python3 skills/calc-toolkit/deposit.py --mode penalty --price {{合同总价}} --deposit {{实付定金}} --breach seller

# 逾期交房/逾期付款违约金（日万分之 N）
python3 skills/calc-toolkit/deposit.py --mode late --price {{合同总价}} --days {{逾期天数}} --rate-wan {{日万分之N}}
```

## 3.2 合同必写 12 条（缺一条就留一个坑）

1. 房屋坐落、证号、证载面积、附属设施（车位/储藏室是否含）
2. 成交价、付款方式与每一笔款的时间点、收款账户（账户名必须与权利人一致）
3. **定金条款**：金额、"定金"字样、交付凭证
4. **税费承担**：各自承担 / 一方承担，逐税种写明（不要写"税费由买方承担"一句了事）
5. **贷款条款**：拟贷金额、若批贷不足或未批的处理（自筹补足 / 解约 / 解约且互不追责），三选一必须选
6. **抵押注销与赎楼**：谁办、谁出钱、最晚完成时间、逾期的违约责任
7. **交房时间与标准**：毛坯/现状、随房交付的家具家电清单（品牌数量逐项列）
8. **户口迁出**：迁出时限 + 逾期违约金（按日计，才有约束力）
9. **租赁处理**：租约解除时间、租客清退责任方
10. **面积误差处理**：约定与法定兜底不一致时以哪个为准
11. **违约与解除**：根本违约的情形、解除权、违约金计算方式
12. **争议解决**：协商 / 诉讼 / 仲裁，管辖地

## 3.3 居间关系要说清的三件事

- 中介费**谁付、付多少、什么时候付**（签约付还是过户付），写进居间合同
- 中介的义务是"核验与如实告知 + 协助办理"，**不是担保产权无瑕疵、不是担保贷款获批**
- 佣金与分佣试算：

```bash
# 二手买卖：买卖双方费率 + 活动折扣 + 客户返佣 + 团队分佣
python3 skills/calc-toolkit/commission.py --scene resale --price {{成交总价}} --buyer-rate {{买方费率小数}} --seller-rate {{卖方费率小数}}
```

**翻车警示**
- ❌ 收据上写"订金"却按定金罚则谈 → 卖方反悔时要不回双倍，客户认为中介不专业
- ❌ 合同只写"贷款不批买方自行解决" → 买方凑不出钱就成了买方违约，定金吃掉，纠纷必起
- ❌ 家具家电写"保持现状" → 交房时家电被换，无清单无法举证
- ❌ 户口条款只写"卖方负责迁出"没写违约金 → 户口拖着不迁，买方拿不到任何补偿

# Part 4 网签、资金监管与贷款审批

## 4.1 网签的四个作用

1. 锁定交易（同套房不能重复网签）
2. 作为缴税与过户的依据（网签价通常就是计税依据）
3. 防止"一房二卖"
4. 部分城市把网签作为贷款受理前置

**注意**：网签价与真实成交价不一致（做低避税）属于违规行为，风险由双方自担：银行按网签价/评估价孰低放贷，做低后贷款额度跟着降，买方现金缺口反而变大；同时存在被税务追缴与处罚的风险。**不建议，也不要在客户面前把它当成"省钱技巧"。**

## 4.2 资金监管：能进就进

- 首付款进入监管账户，过户完成（或抵押登记完成）后按监管协议划给卖方
- 监管协议要看清三个点：**划付条件**（到什么节点划付）、**解付时限**、**争议时的处理方式**
- 全款交易同样建议监管，别用"我信任他"替代制度

## 4.3 贷款审批：五个常见不通过的原因

| 原因 | 表现 | 应对 |
|---|---|---|
| 评估价低于成交价 | 批贷金额按评估价算，差额要现金补 | 签约前先做评估预判，把差额写进付款计划 |
| 房龄超限 | 银行按房龄压缩年限或直接拒 | 签约前用 `loanterm.py` 算年限，别等受理后才知道 |
| 收入流水不足 | 月供/收入比不达标 | 提前 6 个月养流水；或用共同借款人 |
| 征信瑕疵 | 逾期、查询过多、担保记录 | 提前拉详版征信自查 |
| 公积金政策限制 | 套数、缴存月数、额度上限 | 用 `fund.py` 先算额度，别按商贷逻辑承诺 |

```bash
# 公积金可贷额度（四限取最低：账户余额/缴存月数/还贷能力/最高限额）
python3 skills/calc-toolkit/fund.py --city {{城市}} --family {{single|couple}} --balances {{账户余额}} --months {{连续缴存月数}} --price {{总价}} --first {{1|2}} --years {{年限}}

# 月供与组合贷
python3 skills/calc-toolkit/mortgage.py --price {{总价}} --downpay {{首付成数}} --years {{年限}} --mode commercial --city {{城市}}
```

## 4.4 批不下来的三种走向（必须在合同里选一种）

1. **自筹补足**：买方现金补差额，交易继续（要评估买方真实能力）
2. **无责解约**：双方解除，定金与已付款全额退还，互不追责（对买方最有利，卖方通常不同意）
3. **部分无责**：定金退一半 / 只退房款不退定金（折中，最常见）

**没写这一条 = 默认买方违约**，定金没收。这是二手纠纷里占比最高的类型。

**翻车警示**
- ❌ 经纪人替银行承诺"你这个肯定能批" → 批不下来时客户认定你误导
- ❌ 首付直接打给卖方"帮忙赎楼"，没走监管 → 卖方挪用，房没过户钱也没了
- ❌ 网签时按买方要求做低成交价 → 贷款额度下降、税务风险、合同效力争议三连
- ❌ 只算月供不算首付缺口 → 客户签约后才发现差 20 万现金

# Part 5 缴税与过户

## 5.1 税费：先算清"谁承担"，再算"多少钱"

税费金额由税种 × 计税依据 × 优惠档决定；**优惠档（满二、满五唯一、面积线、套数）按当地当期公告现查**。
三个必须分开问清的口径：①买方套数 ②卖方持有年限与是否唯一 ③房屋面积与性质。

```bash
# 二手房交易全成本（买方契税 + 卖方增值税/个税 + 各项费用；逐项标来源与规则版本）
python3 skills/calc-toolkit/tax.py --price {{成交价}} --area {{建筑面积}} --first {{1|2|3}} --held {{卖方持有年限}} --unique {{1|0}} --city {{城市}} --agent {{中介费率}}
```

卖方有未结清贷款时加 `--redeem`，买方贷款时加 `--loan`，工具会把赎楼担保费与评估抵押登记费一起算进去。

**输出纪律**：给客户的费用清单必须**买方、卖方分列**，并标注"按 {{核对日期}} 当地公告口径估算，最终以税务核定为准"。把两边的税混成一个"总税费"，客户会认为你在藏钱。

## 5.2 过户当天的动作顺序

1. 取号 → 提交材料（双方身份证、婚姻证明、合同、完税凭证、权证）
2. **卖方抵押必须已注销**（这一步没做完，窗口直接退件）
3. 缴税 → 取得完税凭证
4. 过户受理 → 领受理单
5. 领新证（或电子证照即时生成，按当地）

## 5.3 面积与合同不一致怎么办

过户前后出现面积差异（多见于房改房、老房、赠送面积），先判断误差比，再决定是补退还是解约：

```bash
# 3% 红线法定兜底口径：误差比 ≤3% 据实结算，超 3% 买方可主张解除
python3 skills/calc-toolkit/area_error.py --contract {{合同面积}} --final {{产权登记面积}} --price {{合同单价}}
```

**纪律**：面积差异的处理优先看合同约定；约定"只多退少补、免除其他责任"这类条款可能被认定为不公平条款，遇到时给出的建议是"以登记面积为准据实结算，并对差异部分主张相应权利"，不要替客户下"一定能赢"的结论。

**翻车警示**
- ❌ 只算买方税费，卖方个税/增值税没算 → 卖方当场拒付，交易卡在过户窗口
- ❌ 听过卖方一句"我满五唯一"就按优惠档报税费 → 系统一查不唯一，差额谁补？必吵
- ❌ 过户当天才发现抵押没注销 → 白跑一趟，双方情绪对立
- ❌ 用"做低成交价能省税"当卖点 → 违规且反噬贷款额度

# Part 6 抵押注销、放款与交房

## 6.1 放款的两个前提

- **买方侧**：过户完成 + 抵押登记完成（银行拿到他项权证/电子抵押权证）
- **卖方侧**：账户已注销原抵押（否则无法过户）

放款到账即触发尾款结算：监管资金按协议划付，中介费按居间合同结算。

## 6.2 交房当天的六件事（做成一张确认单）

1. **钥匙与门禁**：入户门、单元门、车库、信报箱、水电井钥匙
2. **水电燃气**：读表、当场结清、办理过户（拍照留底表数）
3. **物业与供暖**：物业费、供暖费、车位管理费的结清凭证；物业更名
4. **户口**：确认卖方户口已迁出（要求出示迁移凭证或户籍证明），未迁出按合同条款计违约金
5. **随房物品**：按合同清单逐项核对品牌数量，缺件当场记录并折价
6. **房屋现状**：拍照/录像存档（墙面、地面、门窗、固定设施），作为后续争议依据

## 6.3 尾款保留条款（保护买方的唯一抓手）

建议在合同中约定：**留 1~5 万元尾款（或按总价 {{比例}}），在户口迁出、水电物业结清、随房物品核对无误后支付**。
没有尾款保留，卖方交房后就失去配合动力——这是"户口不迁、欠费不结"无解的根因。

**翻车警示**
- ❌ 放款前就把钥匙交了 → 卖方拿到钱但不清户口、不结欠费，买方无抓手
- ❌ 水电物业不过户，只口头问"欠不欠费" → 交房后收到欠费单，原业主已联系不上
- ❌ 交房不拍照 → 后续发现渗漏、拆改，无法证明是交房前状态
- ❌ 尾款全部一次付清 → 合同里所有"逾期违约金"条款失去实际约束力

# Part 7 七类翻车现场与补救路径

## 7.1 查封（最严重）

- **发现时点**：查档阶段最好；过户前发现次之；付完钱发现最糟
- **动作**：立即停止付款 → 要求卖方提供查封原因与解除方案 → 书面通知解除合同并主张返还已付款与定金
- **注意**：查封常因卖方债务纠纷，钱一旦被挪用几乎无法追回。**唯一有效防线是查档 + 资金监管，不是事后追偿。**

## 7.2 共有人未签字

- 夫妻共同财产、继承未析产、代持，都属于隐性共有
- **动作**：要求全部共有人到场签字；确实无法到场的，办理公证委托
- **话术**："不是信不过，是过户窗口只认签字，少一个都过不了。"

## 7.3 租客不搬

- 买卖不破租赁：租约未到期，买方不能赶人
- **动作**：签约前取得租约复印件 + 租客书面放弃优先购买权 + 约定清退责任方与违约金
- **代价对比**：清退谈判的成本（补偿 1~3 个月租金是常见区间，按实际谈）远低于带着租客收房

## 7.4 户口不迁

- 户口不属于法院强制履行的常规范围，只能靠违约金与协商
- **动作**：合同约定按日违约金 + 保留尾款；交房时要求出示迁移凭证
- **提醒**：客户问"能不能强制迁出"，答案是"以当地公安与政策口径为准，先看合同违约金条款能不能逼对方配合"

## 7.5 面积与层高/赠送面积不符

- **动作**：用 `area_error.py` 判误差比 → ≤3% 据实结算，>3% 主张解除或按约定处理
- **赠送面积**：不计入产权，交付时缩水无法按面积误差主张，只能按"虚假宣传/违约"路径

## 7.6 卖方毁约（涨价不卖）

- **动作**：固定证据（合同、付款凭证、沟通记录）→ 主张继续履行或解除 + 违约金/定金罚则
- **工具**：`deposit.py --mode penalty --breach seller` 出双倍返还金额；有约定违约金的，比较两者取更有利的一条（**定金与违约金不能同时主张**）

## 7.7 贷款批不下来

- **动作**：看合同第 5 条属于三种走向的哪一种 → 按约定解约或自筹 → 若合同未约定，按买方违约处理
- **复盘**：把"评估价预判 + 房龄年限测算 + 征信自查"三件事前置到签约前，这一项事故率能降一半

**翻车警示**
- ❌ 出事后先谈情绪不谈责任 → 谁都不退让，最后全部损失由经纪机构兜
- ❌ 承诺"我们帮你打官司" → 超越服务边界，且结果不可控
- ❌ 用"私下再签一份协议"解决查封/共有人问题 → 规避登记，无效且可能构成违法
