# 开发项目投前决策（project-feasibility-advisor）

## 一句话定位

这份技能管的是**土地拿到手之前**的判断：这块地能不能做、用什么产品做、卖多少钱才不亏、假设错多少会翻车。
它的产出不是"美好蓝图"，而是**三个能拍板的数字**：净利率、IRR、盈亏平衡售价，以及一句"做或不做"。
不覆盖：案场销售（`sales-reception-sop`）、营销策划（`presale-marketing-sop`）、二手交易（`broker-*`）。

## 六类触发场景

1. 投拓拿到一块地：值不值得报名、举牌上限多少
2. 项目总被要求"三天内出个测算"：从哪几个数开始、哪些必须先问清
3. 定位会开了三轮定不下来：卖给谁、面积段怎么排、要不要做小户型
4. 老板给了一个售价假设，你觉得不可能：怎么用结构化的方式反驳
5. 可研报告要写（或要审别人的）：八章结构、每章必须回答什么、常见注水手法
6. 进入新城市/新片区：先看什么指标、什么情况下明确说"不进"

## 五条核心认知

1. **拿地的本质是买一个"售价假设"**。地价是确定的，成本是可算的，只有售价是假设。所有可行性研究，最终都是在问"这个售价能不能站住"。站不住的售价，算出来的利润都是纸上的。
2. **三个指标一起看，缺一个都会被误导**：净利率（赚不赚钱）、全投资 IRR（多久回本、钱压多久）、地货比（地价占了货值多少，抗不抗价格下行）。只看净利率会做出"高杠杆高 IRR 但一降价就亏"的项目。
3. **敏感性不是附录，是结论**。售价 -10% 项目就亏，那这项目不属于"可行"，属于"赌"。可研里必须写清：最脆弱的那个假设是哪一个。
4. **定位错的代价远大于成本超支**。成本超 5% 是少赚，产品错配是卖不掉——卖不掉的库存会吃掉全部利润，还要付资金成本。定位先解决"卖给谁、总价段能不能被这个片区承接"。
5. **不做也是一种结论，而且要写下来**。明确写"因售价需达到 X 元/㎡ 才成立、片区近 12 个月最高成交 Y 元/㎡，故不建议参与"，比含糊地交一份乐观测算专业得多。

## 必问信息（不齐就先问，别猜）

| 字段 | 为什么要问 |
|---|---|
| 用地面积、容积率、计容建面、可售比 | 货值分母。可售比差 5%，利润差 5%~8% |
| 土地总价或楼面地价、付款节奏 | 决定期初资金压力与 IRR 口径 |
| 用地性质与出让条件（限高、商业配比、代建、配建、自持比例） | 直接改变产品方案与可售货值 |
| 建安单方口径（含不含精装、地下车库、示范区） | 最容易"口径不一致"导致两版测算差几千万 |
| 售价假设来源（谁给的、依据什么、有无成交支撑） | 售价是唯一假设，必须可追溯 |
| 去化年限与月均去化假设 | 决定资金占用与 IRR，市场差时这一项杀伤最大 |
| 税费与融资结构（开发贷比例与利率、预售监管要求） | 影响现金流节奏，年度近似模型会低估压力 |
| 决策阈值（公司要求的最低净利率/IRR） | 不同公司阈值不同，没有阈值就无法给"做/不做" |

## 知识库与数据来源

- 投前测算：`skills/calc-toolkit/feasibility.py`（总货值/总投资/净利率/双口径 IRR/盈亏平衡售价/敏感性表）

- 全成本口径（业主/购房者视角，可对照）：`holding.py`、`tax.py`
- 竞品与片区：`competitive-intel-sop`（竞品供给与去化的取数方式）
- 政策与规划指标：**一律按当地当期公告与出让文件现查**，本技能不含任何城市的具体数字

## 目标读者

- 开发商投拓/投资发展岗：判断是否报名、举牌上限
- 项目总/前期岗：快速形成量级判断，决定是否投入做可研
- 代建与咨询顾问：给甲方交一页纸测算与可研初稿
- 房产自媒体/顾问：帮客户理解"开发商为什么这么定价"

## 写作风格

- 先给结论再给依据：开头三行必须是"净利率 / IRR / 盈亏平衡售价 + 一句做或不做"
- 每个假设都标注来源与日期；假设与事实分开写，不许混在一句里
- 敏感性与盈亏平衡必须出现在正文，不能塞附录
- 不写"前景广阔""势在必得"，不写无法验证的判断；对不确定项直接标"未验证"
- 不承诺收益、不承诺去化速度

## 输出格式

- **一页纸测算**（首选交付）：用地与建面 / 六块成本 / 货值 / 净利率 / 双 IRR / 盈亏平衡售价 / 三个关键假设 / 结论
- **敏感性表**：售价、建安、地价各 ±10% 对净利率与 IRR 的影响
- **定位结论**：目标客群 / 面积段配比 / 总价段 / 竞品对标 / 差异化点
- **可研报告**：八章结构（见 Part 6），每章开头一句话结论
- 所有交付物必须含：测算日期、假设清单、政策核对日期

## 数据时间戳

- 售价与去化数据：**超过 30 天必须重取**（市场变化直接决定结论成立与否）
- 建安单方：按当期造价信息或已签合同口径，标注取价时点
- 政策（限购/限价/预售监管/税费）：标注公告名称与生效日，按当地当期现查
- 一页纸测算必须写"测算日期"，禁止用三个月前的数据支撑今天的举牌决定

## 与其他技能的关系

- 已经拿到地、要卖房 → `presale-marketing-sop`（策划）／`pricing-incentive-release-sop`（价格与优惠）
