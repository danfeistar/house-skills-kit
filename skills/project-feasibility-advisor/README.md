# 开发项目投前决策（project-feasibility-advisor）

一块地拿到手之前要回答的三件事：能不能做、做什么产品、卖多少钱才不亏。产出是一页纸测算（净利率 / 双口径 IRR / 盈亏平衡售价 / 敏感性）+ 一句能拍板的结论。

## 适用谁
- 开发商投拓 / 投资发展岗：要不要报名、举牌上限多少
- 项目总 / 前期岗：三天内要一个量级判断，决定是否投入做可研
- 代建与咨询顾问：给甲方交一页纸测算与可研初稿
- 房产自媒体 / 顾问：讲清"开发商为什么这么定价"、"这个盘值不值"

## 怎么用（AI 场景）
1. "这块地拿不拿" → Part 1 基本等式 + 三个生死指标（净利率 / 全投资 IRR / 地货比）
2. "三天内出个测算" → Part 3 六块成本 + 必问信息表，缺的参数先问清再算
3. "定位定不下来" → Part 2 三问（卖给谁 / 总价段能不能被承接 / 和谁抢）+ 配比三约束
4. "老板给的售价我不信" → Part 4 三源锚定 + `feasibility.py --breakeven-only` 先算底线
5. "结论怎么写才敢交" → Part 5 敏感性 + 决策阈值表（建议参与 / 有条件参与 / 不建议）
6. "可研报告要写/要审" → Part 6 八章结构 + 六种注水手法对照表
7. "要不要进这个城市" → Part 7 四个指标（库存去化周期 / 人口产业 / 土地供应 / 政策环境）

## 输出纪律
- 金额一律走命令，不口算：`feasibility.py`（基准 + 敏感性 + 盈亏平衡）、`floor_price.py`（单方与楼面地价）、`area_error.py`（面积口径）
- **两个 IRR 必须同时给**：全投资 IRR 可对外引用，自有资金 IRR 只是杠杆上限——只报后者会被当成忽悠
- **单位纪律**：`--far` 是倍数、`--sellable-ratio` 是小数（0.95=95%）、`--other-pct/--admin-pct/--tax-pct/--finance-pct` 是百分数（15=15%）
- 面积换算：1 亩 ≈ 666.67㎡（60 亩 ≈ 40,000㎡），别用 600㎡ 的口算习惯
- 每个假设标来源与日期；假设与事实分开写；不确定项标"未验证"
- 交付物必须含：测算日期、假设清单、政策核对日期；禁止用三个月前的数据支撑今天的举牌决定

## 什么时候不要用我
这个技能只覆盖"土地到手之前"。用错场景会得到结构正确但方向错误的结论：

- **已经拿到地、要卖房** → `presale-marketing-sop`（策划）／`pricing-incentive-release-sop`（价格与优惠）
- **要看竞品在卖什么价、卖得多快** → `competitive-intel-sop`（本技能只给三源锚定的方法，不给取数通道）
- **判断客户买不买得起、月供压不压得住** → `buyer-first-home-advisor` + `calc-toolkit/capacity.py`
- **商铺 / 写字楼 / 公寓类地块** → `commercial-property-advisor`（商业的价值锚是租金，不是售价假设）
- **要正式可研、评估报告、税务筹划、融资方案** → 专业机构；本技能只给量级判断与结构化测算

本技能不含任何城市的具体政策数字：限购、限价、预售监管、税费一律按当地当期公告现查，并标注核对日期。
