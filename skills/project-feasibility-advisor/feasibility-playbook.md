# 投前决策作业手册（feasibility-playbook）

> 七步从"拿到一块地"到"一份能拍板的可研"。所有金额走 `feasibility.py`，不口算。
> 单位提醒：`--far` 是倍数、`--sellable-ratio` 是小数（0.95=95%）、其余费率是百分数（15=15%）。

---

# Part 1 拿地决策的基本等式与三个生死指标

## 1.1 一个等式，两个必须

> **净利润 = 总货值 － 总投资**
> 总货值 = 可售面积 × 售价　｜　总投资 = 土地 + 建安 + 其他 + 财务 + 管理营销 + 销售税费

必须分清两类：**确定项**（土地、建安、面积）与**假设项**（售价、去化年限）。结论的可靠性 90% 取决于假设项。

## 1.2 三个指标一起看

| 指标 | 怎么算 | 看什么 | 参考线（住宅，非硬标准） |
|---|---|---|---|
| 净利率 | 净利润 / 总货值 | 赚不赚钱 | ≥10% 稳健；8%~10% 偏薄；<0 不做 |
| 全投资 IRR | 硬成本期初投入、回款按年摊 | 钱压多久、回报效率 | ≥10% 可做；12%+ 才有竞争力 |
| 地货比 | 土地款 / 总货值 | 抗不抗降价 | <35% 相对安全；≥40% 靠售价硬撑 |

**为什么必须同时给两个 IRR**：自有资金 IRR（只投土地款、其余靠回款滚动）看着能到 30%，那是**杠杆上限**，不是承诺；对外汇报引用的应是全投资 IRR。工具两个都给，别只挑好看的那个。

## 1.3 什么时候该明确说"不做"

四个信号出现任意两个，就该给否定结论：

1. 盈亏平衡售价高于片区近 12 个月最高成交价
2. 售价 -10% 后净利率转负（没有安全垫）
3. 地货比 ≥40% 且去化年限 >3 年（钱压得久、地价又贵）
4. 全投资 IRR 低于公司资金成本

**翻车警示**
- ❌ 只用自有资金 IRR 报决策会 → 30% 的"好项目"实际全投资回报 11%，一旦融资收紧立刻停摆
- ❌ 用地面积与可售面积混用 → 60 亩（约 4 万㎡）×容积率 2.0 = 计容 8 万㎡，可售只有 7.6 万㎡，直接用 8 万㎡算货值会虚高 5%
- ❌ 先有结论再凑假设 → 敏感性能凑过去，但卖房时凑不过去

# Part 2 定位与产品配比

## 2.1 定位三问（按顺序，不许跳）

1. **卖给谁**：这个片区 5 公里内的主力购买人群是谁（首置/改善/投资/学区/养老），他们现在买在哪里、为什么买那里
2. **总价段能不能被承接**：片区近 12 个月成交总价段分布中，你的产品落在哪一段？如果落在"成交占比<10%"的段，必须先解释为什么
3. **和谁抢**：3 公里内在售竞品的面积段、总价、卖点、去化速度。你的差异化是"更好"还是"不同"——后者才有溢价

## 2.2 产品配比的三条硬约束

- **面积段服从总价段**：先定总价上限（片区可承接），再反推面积段；不要先画户型再定价
- **配比服从去化**：主力户型占比一般 50%~70%，极端户型（超大/超小）各不超过 15%，否则尾盘难清
- **限高与退线决定形态**：容积率 2.0 与 3.0 的产品逻辑不同（洋房+小高层 vs 高层为主），别拿一个方案套所有地

## 2.3 定位错的代价（量化）

若产品错配导致去化年限从 3 年拉长到 5 年：
- 财务费用按年增加（年化资金成本 × 未售货值）
- 售价假设要打折清尾
- 两项相加常把 15% 的净利率压到 5% 以下

**翻车警示**
- ❌ 用"我们产品更好"解释溢价，却没有竞品对比表 → 定价会被市场直接驳回
- ❌ 全做改善大户型 → 片区主力是首置，总价段直接脱靶，样板房再漂亮也没客户
- ❌ 商业配比按"政府要求的最低比例"机械执行 → 商业部分往往成为最难去化的库存，测算时要按"打骨折"假设

# Part 3 成本结构六块与易漏项

## 3.1 六块成本（对应工具的六个参数）

| 块 | 口径 | 工具参数 | 常见区间（住宅，按项目实际） |
|---|---|---|---|
| 土地 | 总价 or 楼面地价 × 计容 | `--land-price` / `--land-floor-price` | 决定地货比 |
| 建安 | 元/㎡ × 计容建面（含粗装） | `--build-cost` | 精装另计；地下车库按面积单算 |
| 其他 | 前期+配套+间接费，常按建安 % | `--other-pct` | 10%~20% |
| 财务 | 按（土地+建安+其他）% | `--finance-pct` | 3%~6%（看融资结构） |
| 管理营销 | 按销售额 % | `--admin-pct` | 4%~8% |
| 销售税费 | 按销售额 % | `--tax-pct` | 8%~14%（增值税附加+土增税+所得税综合） |

## 3.2 最常被漏掉的九项

1. 地下车库（建安与可售口径要分开：车位是单独货值）
2. 示范区与样板房（一次性投入，不可售）
3. 精装标准（毛坯与精装差 1,500~3,000 元/㎡，直接决定售价与成本两端）
4. 配建与代建（学校、社区用房、道路——只出成本不出货值）
5. 自持部分（商业/租赁住房，占用资金但不进当期货值）
6. 预售监管资金占用（回款不能立刻用，等于隐性财务成本）
7. 土地增值税清算（预征与清算差异大，清算是利润杀手）
8. 拆迁与土壤治理（旧改地块）
9. 营销渠道费（渠道佣金常 1%~3%，若单列则不要重复计入管理营销）

**翻车警示**
- ❌ 建安口径不一致（一个含精装一个不含）→ 两版测算差几千万，会上吵到散会
- ❌ 忘记配建 → 可售比被高估，利润凭空多出来
- ❌ 土增税按预征率当最终税负 → 清算时补税，项目利润被腰斩的常见原因

# Part 4 价格与去化假设怎么定

## 4.1 售价三源锚定（与二手估值同法，但看新房）

| 源 | 取什么 | 权重 |
|---|---|---|
| 3 公里内在售竞品**实际成交**（不是报价） | 同面积段、同装修档的成交单价 | 50% |
| 片区近 12 个月**二手房成交**（含房龄折价） | 校准"新房溢价"是否合理 | 30% |
| 土地出让时的**限价/备案价**规则 | 政策上限，硬约束 | 20% |

反向校验：用 `feasibility.py --breakeven-only` 先算"卖多少钱才不亏"，再看市场给不给这个价。**先算底线，再谈预期**。

## 4.2 去化年限怎么定

- 用竞品的**真实网签速度**（月均去化套数）反推：本项目可售套数 ÷ 片区月均可承受去化 = 月数
- 新片区没有竞品时，用"同能级城市相似片区首年去化"作参照，并把年限上调 30%
- 去化年限每多 1 年，财务费用与售价折让两层叠加，净利率通常掉 2~4 个百分点

**翻车警示**
- ❌ 用竞品"报价"当成交价 → 售价假设虚高 5%~10%，全投资 IRR 虚高 3~5 个点
- ❌ 去化年限按"公司要求"倒推（要求 3 年就填 3 年）→ 这不是测算，是许愿
- ❌ 忽略限价 → 政策上限低于你的售价假设时，整个模型作废

# Part 5 敏感性与决策阈值

## 5.1 一条命令跑完基准 + 敏感性

```bash
python3 skills/calc-toolkit/feasibility.py --land-area 40000 --far 2.0 \
    --land-floor-price 2500 --build-cost 3800 --price 11000 --sell-years 3
```

实测读数（60 亩 / 容积率 2.0 / 楼面 2,500 / 建安 3,800 / 均价 11,000 / 3 年去化）：

| 项目 | 数值 |
|---|---|
| 计容建面 / 可售 | 80,000㎡ / 76,000㎡ |
| 总货值 | 8.36 亿元 |
| 总投资 | 7.05 亿元（单方可售 9,281 元/㎡） |
| 净利润 / 净利率 | 1.31 亿元 / **15.6%** |
| 地货比 | 23.9% |
| 全投资 IRR / 自有资金 IRR | **11.0%** / 30.1%（上限） |
| 盈亏平衡售价 | **8,953 元/㎡**（安全垫 +22.9%） |

敏感性（同一条命令自动输出）：

| 情景 | 净利率 | 全投资 IRR |
|---|---|---|
| 售价 -10% | 8.0% | 5.2% |
| 建安 +10% | 11.3% | 7.6% |
| 地价 +10% | 13.1% | 9.0% |

读法：**售价是唯一能把项目从"可做"打到"勉强"的因子**（-10% 直接掉 7.6 个点），建安与地价各 ±10% 只影响 2~3 个点。所以谈判与决策的重点应放在"售价假设的证据强度"，而不是"能不能再压两百万建安"。

## 5.2 决策阈值表（写进一页纸，让老板拍板）

| 结论 | 条件（示例，按公司口径替换） |
|---|---|
| 建议参与 | 净利率 ≥12% 且 售价 -10% 后仍 ≥5% 且 地货比 <35% |
| 有条件参与 | 净利率 8%~12%，需满足：压建安 X 元/㎡ 或 地价降至 Y 元/㎡ |
| 不建议参与 | 净利率 <8%，或 盈亏平衡售价 > 片区近 12 个月最高成交价 |

**翻车警示**
- ❌ 敏感性只跑售价一个因子 → 漏掉"建安超支""地价竞到上限"这两个更常见的现实
- ❌ 把"自有资金 IRR 30%"写进决策材料 → 一旦被追问口径，整份测算的可信度归零
- ❌ 没有阈值表 → 汇报变成"形势很好，请领导决策"，等于没给结论

# Part 6 可研报告八章结构与注水手法

## 6.1 八章结构（每章开头一句话结论）

1. **项目概况**：地块位置、面积、容积率、出让条件、付款节奏
2. **市场研究**：片区供需、成交价与量、竞品清单、目标客群
3. **定位与产品方案**：客群/面积段/总价段/配比/差异化
4. **开发计划**：分期、开工与预售节点、去化节奏
5. **投资估算**：六块成本明细 + 单方指标
6. **财务评价**：货值与收入、利润表、现金流、净利率、双 IRR、盈亏平衡
7. **风险与敏感性**：三个关键假设的敏感性 + 政策/市场/资金三类风险
8. **结论与建议**：做/不做、条件、需要谁拍板

## 6.2 常见注水手法（审报告时逐条对）

| 手法 | 表现 | 怎么拆 |
|---|---|---|
| 售价取"最高竞品" | 引用单价最高、位置最好的竞品 | 要同面积段、同装修、近 3 个月成交均价 |
| 去化按理想速度 | 首开即售罄、后续恒速 | 要真实网签速度，首开数据单独看 |
| 成本口径偏窄 | 建安不含精装/车库/示范区 | 要单方构成表，逐项对 |
| 税费按预征 | 土增税只计预征 1%~2% | 要求补清算模型或敏感性 |
| 敏感性只做上行情景 | 只给"售价 +10%" | 必须给 -10% |
| 时间轴压缩 | 拿地 6 个月开盘 | 对照当地审批与预售条件 |

**翻车警示**
- ❌ 报告里假设与事实混写 → 读者无法判断哪句可验证，整份报告失去说服力
- ❌ 只给结论不给假设清单 → 复核无从下手，等于放弃专业身份
- ❌ 审别人报告时直接改结论 → 应先指出"哪个假设不成立、换成什么数、结论变成什么"

# Part 7 城市进入、片区风险与咨询边界

## 7.1 进入新城市先看四个指标

1. **库存去化周期**（月）：当地在售库存 ÷ 月均去化，超过 24 个月要极度谨慎
2. **人口与产业**：常住人口增量、主导产业与就业结构（决定购买力来源）
3. **土地供应节奏**：未来 2 年计划出让量（决定你的竞品供给）
4. **政策环境**：限购/限价/预售监管/公积金与补贴政策（决定去化速度与价格上限）

四项中任意两项不利，建议"不进"或"只做小体量试点"。

## 7.2 三类高频风险

| 风险 | 表现 | 对冲方式 |
|---|---|---|
| 政策风险 | 限价低于测算售价、预售条件收紧 | 售价假设取备案价上限，做 -10% 敏感性 |
| 市场风险 | 竞品集中入市、价格战 | 分期开发、首开小体量试水 |
| 资金风险 | 预售监管导致回款滞后 | 现金流按"回款滞后 6 个月"重算一遍 |

## 7.3 咨询边界（必须写在交付物里）

- 本技能输出是**量级判断与结构化测算**，不替代正式可研、不替代评估机构报告、不构成投资建议
- 不含城市具体政策数字：一律按当地当期公告现查，并标注核对日期
- 不对售价与去化做承诺；所有假设必须由委托方确认后使用
- 涉及土地出让合同、税务筹划、融资结构 → 律师/税务师/银行

**翻车警示**
- ❌ 拿外地经验给本地项目定价 → 片区差异极大，最容易被本地同行当场问倒
- ❌ 承诺"这个价肯定能卖" → 一句话把专业判断变成担保责任
- ❌ 交付件里出现未经核对的政策数字 → 一个过期数字毁掉整份报告的可信度

# 附：常用命令

```bash
# 一页纸测算（基准 + 敏感性）

    --land-floor-price 2500 --build-cost 3800 --price 11000 --sell-years 3

# 只问底线：卖多少钱才不亏

    --land-floor-price 2500 --build-cost 3800 --price 11000 --breakeven-only

# 土地总价已知时直接给总价
python3 skills/calc-toolkit/feasibility.py --land-area 40000 --far 2.0 \
    --land-price 200000000 --build-cost 3800 --price 11000

# 楼面价与货值（拿地视角，土地总价 + 亩数 + 容积率）

```

**面积换算**：1 亩 ≈ 666.67㎡，60 亩 ≈ 40,000㎡。别用 1 亩 = 600㎡ 这种口算习惯。
