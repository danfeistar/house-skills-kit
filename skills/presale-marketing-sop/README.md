# presale-marketing-sop（蓄客期营销动作清单）

蓄客期漏斗管理标准：分周总节奏 → 暖场/拓客/圈层/认筹预热四阶段动作库 → 自媒体蓄客专节 → 数据漏斗复盘 → 合规红线。

## 适用谁
- 策划：蓄客排期、动作组织、物料与活动协调、复盘输出
- 营销负责人：节点决策、预算分配、费效把关
- 拓客团队/置业顾问：动作执行、线索录入与承接
- 自媒体运营：项目号定位、内容日历、线索闭环

## 怎么用（AI 场景）
1. 输入开盘节点与蓄客目标 → 倒排四阶段窗口与分周动作框架
2. 输入当前漏斗数据 → 诊断薄弱层并推荐对应动作
3. 输入活动目的与预算 → 输出活动选型建议与执行清单
4. 输入项目基础信息 → 输出项目号定位与首月内容日历框架

## 输出纪律
- 所有动作必须标注漏斗归因层（触达/留电/到访/认筹），无归因不推荐
- 政策与数字用占位符，以项目当地现行规定为准
- 不输出任何违反预售证资金红线、广告法、个人信息保护的方案
- 内容创作只到策略层（定位/选题/日历），工艺层引用内容线技能

## 什么时候不要用我

这个技能有明确边界，用错场景会得到看似正确但方向相反的结论：

- **物料制作、示范区巡检与版本管理** → `marketing-materials-sop`
- **单场活动的执行与复盘** → `activity-organization-sop`
- **付费投放的预算与素材测试** → `template/modules/media-lead-growth.md.tmpl` 模块
- **单条短视频/图文的选题与脚本** → `property-media-creator`
- **开盘日案场动线** → `sales-opening-sop`

本技能不提供政策数字与法律结论：一律按当地当期公告现查。
