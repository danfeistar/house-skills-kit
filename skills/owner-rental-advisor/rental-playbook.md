# 出租业主 playbook · owner-rental-advisor

> 站在出租业主这一侧。目标是**现金流稳、纠纷少、房子不被糟蹋**，不是"租出全小区最高价"。
> 结构：玩法说明 → 示例 → 翻车警示。金额一律用 `skills/calc-toolkit` 出数，本文数字是示例口径。

---

## Part 1 该租、该卖，还是继续空着

### 1.1 毛回报与净回报（先算清再决定）

```bash
# 毛回报 + 净回报（空置 15%、税负 5%、维修 0.5% —— 都是百分数）
python3 skills/calc-toolkit/rent.py --price 1500000 --rent 3500 --net --vacancy 15 --tax-rate 5 --maint 0.5
```

实测口径（示例）：

```
总价 1,500,000 元 ｜ 月租 3,500 元（年租 42,000 元）
租售比 1 : 429（国际合理 1:200~1:300）
毛回报率 2.80%/年 ｜ 静态回收年限 ≈ 35.7 年
净口径扣减：空置15% × 税负5% − 维修0.5%/年
净年收益 26,415 元 → 净回报率 1.76% ｜ 回收 ≈ 56.8 年
```

**怎么读这个结果**：
- 净回报率 1.76% 低于五年期存款与商贷利率，说明这套房**不是靠租金赚钱的资产**，你真正在赌的是房价
- 如果你的月供（如 70 万贷款、3.1%）约 3,000 元，而实收租金 3,500×11/12 ≈ 3,208 元，**以租养贷基本打平**，但要留出维修与空置缓冲
- 若目标是"每月净现金流为正"，把净回报率算到 3% 以上才有意义——通常是降低买入价或提高租金，而不是换个说法

### 1.2 空置的真实成本

```bash
python3 skills/calc-toolkit/holding.py --area 89 --property 2.5 --price 1500000
```

示例输出：物业费 2,670 元/年；资金占用 23,250 元/年（按无风险利率口径的隐性成本）；**全成本约 25,920 元/年 ≈ 2,160 元/月**。

也就是说：**房子空一个月，成本约 2,000 元**（不算贷款）。这就是"再等等看能不能多租 200 元"的代价 —— 多空一个月，等于把未来 10 个月的涨价全赔进去。

### 1.3 出租 / 出售 / 继续空置三选一

| 选项 | 适合什么情况 | 关键测算 |
|---|---|---|
| 出租 | 不急用钱、片区租金有支撑、房子状况适合长期住 | `rent.py --net` 净回报 ≥ 你的资金机会成本 |
| 出售 | 净回报长期低于机会成本、房子老化、你不想再管 | `owner-sell-home-advisor` 的净得测算 |
| 空置等卖 | 房子要卖、带租约影响看房与贷款 | 空置成本 × 预计成交月数，与"带租约折价"对比 |

```bash
# 出租 vs 出售 vs 理财：10 年期末净资产对比（含月租 3500）
python3 skills/calc-toolkit/buy_vs_invest.py --price 1500000 --growth=-3,0,5 --rent 3500
```

实测输出（含租金）：房价年涨 -3% 时理财赢 41 万；0% 时理财仍略赢 1.7 万；5% 时买房赢 92.7 万。工具同时给出**打平涨幅 0.11%** —— 意思是这套房只要能维持极小幅升值，算上租金就不输 1.98% 的理财。**这是"卖还是留"最直接的一句话结论。**

> **翻车警示**：为了"保住卖相"空置一年等高价，结果价格没涨、空置成本吃掉 2.4 万 —— 这类决策一定要先把两个方案的成本都算出来再选。

## Part 2 租金定价与挂牌

### 2.1 三源租金锚点

| 锚点 | 怎么取 | 注意 |
|---|---|---|
| 同小区同户型**近三月真实成交租金** | 中介系统 / 平台成交记录 / 老租客口径 | 挂牌租金 ≠ 成交租金，通常高 5%~10% |
| 在租房源的**挂牌时长** | 平台"发布时间"推断空置时间 | 挂了 60 天还没租掉的，就是市场在告诉你价格太高 |
| 同类房源带家具 vs 不带家具价差 | 同小区对比 2~3 对 | 带家具通常高 8%~15%，但要扣折旧与维修 |

### 2.2 空置与降租的算术

- 目标月租 3,500 元，空置 1 个月 ≈ 损失 3,500 + 持有成本 2,000 ≈ **5,500 元**
- 降租 200 元/月、提前 1 个月租出 → 一年少收 2,400 元，但省下 5,500 元空置损失，**净赚约 3,100 元**
- 结论：**空置超过 3 周，就该考虑降租**；降租幅度按"一个月的空置成本 ÷ 剩余租期"来定

### 2.3 季节与人群周期

| 时段 | 客群 | 定价策略 |
|---|---|---|
| 春节后（2~3 月） | 换工作、返城、毕业实习 | 需求高峰，可贴近挂牌价 |
| 6~8 月 | 毕业季、家长陪读 | 次高峰，适合家庭与合租 |
| 9~10 月 | 开学后稳定期 | 平稳，适合长租客 |
| 11 月~春节前 | 淡季 | 空置风险高，优先"租出去"而不是"租高价" |

### 2.4 议价与让步方式

不要直接降价，先换条件：

| 租客要求 | 你的让步方式 |
|---|---|
| "能不能便宜 200" | 可以，但租期签 12 个月起、押二付三（按当地上限） |
| "能不能先押一付一" | 可以，但月租上浮，或要求稳定收入证明 |
| "空调太旧想换" | 我换，租金上调或租期延长 |
| "想早两周入住" | 可以，起租日提前，租金从起租日算 |

> **翻车警示**：为了"显得好说话"口头答应一切（可养宠、可转租、可随时退租），签合同时又没写进去 → 后面全是争议。**每一次让步都写进合同**。

## Part 3 房屋准备与合规

### 3.1 安全硬项（不达标不许出租）

- 电路：老房子查线路负荷与插座接地，避免空调/电暖器过载
- 燃气：燃气热水器排烟、管道与灶具连接，按规定定期检查
- 消防：烟感、灭火器（部分城市对出租房有明确要求）、疏散通道不堆物
- 渗漏与霉变：卫生间闭水试验、外墙与窗台渗水
- 装修污染：新装修房源建议做空气质量检测

### 3.2 隔断与群租红线

- 不得改变承重结构与主要功能空间（厨房、卫生间、阳台不得改作卧室）
- 不得违规隔断群租、不得超员居住（各地对人均面积有规定）
- 不得擅自改变房屋用途（住宅改商用、办公、仓储）
- 短租（日租/民宿）须符合当地规定与小区管理规约，多数小区规约禁止

### 3.3 家具家电投入回报

| 投入 | 参考量级 | 回报方式 | 建议 |
|---|---|---|---|
| 床、衣柜、桌椅 | 数千元 | 支撑"拎包入住"，月租可高 5%~10% | 家庭客重点投入 |
| 洗衣机、冰箱、空调 | 数千元 | 无空调的房子在很多城市直接筛掉一半客 | 优先保障 |
| 沙发、电视 | 视情况 | 提升观感 | 非必须，旧了反而减分 |
| 全屋新装修 | 数万元 | 需 3~5 年租期才回本 | 不建议为出租大装修 |

投入判断：**用租期覆盖投入**。预计租期 × 每月可提升租金 ≥ 投入成本 × 1.5，才值得投。

### 3.4 拍照与描述纪律

- 白天自然光横拍，每间房 1~2 张，必须含：客厅、卧室、厨房、卫生间、阳台、小区入口
- 描述写清：面积、楼层、朝向、家电清单、是否可拎包入住、周边交通与生活配套（用可验证的事实，如"步行 8 分钟到地铁 X 站"要实测）
- **红线**：不得美颜拉宽、不得用样板间图、不得写"绝对安静""绝不涨价"这类无法保证的表述

## Part 4 租客筛选与合同

### 4.1 合法筛选边界（先划清）

**可以核验**：身份真实性、收入与支付能力、既往租赁履约情况（如有可核验渠道）、入住人数与关系、是否养宠、是否吸烟、是否需要注册公司/办公

**不可以作为拒绝理由**：性别、年龄、民族、地域、婚姻状况、生育与怀孕情况、宗教信仰、残障（法律另有规定的除外）、携带儿童（不得以"带孩子"为由拒绝）

> 合规提问的方式：问"这套房住几个人、是什么关系、有没有宠物、是否需要在房里办公"，不要问"你结婚了吗、打算要孩子吗"。

### 4.2 材料核验清单

- 身份证原件核对（留存复印件或照片，注明用途）
- 工作与收入证明（劳动合同/工牌/近三个月流水，视情况）
- 入住人清单（姓名、关系、人数）
- 宠物情况（种类、数量、是否绝育、是否已免疫）
- 特殊需求（办公、注册、加装设备、同住老人/儿童）

### 4.3 押金与租金条款（数字按当地上限）

| 条款 | 怎么写 |
|---|---|
| 押金金额 | 按当地规定上限，写明"押金用于抵扣欠租、损坏赔偿、违约金，不足部分另行赔偿" |
| 支付方式 | 押金与首期租金到账后交钥匙，写明到账时间与账户 |
| 租金支付日与逾期 | 每月 X 日前支付；逾期超过 X 日按合同约定处理（含解除条件） |
| 涨租 | 明确租期内不涨租；续租涨租按当地规定与协商写进补充条款 |
| 备案 | 按当地要求办理租赁备案（涉及租客办证、子女入学等） |

### 4.4 十项必备条款（缺一项都可能变成纠纷）

1. 房屋交付状态与家电家具清单（含品牌型号、数量、可否使用）
2. 押金金额、用途、退还条件与时限
3. 租金金额、支付日、支付方式、逾期处理
4. 租期起止、提前退租的通知期与违约责任
5. 维修责任划分（自然损耗 vs 人为损坏 vs 设施老化更换）
6. 水电燃气物业费承担与缴费方式
7. 是否允许转租、分租、增加同住人
8. 是否允许养宠、装修、加装设备、改变结构
9. 房屋使用限制（不得群租、不得经营、不得存放危险品）
10. 解除条件与交接验收方式（验收单、照片、钥匙数量）

> **翻车警示**：合同只写"押一付三、月租 3500"就交钥匙 —— 一旦发生"墙面被钉了十几颗钉子""说好的不许养宠养了两只猫""提前一个月走了要退押金"，你手上没有任何可执行依据。

## Part 5 履约管理与纠纷

### 5.1 维修责任划分

| 情形 | 责任 | 依据 |
|---|---|---|
| 自然损耗、设施正常老化（水管老化、热水器到期） | 业主 | 出租人有维修义务，保障正常使用 |
| 租客使用不当（堵塞、破损、超负荷烧坏） | 租客 | 人为损坏由使用人赔偿 |
| 双方约定的改善性更换（换新家电） | 协商 | 写进补充条款，避免事后争议 |
| 紧急抢修（漏水、燃气、跳闸） | 业主先行处理 | 保留票据，事后按责任划分 |

### 5.2 退租验收流程（四步留痕）

1. **提前约定验收时间**（退租前 3~7 天）
2. **现场共同验收**：按交付清单逐项核对家电家具、墙面地面、门窗锁具；拍照/录像
3. **结算水电气物业**：抄表读数、结清欠费、办理过户或更名
4. **押金退还**：验收后 X 日内退还；如有扣除，**逐项列明金额与依据**（照片、票据、报价单）

### 5.3 欠租处理四步（先协商、再留证、后依法）

1. 到期未付 → 书面（微信/短信/邮件）提醒，保留发送记录
2. 逾期数日 → 书面催告，写明金额、期限与后果（按合同条款）
3. 持续逾期 → 按合同约定的解除条件处理，书面通知解除并要求腾退
4. 拒不腾退或拒不支付 → 通过调解/诉讼等合法途径解决，**不得自行断水断电、换锁、搬走租客物品**

### 5.4 上门权边界

- 业主/中介带看需**提前征得租客同意**并约定时间，不得擅自进入
- 紧急情况（漏水、燃气泄漏、火情）可先行处置并事后说明，但应尽量留痕（同行人、照片、物业见证）

> **翻车警示**：擅自换锁、断水断电、扣押租客物品，容易从"民事纠纷"升级为侵权甚至治安/刑事问题，本来占理的一方变成赔偿方。

## Part 6 自管 vs 托管

### 6.1 常见托管模式与费用结构

| 模式 | 费用 | 说明 |
|---|---|---|
| 传统代管 | 月租金的 8%~15%（或固定服务费） | 代收租、代维修、代沟通，业主保留定价权 |
| 包租（二房东） | 一次性差价（压价 10%~20%） | 业主拿固定租金，风险转移给包租方，但房屋使用不可控 |
| 全程托管（含装修/家具） | 前期投入 + 服务费 | 省心但投入大，回本周期长 |

### 6.2 六维比选

| 维度 | 看什么 |
|---|---|
| 收费透明度 | 服务费、维修加价、空置期是否收费 |
| 租客筛选标准 | 有没有书面标准，是否让你看材料 |
| 维修响应与报价机制 | 报修时限、维修报价是否需你确认 |
| 资金结算 | 租金何时到你账、是否走共管账户 |
| 违约与退出 | 中途解约、房屋损坏赔偿、租客纠纷谁出面 |
| 口碑与主体 | 公司主体、经营年限、可核实的服务案例 |

### 6.3 委托合同要看的三项

1. **定价权归谁**（低于底线价是否需要你书面同意）
2. **维修授权额度**（多少金额以内可自行处理、超过如何报批）
3. **退出机制**（解约通知期、押金与租金的结算方式、房屋交还标准）

> **翻车警示**：包租模式下"业主拿固定租金很省心"，但房子被改结构、被转租、租客频繁更换而你不知道 —— 一定要保留定期查看权并写进合同。

## Part 7 特殊情形

| 情形 | 关键点 | 提醒 |
|---|---|---|
| 合租 / 分租 | 需符合当地规定与小区规约；公共区域维护责任要写清 | 多租客更容易产生纠纷，建议统一合同模板 + 公共费用分摊表 |
| 短租（日租/民宿） | 多数城市与小区规约有限制，需办理相应手续 | 未经允许的短租被投诉清退的成本极高 |
| 以租养贷 | 用 `rent.py --net` 算净回报，与月供对比 | 租金季节性波动与空置期会造成"某月还不上" |
| 学位占用 | 部分城市学位与房屋绑定，出租可能影响学位使用 | 提前查清当地规则；合同中写明是否允许租客使用学位 |
| 落户/居住登记 | 部分城市租房可办理居住登记或落户积分 | 与卖房计划冲突时要评估，学区房尤其注意 |
| 宠物入住 | 可协商加收押金或清洁费 | 退租时的异味与损坏最难举证，务必先拍照留底 |
| 转租 / 二房东 | 未经书面同意不得转租（合同必写） | 发现转租立即书面制止并保留证据 |
| 房屋要卖 | 买卖不破租赁：租约期内出售，租客可继续住 | 计划卖房时优先签短期约或与租客约定配合看房条款 |

> **翻车警示**：打算卖房却签了两年长租 —— 带租约的房子买家会压价、贷款可能受影响，还可能触发租客的优先购买权。**先想清 12 个月内会不会卖，再决定租期长短**。

| 工具 | 参数 | 单位 | 示例 |

| `rent.py` | `--target-yield` | 百分数 | `--target-yield 4` = 4% |

| `efficiency.py` | `--use-coef` | **小数** | `--use-coef 0.88` = 88% |
| `tax.py` `prepay.py` `mortgage.py` | `--rate` `--agent` | 百分数 | `--rate 3.1` = 3.1% |

超范围的值工具会直接报错并提示正确写法（例如 `--use-coef 88` → 提示改成 `0.88`）。
