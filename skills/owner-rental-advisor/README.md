# owner-rental-advisor（出租业主决策助手）

出租业主全链：该租还是空着 → 租金定多少 → 房子配什么 → 租客怎么筛 → 合同怎么写 → 纠纷怎么处理 → 要不要托管。

## 适用谁
- 出租业主（自管）：不知道租金定多少、怕遇到欠租或赖着不走的租客
- 纠结要不要配家具、简装到什么程度的业主
- 在考虑交给托管公司、想知道费用结构是否合理的业主
- 帮家人打理出租房的家庭成员

## 怎么用（AI 场景）
1. "我这房子该租还是卖了" → Part 1 毛/净回报 + 出租车/出售/空置三选一 + 打平涨幅
2. "租金定多少合适" → Part 2 三源锚点 + 空置算术（空一个月亏多少、降多少能换一个月）
3. "要不要配家具" → Part 3 投入回报表（用租期覆盖投入的判据）
4. "这个租客能租吗" → Part 4 合法筛选边界 + 材料核验清单（哪些能问、哪些不能问）
5. "合同怎么写" → Part 4 十项必备条款，可直接抄
6. "退租了押金怎么退、墙被他弄坏了谁修" → Part 5 责任划分 + 四步留痕流程
7. "欠租不搬怎么办" → Part 5 欠租处理四步（含不能做什么）
8. "要不要托管" → Part 6 三种模式费用结构 + 六维比选 + 委托合同三项

## 输出纪律
- 一切金额结论调 `calc-toolkit`：`rent.py`（毛/净回报、反推目标租金）、`holding.py`（持有成本）、`buy_vs_invest.py`（出租 vs 出售 vs 理财、打平涨幅）
- **参数单位先看清**：`rent.py --vacancy/--tax-rate/--maint` 用百分数（15 = 15%）；`commission.py` 的 `--buyer-rate/--seller-rate` 与 `efficiency.py --use-coef` 用小数（0.01 = 1%）。混用差 100 倍，工具对越界值会报错提示
- 押金上限、涨租幅度、备案、短租与群租规定：**按当地当期规定现查**，本技能不含任何城市的具体数字
- 合同以当地示范文本为底稿，附加条款不得与其强制性内容冲突；法律结论建议咨询律师

## 什么时候不要用我
- **你要卖房**（定价、挂牌、选中介、议价、过户） → 用 `owner-sell-home-advisor`
- **你是经纪人要拿房源委托、管房源** → 用 `broker-listing-sop`
- **你从租客角度找房、议价、看合同** → 本技能没有租客侧内容，按租客视角自行核对 Part 4 的条款清单（尤其押金与维修责任）
- **你要判断片区值不值得投资、算租售比是否合理** → 用 `buyer-first-home-advisor` 的片区与回报部分，配合 `calc-toolkit/rent.py`
- **涉及诉讼、强制腾退、人身伤害与治安事件** → 直接找律师与当地主管部门，本技能只讲到"依法途径"这一层
