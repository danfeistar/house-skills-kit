# 营销物料与示范区优化 SOP（marketing-materials-sop）

把楼书、户型单页、展板、沙盘、样板间和示范区从“展示装饰”变成可理解、可验证、可承接、可改进的营销工具。

## 适用谁
- 策划/设计：物料简报、内容结构、版本管理
- 示范区负责人：现场巡检、维护和动线优化
- 置业顾问：试讲、客户反馈和问题回写
- 营销负责人/审核人：事实、合规与预算审批

## 怎么用（AI 场景）
1. 输入客户问题、使用位置和项目事实 → 输出一页物料设计简报
2. 输入示范区巡检记录 → 输出问题分级、责任人和整改清单
3. 输入竞品踩盘与客户反馈 → 输出低成本展示面改进优先级
4. 输入物料版本和审批信息 → 输出发布前检查表

## 输出纪律
- 每件物料只设一个主任务，且必须有使用位置和承接动作
- 规划、配套、价格、交付标准和政策必须标注来源、日期和审核人
- 不以美观代替有效，不隐藏事实，不制造虚假预期
- 旧版本、旧价格、旧二维码和未经授权素材必须撤回

## 与其他技能的关系
- 蓄客期整体排期 → presale-marketing-sop
- 单场活动 → activity-organization-sop
- 竞品展示面输入 → competitive-intel-sop
- 价值与竞品话术 → sales-talk-library
- 接待与需求反馈 → sales-reception-sop
