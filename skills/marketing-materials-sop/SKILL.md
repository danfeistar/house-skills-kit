# 营销物料与示范区优化 SOP（标准作业程序）· marketing-materials-sop

**一句话**：不把物料当装饰、不把示范区当布景，而是从客户任务出发，让每个展示点都能讲清价值、回答疑问、承接咨询，并能根据现场反馈持续改进。

**适用角色**：营销策划、设计与物料供应商、示范区负责人、置业顾问、营销负责人、合规审核人。

**触发场景**：
- 新项目或新批次启动案场展示
- 楼书、户型单页、展板、围挡、线上海报更新
- 示范区、样板间、沙盘、展点巡检
- 竞品踩盘后进行我方展示面改进
- 活动或接待复盘发现客户看不懂、问不清、记不住

## 使用规则

1. 先明确客户任务和展示目标，再安排物料，不从“做一张好看的图”开始。
2. 每件物料只承担一个主任务，最多两个辅助任务；必须指定使用位置和承接动作。
3. 所有价格、面积、规划、配套、交付标准和政策必须有来源、日期和审核人。
4. 示范区优化优先解决动线、信息缺口、体验断点和维护问题，不盲目增加装饰预算。
5. 不通过模糊措辞、夸大效果、虚构配套或隐藏不利信息制造错误预期。

## 核心流程

```text
客户任务 → 展示目标 → 竞品/现场输入 → 物料与动线设计
→ 合规审核 → 小范围试用 → 案场巡检 → 反馈归因
→ 改版发布 → 版本归档
```

## 物料任务分类

| 主任务 | 典型物料 | 客户离开前应获得的结果 |
|---|---|---|
| 认知 | 围挡、入口展板、项目总览 | 知道项目是谁、解决什么需求 |
| 理解 | 区位图、规划图、沙盘标牌 | 看懂位置、规划和项目关系 |
| 比较 | 户型单页、产品对比表 | 能说出差异与适配人群 |
| 验证 | 工程进度、交付标准、配套说明 | 知道事实依据和时点 |
| 决策 | 一房一价、费用清单、流程卡 | 知道下一步如何咨询或办理 |
| 承接 | 预约卡、资料领取、咨询台 | 能留下授权线索或预约到访 |

**设计原则**：先写客户问题，再写信息结构；先确定来源，再写宣传文案；先确定承接动作，再决定二维码、表单或咨询位置。

## 物料审核清单

### 信息准确

- [ ] 项目名称、楼栋、户型、面积、朝向、价格口径与最新资料一致
- [ ] 规划、交通、学校、商业、交付标准等分别标注事实来源和时点
- [ ] 预计、规划、意向、已兑现等状态没有混写
- [ ] 图示比例、方向、距离、楼栋编号没有误导性表达
- [ ] 过期版本已撤下，现场只保留当前生效版本

### 表达合规

- [ ] 不使用绝对化、保证性、升值性和投资回报性表述
- [ ] 不把周边学校写成学区承诺，入学事项提示以当年政策和主管部门规定为准
- [ ] 不把规划中的道路、地铁、商业和公园写成已经兑现
- [ ] 不用虚假稀缺、虚假折扣、虚构客户评价或未经授权的品牌标识
- [ ] 价格、优惠、赠送、付款和活动权益与批准版本一致

### 使用有效

- [ ] 置业顾问知道这件物料在动线哪个节点使用
- [ ] 客户看完后有明确的提问、预约、资料领取或咨询入口
- [ ] 字号、对比度、观看距离和手机端阅读体验合格
- [ ] 重要信息不被装饰、反光、遮挡或复杂图表淹没
- [ ] 已用真实客户或顾问试讲验证理解程度

## 示范区与样板间巡检

### 巡检四层

| 层级 | 检查内容 | 输出 |
|---|---|---|
| 第一层：可达 | 入口、停车、指引、无障碍、开放时间 | 客户能否顺利找到和进入 |
| 第二层：可看 | 沙盘、景观、样板间、公区、工程展示 | 客户能否按顺序看懂 |
| 第三层：可问 | 标识、数据、材质、户型、交付标准 | 顾问能否快速回应 |
| 第四层：可承接 | 咨询位、休息位、预约、留电、离场提示 | 看完能否自然进入下一步 |

### 现场检查表

- [ ] 从停车或入口到案场的第一段指引不缺失
- [ ] 首次到访客户能在不询问工作人员的情况下找到签到处
- [ ] 沙盘、区位图、户型图方向和编号一致
- [ ] 样板间展示的家具、尺寸和交付标准没有被误认为交付内容
- [ ] 现场真实状态与对外图片没有明显不一致；临时施工处有安全提示
- [ ] 讲解节点之间距离合理，客户不会被迫折返或拥堵
- [ ] 每个主要展示点有一个讲解重点，不堆叠无关参数
- [ ] 体验结束后能自然进入咨询、预约或资料领取
- [ ] 破损、褪色、积水、异味、设备故障和卫生问题已登记并限时处理
- [ ] 客户提出的高频问题已回写物料改进清单

## 竞品输入与改进优先级

竞品踩盘只提供观察输入，不直接照搬文案或设计。将问题按下列优先级处理：

1. **事实错误或合规风险**：立即停用并更正
2. **客户看不懂或动线中断**：优先优化信息层级和指引
3. **客户频繁问同一个问题**：补充事实卡、对比表或讲解节点
4. **竞品明显强于我方且与客群相关**：提出低成本替代体验
5. **纯装饰差异**：最后处理，不单独增加大额预算

## 版本与发布纪律

- 每次改版生成版本号、生效日期、审核人和变更摘要。
- 线上与线下物料必须使用同一批准版本；旧二维码、旧价格页和旧海报同步撤回。
- 供应商交付前完成源文件、印刷稿、移动端稿和现场安装位置核对。
- 现场临时修改不得由个人直接发布，须回到审批链并留下变更记录。
- 物料不使用客户隐私、未授权肖像、未经授权的第三方商标和来源不明图片。

## 效果复盘

每次节点活动、开放日或版本更换后，在 {{72}} 小时内完成小复盘：

| 指标 | 记录方式 |
|---|---|
| 客户主动提问集中点 | 记录频次最高的 {{5}} 个问题 |
| 信息理解偏差 | 记录客户误解的表述和发生位置 |
| 动线断点 | 记录停留、折返、拥堵、无人引导位置 |
| 承接结果 | 咨询、预约、留电、到访等进入对应台账 |
| 维护问题 | 记录损坏、脏污、缺件和修复时长 |
| 费用效果 | 改版费用与问题减少、承接改善的对照 |

复盘只保留不超过 {{3}} 条下一步动作，并分别写清负责人、完成时间和验收标准。

## 合规红线

1. 不得用虚假、夸大、误导性展示掩盖项目真实缺点或制造不合理预期。
2. 不得将规划、意向、建设中的配套表述为已兑现事项；引用政策和规划须标明来源与时点。
3. 不得以极限词、保本升值、学区保证、价格保证或虚假稀缺进行宣传。
4. 不得擅自发布未审批的价格、优惠、赠送、团购或认筹信息。
5. 不得使用未授权的客户肖像、录音、评价、联系方式或第三方品牌素材。
6. 发现安全隐患、重大事实错误或合规风险时，先撤下/隔离相关物料，再上报处理。
