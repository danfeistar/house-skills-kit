# channel-management-advisor（渠道管理与分销决策助手）

渠道分销的**决策层**：结构配比 → 佣金体系 → 准入分级 → 归属仲裁 → 产能诊断 → 飞单治理 → 经营节奏。
执行流程（准入动作、报备查重、带看交接、结佣对账）在 [channel-collaboration-sop](../channel-collaboration-sop/)，本技能不重复。

## 适用谁
- 项目营销负责人：渠道政策决策、费效红线把控
- 渠道总监/经理：结构设计、渠道经营与汰换
- 财务/对账：佣金核算与费效复核
- 区域渠道负责人：多项目政策统筹与年度框架谈判

## 怎么用（AI 场景）
1. 开盘前定结构 → Part 1 来访倒推四步 + 渠道依赖度红线（分销占比 >50% 就要开自渠对冲）
2. 设计佣金 → Part 2 点位四步 + **跳点双算法**（全额跳档 vs 分段累进，用 `commission.py --scene channel` 双算）+ 费效上限与红线
3. 签渠道 → Part 3 A/B/C 分级 + **合同八条款**（算法、归属、禁止条款、罚则、保证金、信息边界、变更机制、争议解决）
4. 撞单争议 → Part 4 三段归属（报备 7 天 / 保护期 30 天）+ 证据优先级 + 三步仲裁
5. 月度复盘 → Part 5 六指标 + 四类健康画像 + ROI 排名表 + 汰换话术
6. 发现飞单 → Part 6 五类信号 + 证据链四件 + 处罚梯度
7. 渠道会与年度谈判 → Part 7 三件事议程 + 政策发布节奏 + 四张纸谈判准备

## 输出纪律
- 佣金、费效、单客成本、跳点一律 `calc-toolkit` 出数：`commission.py --scene channel`（阶梯双算法）、`--scene resale`
- 点位数必须给"市场对标 + 可承受上限"两个依据，不给无依据数字
- 政策建议必须带生效日期与不追溯声明；不允许输出"口头调整佣金"这类方案
- 任何方案输出后过合规红线（不返佣给客户个人、不虚假承诺、不默许洗客、不买卖客源名单）
