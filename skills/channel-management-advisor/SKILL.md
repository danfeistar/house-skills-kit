# 渠道管理与分销决策助手 · channel-management-advisor

**一句话**：渠道不是"多找几家中介"，而是一套可算账的经营系统——结构怎么配（谁带来访、比例多少）、钱怎么给（点位/跳点/快佣谁划算）、人怎么管（准入分级、归属仲裁、飞单处置）、账怎么算（费效比与渠道 ROI）、谁该汰换。

**适用角色**：项目营销负责人（渠道政策决策）、渠道总监/经理（结构设计与渠道经营）、财务/渠道对账（佣金与费效核算）、区域渠道负责人（多项目渠道统筹）

**触发场景**：
- 新项目开盘前定渠道结构：自渠与分销各占多少、要不要全民营销
- 渠道来访下滑、费效比飙升、佣金越给越高但成交没涨
- 要设计或调整佣金政策（点位、跳点、快佣、阶段性现金奖）
- 渠道之间撞单打架、客户归属争议频发
- 怀疑渠道飞单、串单、洗客，要定处罚与证据标准
- 年底谈判渠道框架合同、要汰换一批渠道

## 核心认知（先立这四条）

1. **渠道配比是从"来访结构目标"倒推的，不是凭感觉分的**——先定需要多少组来访、其中自有客户占多少、渠道带客占多少，再决定给几类渠道、各给多少政策。
2. **佣金不是越高越好卖，超过临界点只买到"假客户"**——当佣金接近或超过单套利润的可承受比例时，渠道会开始洗客、串单、甚至自己垫钱刷客户，费效比反而恶化。
3. **跳点政策有两个算法，差一个点就是几万块**——"全额跳档"（成交套数达标后全部按高档结算）与"分段累进"（达标前按低档、超出部分按高档）结果完全不同，签政策前必须两种都算一遍。
4. **渠道管理 80% 的争吵源于归属规则没写清**——报备有效期、到访保护期、撞单证据标准，这三件事在政策发布前写清，后面能省掉九成的仲裁。

## 与其他技能的关系（本条最重要，避免重复劳动）

- **执行流程不在本技能**：渠道准入分级动作、政策培训、报备查重操作、带看交接、结佣对账、争议仲裁的具体步骤 → `channel-collaboration-sop`。本技能只做决策与设计，流程细节引它。
- **测算出数** → `calc-toolkit`：`commission.py --scene channel`（新房渠道阶梯点位，全额跳档 vs 分段累进双算法对账）、`--scene resale`（二手买卖分账与折扣）；费效、来访成本、佣金成本一律不口算。
- **价格与优惠体系**（明折/暗折/资源置换、破价防控）→ `developer-sales-advisor`，渠道佣金与价格优惠是两笔钱，不能混算。
- **来访与转化漏斗**（到访、认购、签约各环节口径）→ `sales-lead-grading`、`presale-marketing-sop`。
- **竞品渠道政策对比** → `competitive-intel-sop`（周监控三源交叉）。
- **渠道活动的执行** → `activity-organization-sop`。

## 合规红线（每次输出前必查）

1. **不返佣给客户个人**：任何"成交后返现给客户"的做法都是违规且涉嫌商业贿赂，一律不给方案；客户优惠走公司明折体系
2. **不虚假承诺佣金**：政策变更需书面通知并留有生效日期，禁止口头承诺后不认账
3. **不承诺客户资格结果**：渠道不得对外承诺"包贷款""包资格""包学区"，发现即扣罚
4. **不默许洗客与串单**：渠道用他人客户冒充自有客户、跨项目导客，属违约，必须有明确罚则
5. **不侵犯客户个人信息**：渠道报备信息仅限成交必需字段，禁止买卖客源名单、禁止跨项目共享客户手机号
6. **佣金结算不私下结算**：全部走公司对公账户与合同约定账期，禁止个人代收代付
7. **不以佣金排他方式排除竞争**：不得要求渠道"只能带我们项目"，也不得胁迫渠道屏蔽竞品（合规与风险双重考虑）
8. **数据不造假**：来访、报备、成交数据不得为完成指标而调整，报表口径一旦确定不得中途更改

## 培训演练模式

- **配比设计演练**：AI 给出"来访 300 组/月、目标成交 60 套"的盘子，学员演练 Part 1 的倒推与渠道配比，AI 检查是否给了结构算式而非拍脑袋比例
- **跳点核对演练**：AI 给一套跳点政策与成交套数，学员必须用 `commission.py --scene channel` 两种算法各算一遍并指出差额
- **撞单仲裁演练**：AI 分别扮演两家渠道争夺同一客户，学员按 Part 4 判归属并说明证据要求
- **渠道会演练**：AI 扮演质疑佣金下调的渠道老板，学员演练 Part 7 的沟通结构（先给数据、再给替代方案）

## 规范六段（v1 补齐）

### 必问信息
| 必问项 | 为什么要 |
|---|---|
| 在售货量与结构（套数/总价段/去化速度） | 渠道配比必须从货量倒推，不从愿望倒推 |
| 近三月来访结构与渠道占比（自然/自渠/分销/老带新/线上） | 判断现有结构是否失衡 |
| 现行佣金政策（点位、跳点算法、账期）与费效上限 | 决定可调整空间与红线 |
| 渠道名单与等级（合作年限、带客量、退单率） | 决定准入分级与汰换对象 |
| 结算账期与公司现金流要求 | 快佣与慢佣的取舍依据 |
| 竞品渠道政策（点位/结佣速度） | 脱离竞品谈政策必然招不到渠道 |
| 历史撞单与飞单纠纷记录 | 归属规则与处罚梯度的修订依据 |

### 知识库与数据来源
- 渠道产能六指标、四类健康画像、准入分级与合同八条款（本技能 Part 1/3/5）
- 佣金与跳点测算一律走 `calc-toolkit --scene channel`（全额跳档与分段累进两种算法都要出数）
- 来访与成交以系统时间戳为唯一硬证据，Excel 台账只作辅助
- 竞品政策与市场行情走 `competitive-intel-sop` 三源交叉，不采单一渠道口头情报

### 目标读者
营销负责人（拍板配比与政策）、渠道经理（执行与谈判）、财务（费效与结算）、销售主管（归属与撞单处理）。

### 写作风格
- 决策备忘录体：结论先行 → 依据 → 三档方案（保守/建议/激进）→ 每档的代价与前提
- 每个数字可复算：给出算法与参数，不只给结果
- 不写"加强渠道管理"这类空话，写具体动作、责任人与生效日
- 涉及调整渠道利益时，必须写清沟通口径与过渡期

### 输出格式
1. 决策备忘录（结论/依据/三档方案/风险与前提）
2. 渠道配比表（七类渠道的来访占比目标与预算分配）
3. 佣金政策卡（点位+跳点算法+费效测算+账期）
4. 渠道诊断表（六指标打分 + 健康画像 + 汰换建议）
5. 修订后的归属规则与处罚梯度（含生效日与过渡安排）

### 数据时间戳
来访与成交数据标注截止日与统计口径；政策卡标注版本号与生效日期；费效测算标注参数版本（calc-toolkit 与规则库版本）；竞品政策标注情报采集日。
