# 商业物业作业手册（commercial-playbook）

> 七步从"客户想买商铺"到"买不买、多少价、怎么退"。金额走 `commercial.py`，不口算。
> 单位提醒：`--vacancy`/`--opex-pct`/`--tax-pct`/`--cap`/`--growth`/`--exit-cap` 都是**百分数**（8=8%），`--rent` 是元/㎡·月。

---

# Part 1 商业与住宅的六个根本差别

| 维度 | 住宅 | 商业（商铺/写字楼/公寓） |
|---|---|---|
| 定价锚 | 同小区成交价（比较法） | **租金决定的收益法**（NOI ÷ cap） |
| 空置 | 月级，好租 | 可能年级，位置差就长期空置 |
| 税费 | 契税 1%~3%，满二免增值税等优惠多 | 契税常见 3%，增值税/土增税/房产税口径不同，优惠少 |
| 贷款 | 最长 30 年、可公积金 | 通常 10 年、首付 50%、利率上浮 |
| 使用限制 | 基本无 | 业态、排烟、消防、明火、营业时间多重限制 |
| 退出 | 卖给下一个自住/投资客 | 卖给"能算出账的人"，接盘面窄，周期长 |

**一句话**：住宅买的是"预期"，商业买的是"现金流"。用住宅思维买商业，最典型的亏法是"等升值"，而商业的价格是算出来的，不是等出来的。

**翻车警示**
- ❌ 用住宅租售比（1:400~1:600）套商业 → 商业租售比 1:150~1:250 才可能成立，套错直接判成"很便宜"
- ❌ 按住宅贷款条件给客户做预算 → 商业首付 50%、10 年期，月供压力比住宅高一倍

# Part 2 商铺：位置分级、业态与硬件

## 2.1 位置分级（决定租金天花板）

| 级别 | 特征 | 租金弹性 | 风险 |
|---|---|---|---|
| 一线街铺/核心商圈 | 客流自然经过、可品牌化 | 高 | 租金已被充分定价，cap 低（3.5%~5%） |
| 社区底商（主入口/主通道） | 服务周边 1~3 个小区 | 中 | 依赖小区入住率与动线，好位置与差位置差 2~3 倍 |
| 社区底商（次通道/背街） | 需绕行 | 低 | 空置率高，租金难涨 |
| 商场内铺 | 依赖商场运营 | 中高（好商场） | 商场一旦整改/主力店撤场，客流断崖 |
| 专业市场/批发 | 依赖产业 | 低~中 | 产业迁移即归零 |

## 2.2 五个硬件硬指标（不满足就别买）

1. **能否餐饮**：有无专用排烟井、燃气、隔油池。不能餐饮的铺，承租能力最强的业态直接出局
2. **面宽与进深**：面宽 <3.5m 或进深/面宽 >3 的"火车厢"铺，展示面差、坪效低
3. **层高与结构**：层高 <3.6m 难做夹层；承重墙位置决定能否改布局
4. **独立水电与增容**：商用水电是否独立计量，电容能否增容（餐饮/美业用电大）
5. **门前条件**：有无台阶、绿化带遮挡、是否单行线、能否停车、是否被地铁围挡

## 2.3 客流怎么看（三次实地法）

- 工作日一次、周末一次、晚上一次，每次 15 分钟，数**经过铺门的人数**与**进店人数**
- 记录周边业态：是否有"引流主力"（超市/菜场/学校/医院）与"排他主力"（同类竞争）
- 问三家邻近商户：月租、月流水量级、续租意愿、物业是否涨租

**翻车警示**
- ❌ 只看到"小区 2,000 户"就判断客流 → 户数不等于客流，动线与出入口决定一切
- ❌ 买"规划中"的地铁/商场旁的铺 → 规划变更与落地时间都不可控，租金假设要打对折
- ❌ 商场内铺按"商场日均客流"算自己铺的客流 → 楼层、位置、扶梯动线决定 90% 的差异

# Part 3 写字楼与公寓：租户结构、得房率、空置

## 3.1 写字楼三看

1. **看租户结构**：单一租户占 50% 以上 = 高集中度风险（一撤即空半层）；小微租户多 = 管理成本高但抗风险
2. **看得房率与硬件**：得房率 60%~70% 常见；层高、电梯配比（每部电梯服务面积）、空调形式（中央/分体）、是否 24 小时可入
3. **看租约**：整层租约通常 3~5 年带递增；小面积租约 1~2 年，续租率是核心指标

## 3.2 公寓（商业性质）四个坑

- 产权 40 年（部分地区 50 年），剩余年限短 → 退出难、贷款年限更短
- 商用水电、物业费高 → 实际持有成本远高于住宅
- 不能落户、不能划学区 → 只能租给"过渡型"租客，续租率低
- 供应集中（同一栋楼几十上百套同类房源）→ 你自己就是竞争者，租金被压

**翻车警示**
- ❌ 把公寓当住宅算回报 → 商水商电 + 高物业费，净回报常被吃掉 1~1.5 个百分点
- ❌ 忽略"同栋同类房源"的竞争 → 出租时你和邻居在打价格战，空置期被拉长

# Part 4 收益法估值与隐含 cap 反查

## 4.1 一条命令算完

```bash
python3 skills/calc-toolkit/commercial.py --area 60 --price 1800000 --rent 120
```

实测读数（60㎡ 商铺 / 总价 180 万 / 月租 120 元/㎡ / 空置 8% / 运营 15% / 税费 12% / cap 5%）：

| 项目 | 数值 |
|---|---|
| 月租合计 / 年潜在租金 | 7,200 元 / 8.6 万元 |
| 有效租金（扣空置 8%） | 7.9 万元 |
| NOI | **5.8 万元 / 年**（月均 4,836 元） |
| 毛租金回报率 | 4.80%（**这是销售话术口径**） |
| 净回报率（NOI/总价） | **3.22%** |
| 租售比 | 1:250 |
| 静态回收年限 | 31.0 年 |
| 按 cap 5% 的合理估值 | 116.1 万元（现价 **+55.1%**） |
| 持有 10 年 IRR | **1.5%**（租金年增 2%、期末按 5% cap 退出） |

**这个案例说明的事**：卖方说"年回报 4.8%"，实际净回报 3.22%；按市场 cap 5% 估值只值 116 万，要价 180 万——溢价 64 万买的是"未来涨租与升值"的预期。持有 10 年 IRR 只有 1.5%，低于多数理财产品。

## 4.2 隐含 cap 反查（谈判最有用的一招）

```bash
python3 skills/calc-toolkit/commercial.py --area 60 --price 1800000 --rent 120 --implied-cap
```

输出：当前价隐含资本化率 ≈ 3.22%（市场参照 5%），按市场 cap 应值 116.1 万元。

谈判话术（可直接用）："按现在租金，这个价对应的资本化率是 3.22%，市场上同类铺是 4.5%~5%。要么租金能到 X 元，要么价格到 Y 万，否则这笔账算不过来。"——把"贵"变成可核对的两个数。

## 4.3 三种估值方法的适用面

| 方法 | 适用 | 局限 |
|---|---|---|
| 收益法（NOI/cap） | 有稳定租约的商铺、写字楼 | 空置铺没有 NOI，只能用市场租金假设 |
| 市场比较法 | 同类铺成交样本充足时 | 商业成交样本少，可比性差 |
| 重置成本法 | 特殊物业、无租金数据 | 不含位置价值，结论常偏离市场 |

**翻车警示**
- ❌ 用毛回报率对比银行理财 → 毛回报没扣空置、运营、税费，实际净回报常常腰斩
- ❌ cap 取 3% 让估值好看 → cap 是市场给的，不是自选的；换成 5% 结论直接反转
- ❌ 空置铺按"满租"算 → 新铺招商期 3~12 个月是常态，必须计入

# Part 5 租约与运营条款清单

签约前逐条核对（缺一条就别签）：

1. 租期与起租日、免租期（装修期）天数
2. 租金单价与计租面积口径（建面 vs 可租面积）
3. 递增条款（每年固定 % 还是每两年跳一次）、递增起始时点
4. 押金月数、支付方式、退还条件与时限
5. 物业费、取暖费、公共能耗由谁承担（商业这块常比租金还敏感）
6. 装修补贴与复原责任（退租时是否要恢复原状，费用谁出）
7. 转租与分租限制、实际经营人与签约人是否一致
8. 业态限制与独家经营条款（是否承诺"同类不再引入"）
9. 提前解约条件与违约金（商业常约定 3~6 个月租金）
10. 招商佣金与租赁代理费用归属（谁付、几个月租金）

## 5.1 租户质量四问

- 做什么业态、做了几年、有几家店（连锁 vs 首店）
- 流水支撑得起这个租金吗（租金占营业额通常 8%~15% 可承受，餐饮 10%~20%）
- 是否有履约能力（查工商、问隔壁、看装修投入——装修投入越高越不会轻易撤）
- 实际控制人与签约人是否同一人（防"租壳"）

**翻车警示**
- ❌ 只签"租金 + 期限"两行 → 物业费、装修复原、递增缺失，退租时全是争议
- ❌ 承诺"独家经营"却没写例外 → 后续引进同类业态，租户索赔
- ❌ 收押金不留收据不进监管 → 房东跑路或换手时，押金归属扯不清

# Part 6 买入与退出的决策口径

## 6.1 三条门槛（按目的选）

| 目的 | 门槛（示例，按客户风险偏好调整） |
|---|---|
| 收租型 | 净回报率 ≥ 4%（一线）/ ≥ 5.5%（三四线），且 租约剩余 ≥3 年带递增 |
| 自用型 | 年持有成本（NOI 亏损部分 + 物业 + 资金占用）< 同位置租金 |
| 升值型 | 隐含 cap 不高于市场 cap 1 个百分点以上（否则已在为预期付钱） |

## 6.2 退出的三个变量

- **退出 cap**：买入 3.22%、卖出时市场要 5% → 估值直接跌 35%；即使租金涨了也补不回来
- **剩余产权年限**：剩余 20 年以下的商业，贷款与接盘面都急剧收缩
- **持有期税金**：增值税、土增税、所得税，商业转让税负远高于住宅，退出前必须算净到手

```bash
# 持有 10 年、租金年增 2%、退出 cap 5% 的 IRR
python3 skills/calc-toolkit/commercial.py --area 60 --price 1800000 --rent 120 --hold 10 --growth 2 --exit-cap 5
```

## 6.3 一页纸估值卡（交付模板）

1. 标的与面积口径（建面/可租）
2. 租金与租约（现租 vs 市场租、剩余年限、递增）
3. NOI 与三个回报口径（毛/净/租售比）
4. 收益法估值与现价偏差 + 隐含 cap
5. 持有期 IRR（含退出 cap 假设）
6. 三条结论：买/不买/多少价买；风险清单；下一步核实项

**翻车警示**
- ❌ 只看买入 IRR 6% 就签 → 退出 cap 一变，十年白干（cap 从 4% 到 5.5%，估值跌 27%）
- ❌ 不算转让税就承诺"三年翻倍" → 税后可能连本金都难保
- ❌ 把"租金会涨"当既定条件写进结论 → 所有涨租必须作为假设单列，并给不涨的版本

# Part 7 七类高风险陷阱与咨询边界

| 陷阱 | 表现 | 本质 | 怎么办 |
|---|---|---|---|
| 返租/售后包租 | "买铺返租 8 年、年返 8%" | 把未来租金风险转给买方，且常由项目公司担保（可注销） | 查兜底主体与偿付能力，书面写明"回报以实际经营为前提"的免责条款；按无返租重算一遍 |
| 产权式商铺（分割销售） | 大商场切成小铺卖，承诺统一经营 | 无法独立经营，退出只能卖给同一运营方 | 查地方是否已限制此类销售；不买"看不见摸不到"的铺 |
| 高 cap 诱饵（远郊商业） | cap 8%~10% 看着很香 | 租金是短租或补贴租，租户随时撤 | 查租约剩余年限与租户背景，按空置 30% 重算 |
| 主力店依赖 | 靠一家超市/影院引流 | 主力店一撤，整条街租金重定价 | 查主力店租约年限与经营状况 |
| 规划憧憬 | "地铁口、mall 旁" | 规划可变更、工期不确定 | 只承认已开工/已运营的配套 |
| 商改住/公寓包装 | 按住宅卖商业公寓 | 不能落户、商水商电、转手难 | 以产权证用途为准，不看销售说辞 |
| 税费陷阱 | "税很少" | 商业转让税费项目多且高 | 交易前用 `tax.py` + 当地核定算净到手 |

## 7.1 咨询边界（必须写在交付物里）

- 本技能给**测算与核对口径**，不做收益承诺、不替卖方/开发商担保
- 不含城市具体税率与产权年限规定：一律按当地当期公告与产权证现查，标注核对日期
- 涉及返租协议、分割销售合规、诉讼 → 律师；涉及税务筹划 → 税务师
- 客户是"想靠这个发财"的心态时，先把最差情景算给他看（空置 30%、退出 cap +1.5 个点）

**翻车警示**
- ❌ 帮客户"圆"返租方案 → 一旦兑现不了，你在中间既失信又担责
- ❌ 交付件里只写回报不写风险 → 客户只记住 8%，出事只找你
- ❌ 用未核实的市场 cap 报价 → 估值差 20% 就是几十万，专业身份直接受损
