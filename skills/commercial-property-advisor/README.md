# 商业物业投资与租赁决策（commercial-property-advisor）

商业物业的定价锚是租金，不是"隔壁卖多少"。这套技能只做三件事：这套商业值多少钱、这个价买贵没有、拿 N 年能不能赚。

## 适用谁
- 二手 / 商业地产经纪人：给客户讲清商铺与写字楼的价值逻辑
- 投资客顾问：测算净回报与退出路径
- 商铺 / 写字楼自用客户：买还是租、买哪个位置
- 房产自媒体：商业类选题的结构化口径

## 怎么用（AI 场景）
1. "客户想买一间社区底商，值不值" → Part 2 位置分级 + 五个硬件硬指标 → Part 4 算净回报与收益法估值
2. "卖方说年回报 6%" → Part 4 先分清毛/净：`commercial.py` 一次给出毛 4.80% vs 净 3.22%
3. "这个价贵不贵、怎么还价" → Part 4.2 隐含 cap 反查（`--implied-cap`）+ 可直接用的谈判话术
4. "写字楼整层要不要接" → Part 3 三看（租户结构 / 得房率硬件 / 租约）+ 集中度风险
5. "返租 8 年、年返 8% 的方案好不好" → Part 7 七类陷阱第一条：查兜底主体、按无返租重算一遍
6. "拿十年能赚多少" → Part 6 持有期 IRR + 退出 cap 敏感性（cap 从 3.22% 到 5%，估值跌 35% 以上）
7. "租约怎么签才不出事" → Part 5 十项条款清单 + 租户质量四问

## 输出纪律
- 金额一律走命令：`commercial.py`（NOI / 毛净回报 / 租售比 / 收益法估值 / 隐含 cap / 持有期 IRR）、`tax.py`（商业交易税费）
- **毛回报与净回报必须成对出现**：只报毛的是销售话术（案例里毛 4.80% 而净只有 3.22%）
- **单位纪律**：`--vacancy/--opex-pct/--tax-pct/--cap/--growth/--exit-cap` 全是百分数（8=8%）；`--rent` 是元/㎡·月，不是月租总额
- 资本化率只引用市场区间并标注时点，禁止"为了估值好看"把 cap 调低
- 租金、成交价、空置率 **超过 30 天必须重取**；产权年限、税率按当地当期公告现查
- 交付物用一页纸估值卡（六块：面积口径 / 租金与租约 / NOI 与回报 / 估值偏差 / 持有 IRR / 三条结论）

## 什么时候不要用我
商业和住宅是两套完全不同的账，用错场景算出来的数字会很"漂亮"但完全失真：

- **住宅出租回报与留卖判断** → `owner-rental-advisor`（住宅口径，租售比与税费完全不同）
- **住宅租赁中介作业流程** → `broker-lease-sop`（委托、筛选、交房、退租）
- **开发商拿商业地块做投前测算** → `project-feasibility-advisor`（货值逻辑，不是 NOI 逻辑）
- **住宅买卖税费与过户** → `broker-client-deal-sop` + `tax.py`
- **返租协议合规、分割销售合法性、诉讼** → 律师；本技能只给风险识别与重算方法

本技能不含任何城市的税率与产权年限数字：一律按当地当期公告与不动产权证现查，并标注核对日期。
