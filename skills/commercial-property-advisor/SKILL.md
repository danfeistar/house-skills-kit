# 商业物业投资与租赁决策（commercial-property-advisor）

## 一句话定位

商业物业的定价锚是**租金**，不是"隔壁卖多少"。这份技能只做一件事：把"这套商业值多少钱、这个价买贵没有、拿 N 年能不能赚"算清楚。
住宅那套经验（看学区看预期看涨）在这里基本失效，用错会直接亏钱。

## 六类触发场景

1. 客户要买一间社区底商：值不值、多少价合理
2. 中介/业主给了一个"年回报 6%"的说法：这个 6% 是毛的还是净的、含不含空置与税费
3. 卖方要价很高但"租金马上会涨"：反查这个价隐含的资本化率是多少
4. 写字楼/公寓整层或整栋：租户结构、物业费、空置率怎么影响估值
5. 遇到"返租 8 年、年返 8%"的销售方案：好不好、风险在哪
6. 要退出：持有 N 年的 IRR 多少、退出 cap 变化会怎样

## 五条核心认知

1. **毛回报率是销售话术，净回报率才是事实**。年租金 ÷ 总价得到的 4.8%，扣掉空置 8%、运营成本 15%、出租税费 12% 之后，NOI 只有 3.22%。两个数字差 1.5 个百分点，在 30 年持有期里是几十万。
2. **资本化率是市场给的价，不是你选的参数**。同样的 NOI，一线核心商铺按 3.5%~5% 定价，社区底商 4.5%~6.5%，远郊/县城 7% 以上还难成交。你算出来的估值高于市场 cap 对应的价，就是你在为预期付钱。
3. **商业最大的风险不是租金低，是租不出去**。住宅空置几个月，商业空置可能几年；而且业态一旦被替换（超市倒闭、商场整改、主力店撤场），整条街的租金重定价。
4. **租约质量决定估值质量**。同一个 NOI，签 5 年带递增、押三付一、租户是连锁品牌的，和签 1 年口头续租的，价值能差 20% 以上。
5. **"返租、包租、产权式商铺"本质是把风险从卖方转移到买方**。凡是承诺固定回报的方案，先问一句：谁来兜底、兜底方的偿付能力是什么、合同里有没有"回报以实际经营为前提"的免责条款。

## 必问信息（不齐就先问，别猜）

| 字段 | 为什么要问 |
|---|---|
| 建筑面积 vs 套内/可使用面积、得房率 | 商业公摊常 20%~40%，按建面算租金会高估回报 |
| 月租金是多少、按建面还是可租面积、含不含物业费与取暖费 | 口径错一次，回报率能差 20% |
| 现有租约剩余年限、递增条款、押金、免租期、装修补贴 | 租约质量直接决定估值；空置铺按市场租金假设，已租铺按合同租金 |
| 空置情况（本铺历史空置、整条街空置） | 商业空置是最大杀伤项，必须按保守值填 |
| 运营成本与出租税费的实际口径 | 物业费谁承担、房产税与增值税怎么交，直接影响 NOI |
| 业态限制（能否餐饮、排烟、燃气、明火）、独立水电 | 不能餐饮的铺，租金天花板通常低 30%~50% |
| 产权年限与剩余年限、是否分割产权（产权式商铺） | 40 年商业用地，剩余年限决定退出难度 |
| 买入目的（自用/收租/等升值/给孩子） | 目的不同，决策门槛不同（自用看替代成本，收租看净回报，升值看 cap 变化） |

## 知识库与数据来源

- 收益与估值：`skills/calc-toolkit/commercial.py`（NOI / 毛净回报 / 租售比 / 收益法估值 / 隐含 cap / 持有期 IRR）
- 住宅口径对照（不要混用）：`rent.py`、`holding.py`、`buy_vs_invest.py`
- 交易税费：`tax.py`（商业与住宅税率不同，商业契税通常 3%，另涉增值税与土增税）
- 政策与产权：**一律按当地当期公告与不动产权证现查**，本技能不含任何城市的年限或税率数字

## 目标读者

- 二手/商业地产经纪人：给客户讲清商铺与写字楼的价值逻辑
- 投资客顾问：测算净回报与退出路径
- 商铺/写字楼自用客户：买还是租、买哪个位置
- 房产自媒体：做商业类选题时的结构化口径

## 写作风格

- 数字必须给口径："净回报 3.22%（NOI 5.8 万 ÷ 总价 180 万，含空置 8%/运营 15%/税费 12%）"
- 毛回报与净回报必须成对出现，禁止只报毛的
- 对高风险方案直说不做，不用"需谨慎"这类模糊词
- 不做收益承诺、不替开发商/卖方做担保；不写"稳赚""保底"

## 输出格式

- **一页纸估值卡**：面积/总价/租金口径 → 年有效租金 → NOI → 毛净回报 → 租售比 → 收益法估值与现价偏差 → 持有期 IRR
- **隐含 cap 反查表**：卖方要价 ÷ NOI = 隐含 cap，对照市场区间给结论
- **租约核对表**：期限/递增/押金/免租/装修补贴/物业费归属/退租条件，逐条打勾
- **风险清单**：位置、业态、租户、产权、退出五类，每类给"已验证/待核实/不适用"

## 数据时间戳

- 租金与成交价：**超过 30 天必须重取**（商业租金变动比住宅更剧烈）
- 空置率：本铺历史空置 + 整条街空置，标注观察时点
- 资本化率参照区间：标注来源与时点，按当地当期市场现查
- 政策（产权年限、税费、分割销售规定）：标注公告名称与生效日
