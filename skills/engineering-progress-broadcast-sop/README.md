# 工程进度与品质播报 SOP（engineering-progress-broadcast-sop）

以工程部书面口径为事实源，完成进度采集、现场核验、图文发布、客户答疑、风险升级和版本归档。

## 适用谁
- 工程部：提供进度、节点和允许公开的工艺资料
- 策划/品牌：编排播报和发布版本
- 案场/客服：客户答疑与问题登记
- 项目负责人：延期、质量和重大事项统一决策

## 怎么用（AI 场景）
1. 输入工程部本期书面口径和现场照片说明 → 输出工程播报初稿
2. 输入上期播报、合同节点和本期进度 → 输出节点对照表
3. 输入客户集中提问 → 输出已确认答复、待核实问题和升级清单
4. 输入播报数据 → 输出下一期改进与归档清单

## 输出纪律
- AI 不根据照片自行推断工期、质量或交付日期
- 已完成、施工中、计划、预计、待确认必须分开表达
- 延期、质量、投诉和交付责任只按合同及正式口径回答
- 任何照片、客户信息和对外版本均须经过授权和审核

## 与其他技能的关系
- 物料与示范区落地 → marketing-materials-sop
- 工地开放日活动 → activity-organization-sop
- 工程疑虑话术 → sales-talk-library / sales-objection-handling
