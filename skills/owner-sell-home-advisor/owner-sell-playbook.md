# 卖房业主决策 playbook · owner-sell-home-advisor

> 站在卖方这一侧。目标不是"卖得高"，是**净得最多、卖得不后悔**。
> 每个 Part 结构：玩法说明 → 示例（清单/表格/测算/话术）→ 翻车警示。
> 所有金额类结论都用 `skills/calc-toolkit` 出数，本文里的数字是示例口径，实际以你自己跑出来的为准。

---

## Part 1 卖前决策：这笔钱该不该现在拿

### 1.1 先回答三个问题

1. **为什么卖**：置换改善 / 资金周转 / 家庭结构变化 / 处置投资 / 不想再持有。
   动因决定你在谈判桌上的耐心，也决定你能接受的最低净得价。
2. **什么时候必须拿到钱**：没有硬时点的，可以等价格；有硬时点的（还债、买新房尾款、孩子入学），时间优先于价格。
3. **不卖行不行**：把"继续持有"的成本算出来，你才知道降价 5 万到底是不是亏。

### 1.2 持有成本测算（决定你能扛多久）

```bash
python3 skills/calc-toolkit/holding.py --area 89 --property 2.5 --price 1500000 --rent 0
```

示例口径：一套 89㎡、物业费 2.5 元/㎡/月、总价 150 万的空置房，光物业费一年 2,670 元，加上贷款利息（如剩余 70 万、3.1%）一年约 2.1 万。**每月持有成本 2,000 元上下**——这意味着"多扛三个月等价于降价 6,000 元不值得"，而"多扛三个月换 5 万涨价"才值得。算过这个数，别人说"再等等"你才有判断力。

### 1.3 置换顺序：先卖还是先买

| 顺序 | 好处 | 代价与风险 | 适用 |
|---|---|---|---|
| 先卖后买 | 资金确定、不背二套认定风险、有现金谈新房 | 中间要过渡居住；若房价上行，新房的价也涨 | 需要卖房款付新房首付（多数情况） |
| 先买后卖 | 不怕没房住，卖房不急 | 首付压力大、两套月供叠加、触发二套利率与税费 | 手头现金够付新房首付 |
| 同步操作 | 时间最紧凑 | 两边违约风险同时存在，最考验节奏 | 有经验 + 有中介兜底 + 合同里留退路 |

**关键测算**：新房首付 = 新房总价 × 首付比例；卖房净得 = 成交价 − 剩余贷款 − 中介费 − 卖方税费。两个数字的缺口就是你需要准备的过桥资金。

```bash
# 卖房净得的税费部分（示例：150 万 / 89㎡ / 满五唯一 / 首套）
python3 skills/calc-toolkit/tax.py --price 1500000 --area 89 --first 1 --held 6 --unique 1
```

实测输出中卖方口径约 **15,267 元**（中介费双方各半 15,000 + 交易手续费 267），满五唯一免征个税、满两年免增值税。若你的房子**不满两年**或**非唯一**，这两个税种会显著改变净得，必须重跑。

### 1.4 三个必须先查清的前置条件

1. **权属**：不动产登记信息（权利人、共有情况、抵押、查封）
2. **占用**：是否有租约在执行、户口是否落在此房、学位是否被占用
3. **欠费**：物业费、水电燃气、供暖（北方）、维修资金是否缴齐

> **翻车警示**：这三项在签约后才暴露，是毁约与降价的第一大原因。带租约的房子若租约未到期且租客不配合搬离，买家贷款与过户都会被拖；户口不迁出则买家可能拒付尾款。**先查清再挂牌**，不要边卖边查。

## Part 2 定价四步：把"我觉得值"换成"市场会认"

### 2.1 第一步：三源锚点

| 锚点 | 用法 | 注意 |
|---|---|---|
| 同小区同户型**近三月真实成交** | 主锚点，决定价格区间 | 必须剔除特殊交易（亲属间、抵债、法拍、含家具家电打包） |
| 在售挂牌（同户型同楼层段） | 看你在比价列表中的位置 | 挂牌价是"卖方期望"，不是成交，通常高于成交 3%~8% |
| 同户型成交周期 | 判断市场冷热与你该给多少让价空间 | 40 天无带看 = 价格问题的强信号 |

### 2.2 第二步：净得价倒算（先算钱，再谈价）

```
净得价 = 成交价 − 剩余贷款 − 中介费 − 卖方税费 − 解押相关费用
```

```bash
# 中介费（卖方 1%）
python3 skills/calc-toolkit/commission.py --scene resale --price 1500000 --buyer-rate 0 --seller-rate 0.01
# → 卖方承担 1% = 15,000 元（注意本工具费率用小数，0.01=1%）
```

**重要**：这套工具里 `commission.py` 的费率是**小数**（0.01=1%），而 `tax.py`/`mortgage.py` 里很多参数是**百分数**（`--rate 3.1` = 3.1%）。混用会差 100 倍，脚本对超大费率会打单位提醒，但**核对一遍再签字**。

### 2.3 第三步：定挂牌价与让价空间

| 策略 | 挂牌价 | 预期 | 风险 |
|---|---|---|---|
| 贴近成交（+2% 内） | 低 | 带看多、成交快、议价空间小 | 可能少赚 1%~2% |
| 常规（+5%） | 中 | 主流做法，留 3%~5% 让价空间 | 需要持续曝光支撑 |
| 试高（+10% 以上） | 高 | 少数情况下遇到不敏感买家 | 前三周是流量黄金期，浪费后极难恢复 |

**建议**：把"你能接受的净得底线"换算成挂牌价，再减去 3%~5% 让价空间作为实际挂牌价。挂牌价不是你的期望，是**你要吸引的那批买家愿意点进来的价格**。

### 2.4 第四步：降价节奏（如果 40 天没动静）

| 时间 | 现象 | 动作 |
|---|---|---|
| 0~14 天 | 带看量正常 | 不动价格，优化可看性 |
| 15~30 天 | 带看有、无出价 | 收集反馈（3 条以上重复出现的缺点才是真缺点） |
| 30~45 天 | 带看明显下降 | 一次性降到位（3%~5%），不要小步慢降 |
| 45 天+ | 几乎无带看 | 价格已脱离市场，重做锚点分析 |

> **翻车警示**：小步慢降（每次降 1 万）最伤——每个新价格你都错过了最有意愿的那批已看客户，而挂牌历史里的连续下调会被买家当成"还能再压"。**宁可一次降到位**。

## Part 3 可看性工程：同样的价，为什么别人先成交

### 3.1 清空与去个人化（成本最低、效果最好）

- 收走：全家福、奖状、宗教物件、宠物用品、晾晒衣物、冰箱贴
- 清空：台面只留 1~2 件装饰；衣柜留 1/3 空位；储物间腾出一半
- 检查：进门第一眼的视线尽头放什么（大多数看房视频/照片都从这里开始）

### 3.2 低成本维修清单（按投入产出排序）

| 项目 | 预算 | 为什么值得 |
|---|---|---|
| 补墙面划痕、擦净踢脚线 | 几百 | 直接影响"是否被维护过"的判断 |
| 更换老化灯泡、加亮客厅 | 百元级 | 昏暗是二手房最大的隐形折价项 |
| 修漏水、疏通下水、换水龙头 | 千元级 | 被发现一次，买家会按最坏情况砍价 |
| 深度保洁（含窗、油烟机、卫生间缝隙） | 千元级 | 照片与实地观感的第一道门 |
| 不建议做全屋翻新 | 数万 | 买家一定按自己的风格重做，投入收不回 |

### 3.3 拍照与视频

- 横拍、广角、白天有自然光时段拍（上午 9~11 点或下午 3~5 点）
- 每间房 2 张（全景 + 亮点），必须覆盖：客厅、主卧、厨房、卫生间、阳台、入户、小区外立面
- **红线**：不得美颜、不得拉宽、不得用样板间图、不得 P 掉漏水痕迹与裂缝——买家到现场发现落差，直接进入压价模式，且你有披露义务

### 3.4 带看配合

- 钥匙：交给中介一把备用 + 自己留一把；能配合随时看房的房源，带看量通常高一截
- 时段：接受晚 7 点后与周末（多数买家只有这两个时段）
- 在场与否：**建议不在场**。你在场买家不好意思细看，也不好问"为什么卖"
- 宠物与气味：提前安置宠物，通风；气味是买家最不好意思说但最影响决策的因素

> **翻车警示**：为了"显得好卖"而临时遮掩（把渗水墙刷白、把裂缝贴墙纸），一旦被发现，交易不但会崩，还会牵出"隐瞒瑕疵"的定金与赔偿争议。

## Part 4 选中介：三家比选，条款核验

### 4.1 六维比选打分（每家打分，1~5 分，加权看结果）

| 维度 | 看什么 | 权重 |
|---|---|---|
| 同小区成交案例 | 近半年本小区成交几套、什么价 | 25% |
| 客源匹配能力 | 能否说清"我这房子适合谁" | 20% |
| 带看量与反馈质量 | 承诺周带看量，反馈是否具体 | 20% |
| 费率与费用结构 | 总费率、买卖双方分摊、是否有其他费用 | 15% |
| 服务内容 | 是否含拍照、推广、资金监管协助、过户陪同 | 10% |
| 口碑与稳定性 | 门店经营年限、经纪人从业年限 | 10% |

### 4.2 独家 vs 多家

| 类型 | 对价 | 适合 |
|---|---|---|
| 多家委托 | 无投入，靠自然带看 | 房子优质、位置好、不着急 |
| 限时独家 | 换取推广投入、专属经纪人、周带看承诺 | 着急卖、房源有硬伤需要资源堆 |

**独家必须换到对价**：推广预算多少、周带看几组、多久一次书面反馈、未达标怎么办（解约条款）。没有对价的独家只锁住了你自己。

### 4.3 委托条款七项核验

1. 委托类型（一般/独家/限时独家）与期限
2. 佣金费率、由谁承担、是否含其他费用
3. 独家期内自行成交（自己找到的买家）怎么算
4. 委托到期后的"保护期"条款（到期后多久内成交仍需付佣）
5. 降价是否需要你书面确认
6. 中介的披露与反馈义务（多久一次、反馈什么）
7. 解除条件与违约责任

### 4.4 应对"压价催签"

中介最常见的三句话与应对：

| 对方说 | 真实含义 | 你该做的 |
|---|---|---|
| "市场很差，这个价没人看" | 可能是事实，也可能是压价 | 要**带看记录与具体买家反馈**，不是结论 |
| "签独家我就给你主推" | 换取你的独家 | 要书面：推广预算、周带看量、未达标的处理 |
| "有客户出价 X，今天必须定" | 制造紧迫 | 要求见买家或至少书面 offer，**不接受口头出价** |

> **翻车警示**：把"独家"签给了不带看的中介，等于把房源放进冷库。签之前先看对方近三个月的带看记录。

## Part 5 议价与接单：什么时候点头

### 5.1 接 offer 五问

1. 净得多少？（跑一遍 Part 2 的倒算）
2. 买家是全款还是贷款？贷款的话预审过了吗、批贷要多久？
3. 付款节奏：定金多少、首付什么时候到位、尾款与过户怎么衔接？
4. 有没有附加条件？（要求你承担税费、赠送家具家电、延后交房、先租后买）
5. 违约责任怎么定？（定金还是违约金，谁承担中介费）

### 5.2 还价与让价阶梯

- **不要一次让到底**：第一次让 1%~2%，每次让步换取一个对价（定金提高、付款提前、放弃附加条件）
- **不要接受"口头的更高出价"**：没有书面 offer 的出价等于没有
- **不要在同一天答复两个 offer**：先比较净得与确定性，再给答复时点

### 5.3 定金与违约责任测算

```bash
# 你在收 5 万定金后反悔（卖方违约）= 双倍返还
python3 skills/calc-toolkit/deposit.py --mode penalty --price 1500000 --deposit 50000 --breach seller
```

实测：卖方违约应返还 **100,000 元**（有效定金双倍）；买家违约则不退定金。**注意**：合同里必须出现"定金"字样，写成"订金/意向金/认筹金"不适用定金罚则。

### 5.4 有贷款的房子：解押怎么安排

卖房前剩余贷款通常要先还清才能过户（各地"带押过户"政策不同，按当地当期规定现查）。测算一下提前还款的实际节省：

```bash
python3 skills/calc-toolkit/prepay.py --loan 700000 --rate 3.1 --years 30 --paid 60 --prepay 300000
```

示例输出：剩余本金 70 万、执行利率 3.1%、剩余 300 期；提前还 30 万并缩短期限，剩余期限 300 → 143 期，**节省利息约 22.7 万元**。

**关键判断**：如果你打算卖房，解押的钱从哪来？三条路——自有资金、买家首付垫付（需资金监管与合同约定）、垫资公司（有成本）。**不要用"买家首付直接还我的贷款"这种没有监管的口头安排**。

> **翻车警示**：签约时不知道有解押成本与时间，导致"过不了户"违约的案例，比价格谈崩的多得多。

## Part 6 交易流程与五类高频纠纷

### 6.1 标准流程（各环节时限按当地当期规定）

```
签约（定金）→ 网签备案 → 资金监管 → 解押（如有贷款）→ 买方贷款审批 → 过户缴税 → 领证 → 交房（水电过户、物业交割）
```

### 6.2 五类高频纠纷与预防动作

| 纠纷 | 触发点 | 预防动作 |
|---|---|---|
| 户口未迁出 | 买家要求迁出才付尾款 | 挂牌前查清户口；合同中约定迁出时点与违约金 |
| 租约占用 | 带租约出售，租客不搬 | 提前与租客协商解约并留书面；否则在合同中披露并约定交房条件 |
| 渗漏与隐蔽瑕疵 | 交房后 buyer 发现漏水 | 主动披露已有问题；交房前做一次闭水试验并留记录 |
| 面积/权属不符 | 实际面积与产证不符、有违建 | 挂牌前核对产证；违建部分提前处理或明确披露 |
| 一方毁约 | 房价波动导致后悔 | 定金与违约金条款写清；不要用"订金"字样 |

### 6.3 交房清单

水电气读数与过户、物业费与供暖费结清证明、维修资金缴存凭证、钥匙与门禁卡、家电家具清单（若含在总价内）、装修与保修资料、小区车位与储物间归属。

## Part 7 特殊情形（只给流程，不下法律结论）

| 情形 | 能不能卖 | 关键动作 | 提醒 |
|---|---|---|---|
| 继承所得 | 能，需先办继承登记 | 全部继承人到场或提供公证文件；先完成继承过户再交易 | 有继承人不同意时无法过户，需先解决争议 |
| 共有产权（夫妻/家人） | 能，需共有人同意 | 全部共有人签署合同；婚内财产按婚姻状况确认 | 只有一方签字可能导致合同无效 |
| 离婚析产 | 能，需先明确归属 | 按协议或判决书办理析产登记后再出售 | 未析产直接出售会卡在登记环节 |
| 有抵押 | 能，需解押或带押过户 | 确认当地是否支持带押过户；否则先还款解押 | 解押资金与时间要计入交易计划 |
| 被查封 | 不能，需先解除 | 查明查封主体与原因，解除后方可交易 | 查封房交易属高风险，不要轻信"马上能解" |
| 学位被占用 | 能，但影响价格与买家决策 | 查清占用年限；如买家在意须书面披露 | 承诺"学位可用"是高危表述，不承诺 |
| 带租约出售 | 能，受"买卖不破租赁"限制 | 披露租约；与租客协商优先购买权与搬离时间 | 租客有优先购买权，须书面放弃或通知 |

> **翻车警示**：以上每一种情形，只要"先签约、后解决"，就会变成违约。**顺序永远是：先解决权利瑕疵，再对外报价。**

## 交付物模板：卖房决策一页纸

```
【卖房决策一页纸】房源：______ 面积：______ 挂牌价：______

一、为什么卖 / 最晚什么时候要钱：____________
二、净得测算：成交价 - 剩余贷款 - 中介费 - 卖方税费 = 净得 ______
     税费口径：满__年 / 唯一__ / 来源与日期 ______
三、锚点：同户型近三月成交 ___ 套，区间 ______；在售同户型 ___ 套，我们排第 __
四、可看性整改：必做 __ 项（预算 ___），选做 __ 项
五、中介比选：A/B/C 三家得分 ______，选择 ______，独家对价 ______
六、接单底线：净得低于 ______ 不接；附加条件不接受 ______
七、风险清单：户口 / 租约 / 抵押 / 瑕疵 / 其他 ______
```

填不满这一页，说明还没到能挂牌的状态。
