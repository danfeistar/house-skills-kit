# owner-sell-home-advisor（卖房业主决策助手）

业主侧的卖房全链决策：卖前该不该卖 → 定价四步 → 可看性 → 选中介 → 议价签约 → 交易流程 → 特殊情形。

## 适用谁
- 二手房业主：自己卖房、纠结挂牌价、被中介压价催签
- 置换业主：算不清卖房净得、拿不准先卖还是先买
- 帮家人处置房产的成年子女：房子有共有、继承、租约、抵押等情形

## 怎么用（AI 场景）
1. 想卖但不知道挂多少 → Part 2 三源锚点 + 净得价倒算，出定价卡
2. 中介说"市场差、再降点" → Part 4 应对压价催签三句话 + 要带看记录
3. 纠结独家还是多家 → Part 4 独家必须换到的四项对价
4. 房子卖相不好 → Part 3 低成本维修清单（按投入产出排序）
5. 收到 offer 该不该点头 → Part 5 五问 + 净得对比 + 定金违约测算
6. 有贷款不知道解押怎么安排 → Part 5 三条路径 + 提前还款测算
7. 房子有继承、共有、租约、抵押 → Part 7 各情形的顺序与前置动作

## 输出纪律
- 一切金额结论调 `calc-toolkit`：`tax.py`（卖方税费）、`commission.py --scene resale`（中介费，费率用小数 0.01=1%）、`prepay.py`（解押）、`deposit.py`（定金违约责任）
- 定价必须给三源锚点，且成交锚点注明成交日期与来源；**超 30 天的价格数据必须重取**
- 法律与税务只给流程与要问的问题，不下结论；争议建议咨询律师或税务师
- 政策数字一律"按当地当期公告现查"，本技能不含任何城市的具体数字

## 什么时候不要用我
这个技能有明确边界，用错场景会得到看似正确但方向相反的结论：

- **你是经纪人/门店，要拿房源委托** → `broker-listing-sop`（房源开发、价格校准话术、委托签约、防跳单）
- **你要帮买家选房、议价、验真** → `buyer-first-home-advisor`（站位不同，结论会相反）
- **你要做出租决策**（该不该租、租金多少、租客怎么筛） → `owner-rental-advisor`
- **你要判断某个片区值不值得投资** → `buyer-first-home-advisor` 的片区与回报部分，配合 `calc-toolkit/rent.py`、`calc-toolkit/buy_vs_invest.py`
- **你要确权诉讼、继承争议、离婚财产分割的最终结论** → 律师；本技能只给流程与要问的问题

本技能不提供政策数字与法律结论：一律按当地当期公告现查。
