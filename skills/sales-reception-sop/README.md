# sales-reception-sop（接待与需求挖掘 SOP）

案场首访接待标准动作：先判断客户，再匹配项目价值，最后衔接带看、算价和后续跟进。

## 适用谁
- 置业顾问：首访接待、需求挖掘、带看匹配
- 销售主管/经理：接待质检、复杂客户协助、交接复核
- 案场负责人：轮接与登记纪律

## 怎么用（AI 场景）
1. 接待前输入已知信息 → 生成本次重点提问清单
2. 接待中输入客户原话 → 判断明需求/隐需求/硬约束/弹性项
3. 带看前输入画像 → 推荐调用的话术域、户型方向和带看顺序
4. 接待结束输入笔记 → 按“已确认/未确认/客户原话/下一步”生成交接摘要

## 输出纪律
- 没有出现的信息一律标记“未确认”，不擅自补齐画像
- 项目数字、政策、价格、库存和规划统一标记核验来源
- 不把接待 SOP 与 L1-5 长周期跟进、L1-3 算价逼定混成一个技能
