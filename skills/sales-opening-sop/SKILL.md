# 开盘执行 SOP · sales-opening-sop

**一句话**：把开盘日变成可复制的流程——开盘前梳理与预登记 → 认筹转认购 → 开盘日三区选房动线 → 规则与口径统一 → 岗位分工与应急预案 → 盘后转化。

**适用角色**：置业顾问（客户组织与选房陪同）、销售主管/案场负责人（现场指挥与规则执行）、开盘执行团队（叫号/复核/认购签约岗）

**触发场景**：
- 项目开盘或加推前 2-4 周启动执行准备
- 认筹客户转认购的意愿梳理与动员
- 开盘日现场选房、认购、签约的流程执行
- 开盘现场出现争议、拥堵、系统故障等突发情况
- 开盘结束后未选房客户与剩余房源的转化

## 核心认知

1. **开盘的核心矛盾是"热度"与"秩序"**：流程的目的不是走形式，是让每一组客户在正确的时间做正确的动作——顺序公平、节奏可控、结果可查。
2. **开盘七成功夫在盘前**：客户梳理、意愿分层、预登记做得越实，开盘日越顺；现场靠临场发挥的开盘一定乱。
3. **口径统一是纪律**：房源清单、选房规则、价格优惠在开盘前锁定，全员一个口径；开盘日任何个人无权现场改规则。
4. **应急预案不是文档是演练**：每个岗位知道自己"出状况时听谁的、做什么"，预案才算存在。

## 结构

详见 `opening-playbook.md`：
- **Part 1 开盘前执行准备**：客户梳理分层、房源与规则锁定、**房源意向落位**（认筹客户×意向房号落位表）、**价格管控与调度准备**（放价审批链与现场调度规则）、物料与场地检查清单
- **Part 2 认筹转认购执行**：转认购动员节奏、意向房源锁定话术、转认购节点管理
- **Part 3 开盘日选房动线**：签到→等候→叫号→选房→认购→签约→离场七环节；**房源销控**（销控板唯一事实源、销控三岗、先销控后签约）
- **Part 4 选房规则与口径统一**：排序规则、房源公布节奏、弃选处理、全员口径表
- **Part 5 现场岗位与应急预案**：岗位分工表、五类突发（拥堵/争议/系统故障/客诉/时间超时）处置流程
- **Part 6 开盘后转化**：未选房客户分层跟进、尾房去化、复盘会模板

每 Part 格式：**规则 → 动作 → 话术 → 翻车警示**

## 合规红线

1. 房源与价格信息以政府备案和公司发布口径为准，开盘前不得私自向客户泄露未公布房源价格。
2. 选房顺序规则一经公布不得临时变更；不搞"关系户插队"，一票否决。
3. 不制造虚假热度：不谎报"仅剩 X 套"、不安排虚假抢房，涉虚假宣传。
4. 认购金/认筹金的收取、退还严格按公示规则与公司财务流程执行。

## 与其他技能的关系

- 开盘前的客户分级与预登记 → L1-5（判客分级是开盘排号意愿梳理的底座）
- 选房现场的算价、逼定与签约 → L1-3；客户异议 → L1-2；按揭材料 → L1-6
- 渠道客户到场核对与结算 → L3 渠道线规则
- 开盘价格策略与推盘节奏（策略层）→ L2 策划线；本技能只管执行层
