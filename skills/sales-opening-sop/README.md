# sales-opening-sop（开盘执行 SOP）

开盘执行层标准流程：盘前准备 → 认筹转认购 → 开盘日选房动线 → 规则口径 → 岗位应急 → 盘后转化。

## 适用谁
- 置业顾问：客户组织、选房陪同、认购推进、盘后跟进
- 销售主管/案场负责人：现场指挥、规则执行、应急处置、复盘主持
- 开盘执行团队：签到、叫号、复核、认购、签约各岗

## 怎么用（AI 场景）
1. 输入认筹客户台账 → 按分级输出开盘意愿分层与动员优先级
2. 输入开盘流程节点 → 输出岗位分工表与时间轴模板
3. 输入突发情况描述 → 输出对应应急流程与话术
4. 输入开盘结果数据 → 输出复盘会框架（去化/客户流失节点/口径执行偏差）

## 输出纪律
- 房源数量、价格、优惠一律用占位符，以政府备案和公司发布口径为准
- 选房规则输出为"模板"，开盘前须经案场负责人确认并公示，AI 不代定规则
- 不输出任何"制造紧张气氛"式话术（谎报余量、虚假抢房）
- 应急处置以"现场指挥负责人"为唯一决策点，AI 建议不替代现场指令
