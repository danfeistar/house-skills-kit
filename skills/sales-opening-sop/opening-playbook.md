# 开盘执行 SOP 正文（执行层）

> 本文只写开盘执行层；价格策略与推盘节奏（策略层）在 L2 策划线，客户分级在 L1-5，算价逼定在 L1-3。
> 全文房源套数、价格、优惠、时间一律 `{{}}` 占位，以政府备案与公司发布口径为准。
> 选房规则模板须案场负责人开盘前确认并公示后生效，任何个人无权现场变更。

## Part 1 开盘前执行准备（开盘前 {{2-4}} 周启动）

### 1.1 客户梳理与意愿分层（底座=L1-5 分级台账）

| 层级 | 定义 | 盘前动作 |
|------|------|---------|
| 必到层 | 认筹 + A 类客户 | 一对一通知开盘时间地点规则；预登记意向房源 {{2-3}} 套 |
| 冲刺层 | B 类客户 | 开盘前一周集中动员：价值梳理 + 开盘政策讲解邀约 |
| 保温层 | C 类客户 | 开盘政策统一短信/微信触达，到场送签到礼 |
| 渠道层 | 渠道带访认筹客户 | 按 L3 规则核对报备与结算材料，开盘日前完成核验 |

**预登记纪律**：
- 意向房源预登记只作组织依据，不作选房承诺；话术必须带"以开盘当天选房为准"
- 预登记数据开盘前 {{3}} 天锁定快照，供叫号顺序与房源热力预估用

### 1.2 房源与规则锁定（开盘前 {{7}} 天）

1. 房源清单锁定：可售套数、楼层价差表，以公司发布口径为准，案场负责人签收
2. 选房规则公示稿定稿：排序规则、每号选房时限、弃选规则、认购金金额与退付规则（模板见 Part 4）
3. 价格优惠口径锁定：开盘优惠、付款方式优惠的准确口径，全员培训签字
4. **锁定后任何调整走正式变更流程并重新公示**，不得口头传达

### 1.3 物料与场地检查清单（开盘前 {{1}} 天全查一遍）

| 类别 | 检查项 |
|------|--------|
| 证件公示 | 预售证、一房一价表公示到位 |
| 现场分区 | 签到区/等候区/选房区/认购区/签约区/财务区标识与隔离 |
| 叫号系统 | 叫号屏、话筒、备用扩音器测试；系统故障时的人工叫号预案 |
| 认购材料 | 认购书、POS 机、认购金收款码、备用纸质单据 |
| 人员到岗 | 各岗位职责卡人手一份（见 Part 5 岗位表） |

**翻车警示**：
- ❌ 预登记对客户说"帮您留好 {{房源}}"——留房承诺开盘日兑现不了就是纠纷
- ❌ 规则靠微信群口头通知——以公示 + 签收为准
- ❌ 开盘前夜才发现 POS 机没调试——清单要提前一天全项过

## Part 2 认筹转认购执行

### 2.1 转认购三步节奏

| 步骤 | 时点 | 动作 |
|------|------|------|
| 意愿确认 | 开盘前 {{7-10}} 天 | 认筹客户逐一电话/到访确认：是否到场、意向房源有无变化 |
| 动员强化 | 开盘前 {{3}} 天 | 开盘政策说明会/一对一讲解：规则、房源、优惠口径统一宣讲 |
| 到场确认 | 开盘前 {{1}} 天 | 短信+电话双确认到场时间；未确认客户开盘日晨补一轮 |

### 2.2 意向锁定话术（不作承诺版）

> "{{称呼}}，开盘那天您最想要的是 {{意向房源方向}} 吧？我先登记上，方便当天第一时间安排您选房。当天房源谁先选谁得，以现场为准，您早点到机会更好——我 {{时间}} 在签到区等您。"

**翻车警示**：
- ❌ "您不转认购就买不到了"式恐吓——虚假紧迫红线
- ❌ 认筹金转认购金的规则没讲清就收钱——纠纷源头，必须按公示规则讲明退付条件

## Part 3 开盘日选房动线（七环节）

```
签到 → 等候区（规则宣讲）→ 叫号 → 选房区（3分钟选房）→ 复核销控
 → 认购区（签认购书+交认购金）→ 签约区（财务/贷款材料）→ 离场（礼包+后续节点告知）
```

### 3.1 环节要点

| 环节 | 执行要点 |
|------|---------|
| 签到 | 按认筹单号核对身份；渠道客户同步完成 L3 核对；发号序号牌 |
| 等候区 | 每 {{20-30}} 分钟一轮规则宣讲：选房顺序、时限、弃选规则、房源动态播报口径 |
| 叫号 | 严格按公示顺序叫号，叫号三次未到按弃选处理（规则公示过的才可执行） |
| 选房区 | 每号限时 {{3}} 分钟（或公示时限）；销控板实时更新；选房确认单签字 |
| 复核 | 复核岗核对房源状态防止一房两卖，错配当场纠正 |
| 认购区 | 认购书填写规范、认购金收取、按揭材料预收（转 L1-6 清单） |
| 签约离场 | 财务开票；告知后续签约/贷款节点；发放签到礼；引导离开不滞留 |

### 3.2 顾问在动线中的三个动作

1. **盘前**：把自己客户"接进来"——提前与客户约好见面点位，签到即接管
2. **选中**：陪同选房只做两件事——帮客户在时限内完成对比决策（L1-3 算价口径），提醒规则时限不替客户抢房
3. **选定后**：直送认购区完成签字付款，中途不带去别处，防止节外生枝

**翻车警示**：
- ❌ 顾问替客户抢房源引发冲突——引导可以，动手不可以
- ❌ 选房区拥堵不管控——一次只放对应号码的客户进入
- ❌ 客户选定后又"想再看看"放行出去——按规则处理：已确认选房的按弃选/锁定规则办，口径统一，不开口子

## Part 4 选房规则与口径统一（公示模板）

### 4.1 选房规则公示要素（开盘前公示 + 等候区反复宣讲）

1. **排序规则**：按认筹顺序/公证摇号/公示的优先规则（按当地监管要求与公司口径执行）
2. **选房时限**：每号 {{3}} 分钟，超时按当前轮次末位重排或按弃选处理（公示哪种执行哪种）
3. **弃选规则**：叫号三次未到 / 超时未确认 / 确认后放弃的房源处理与再次进入规则
4. **认购金**：金额、支付方式、退付条件与时效（按公示与监管要求）
5. **房源动态**：销控板为准，播报口径统一为"{{房源状态以销控板为准}}"

### 4.2 全员统一口径表（开盘日只允许说这些）

| 场景 | 统一口径 |
|------|---------|
| "还有房吗" | "以销控板实时为准，您关注叫号，轮到您时选房区看得见" |
| "能不能先帮我留一套" | "开盘规则谁先选谁得，对大家都公平，我陪您盯您的号码" |
| "能不能便宜点" | "今天优惠口径开盘前已公示，就这一套，谁来说都一样" |
| "我排号靠后没戏了吧" | "前面对房源会有调整，前面的选择不一定合您，轮到您时按当时余量选，机会一直有" |
| 规则争议 | "规则开盘前已公示，按公示执行；您的诉求我记录，交现场负责人统一处理" |

**翻车警示**：
- ❌ 谎报"只剩 {{X}} 套了赶紧定"——虚假宣传红线，按销控板事实说话
- ❌ 顾问间口径打架（一个说有优惠一个说没有）——开盘前全员口径培训签字
- ❌ 现场给"关系户"临时插队——一票否决，引发群体事件风险最高的一条

## Part 5 现场岗位与应急预案

### 5.1 岗位分工表（一岗一卡，职责卡人手一份）

| 岗位 | 职责 | 汇报对象 |
|------|------|---------|
| 现场总指挥 | 规则解释权、突发事件决策、房源口径发布 | 案场负责人 |
| 叫号岗 | 按序叫号、弃选登记 | 总指挥 |
| 选房区管控 | 限流放进、时限提醒、销控板更新 | 总指挥 |
| 复核岗 | 房源状态复核、防一房两卖 | 总指挥 |
| 认购签约岗 | 认购书、收款、贷款材料预收 | 财务/主管 |
| 客户引导岗 | 动线引导、等候区秩序、宣讲 | 主管 |
| 安保岗 | 场外排队、出入口、冲突先期处置 | 总指挥 |
| 机动岗 | 补位任何空岗 | 总指挥 |

### 5.2 五类突发处置

| 突发 | 处置流程 | 口径 |
|------|---------|------|
| 客户对排序/弃选争议 | 引导至争议处理区单独沟通 → 总指挥按公示规则答复 → 登记诉求承诺回复 | "按公示规则执行；您的诉求已登记，{{时限}} 内给您答复" |
| 现场拥堵混乱 | 安保控制人流 → 叫号暂停 → 广播安抚 → 分批放入 | "大家稍安，为了保证每个人选房体验，现在分批进入" |
| 叫号/系统故障 | 启动人工叫号（备用扩音器+纸质登记）→ 双人复核防错漏 | "系统正在恢复，我们按登记顺序人工叫号，顺序不变" |
| 客诉激动/冲突 | 安保隔离 → 主管带离现场单独处理 → 不在选房现场对峙 | "这里人多，咱们到旁边坐下说，我给您安排专人对接" |
| 时间严重超时 | 总指挥宣布当日截止节点 → 未叫号客户安排次日顺延方案并公示 | "今天进行到 {{号码}}，剩余顺延至明天 {{时间}}，规则不变，请大家留意通知" |

**应急总纪律**：所有突发先控场、再答疑、后处理个案；决策权只在现场总指挥，其他人不自行答复规则类问题。

## Part 6 开盘后转化与复盘

### 6.1 未选房客户分层（开盘后 {{48}} 小时内完成首轮跟进）

| 客户 | 原因分层 | 跟进动作 |
|------|---------|---------|
| 未到场 | 时间冲突/意愿弱 | 确认意向度；意向仍在的约案场一对一（房源余量实报） |
| 到场未选 | 房源不合/价格/资金 | 按真实原因转 L1-2/L1-3/L1-6 对应路径；{{3}} 天内二次触达 |
| 弃选客户 | 顺序靠后/临时犹豫 | 余量房源实报 + 后续加推动员；不虚报余量 |
| 已认购未签约 | 材料中/犹豫 | 按 L1-6 清单跟材料；签约节点到期前 {{3}} 天提醒 |

### 6.2 尾房去化执行

1. 余量房源实数统计 → 销控口径更新 → 全员同步一次
2. 针对性邀约：按弃选/未选客户的需求画像匹配剩余房源，一对一向客户说明匹配理由
3. 渠道未转化客户按 L3 规则同步渠道方继续带访

### 6.3 开盘复盘会（开盘后 {{3}} 天内，模板）

| 复盘项 | 问题 |
|--------|------|
| 去化 | 认购/签约/弃选各多少？与预登记热力的偏差及原因 |
| 客户流失节点 | 签不到场/等候离场/选房弃选/认购未签，哪个环节丢客最多 |
| 口径执行 | 有无口径打架、私改规则、超时未纠？出处与纠正 |
| 流程卡点 | 叫号/选房/认购哪个环节堵？时长数据 |
| 应急检验 | 五类预案有无启用？处置是否按流程 |
| 改进项 | 下次开盘/加推的 {{3}} 条以内可执行改进 |

**翻车警示**：
- ❌ 复盘会开成庆功会——数据不摆就没有改进
- ❌ 弃选原因不记录——下次开盘同样的坑再踩一遍
