# mock 适配器 — house-skills-kit

**零依赖、零外部 API**。任何人 clone 本仓库后即可完整演示技能渲染链路，这也是我们建议开源冷启动的默认适配器。

## 它做什么

不做真实数据。渲染时它向 SKILL.md 注入一段「适配器约定」说明，并附带一个可运行的 `mock_cli.py`，用固定样例数据模拟「搜索/详情/小区」三个接口，让使用者理解数据层长什么样、接口契约是什么。

## 目录

- `mock_cli.py` — 演示用假数据 CLI（`search` / `detail` / `resblock` 三个子命令）
- `adapter.md` — 本适配器的能力与接入说明（渲染时可作为 adapter_usage 注入）

## 上线真实数据时

把 brand.yaml 的 `adapter.id` 换成真实适配器（beike-cli / custom-rest / 自研），并在模板正文替换调用方式即可——**技能提示词层零改动**，这正是本套件的核心设计。

## 自制适配器最低要求

1. 提供三个能力：房源搜索、房源详情、小区信息（名称可不同，语义对齐即可）；
2. 提供可用性预检方式（一条命令或一个健康检查端点）；
3. 失败时返回明确错误，**绝不返回编造数据**（模板第 4.1 节会约束 AI 行为，但适配器自身也要守这条）。
